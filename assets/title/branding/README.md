# 炼字狱字标

`lianziyu-wordmark-v1.png` 是正式标题界面使用的透明 RGBA 字标，基于用户提供的参考通过内置 ImageGen 编辑生成，再进行一轮去浮雕与粗描边的调整。

它是按参考重建的书法资产，并非逐像素保真的传统选区抠图。金色飞白、朱砂圆痕与文字为同一张透明图片；原图下方的口号、右侧小印和背景没有保留。

项目内不依赖临时目录。来源参考、完整提示词和实机截图保存在 `docs/art-concepts/2026-10-19-lianziyu-title/`。

菜单、指示菱形和选中框由 Godot 原生控件绘制；前景灯、阴影、落叶和水面仍由实时三维场景负责。金纹云为可编辑 SVG，按世界视线方向采样到天空。
