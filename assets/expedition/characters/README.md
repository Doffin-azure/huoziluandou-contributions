# 持灯行者 · 原生低模样模

根据用户提供的兜帽行者三面设定制作，用几何轮廓、顶点分色和真实光照表现角色。与园林组件共用像素轮廓线及分段漫反射，没有角色贴图或面向相机的立片。

本轮是独立角色样模，尚未替换运行地图的行者，也未制作骨骼、蒙皮或行走动画。当前待机只是轻微呼吸和提灯摆动。

## 使用

- 将 `res://assets/expedition/characters/lantern_traveler.tscn` 实例化到 Godot 3D 场景即可；角色自动创建共享画风材质。
- 运行 `res://src/tools/expedition_traveler_lab.tscn` 检查三面、体积、园林比例与夜间提灯。左键转看、中键拖看、滚轮缩放；底部可以改色、开关提灯和待机。
- 若已有共享 `ExpeditionFlatStyle`，添加节点后立即调用 `setup(style)`。共享风格的拥有者负责更新相机和轮廓；独立实例会自行维护自己的轮廓。
- 资源默认整体缩放 `0.43`，当前模型源高约 `3.43`，默认世界高度约 `1.47`。原点在双脚之间的地面，正面朝 `+Z`。提灯在角色右手。

## 造型与材质

兜帽使用六边形开口、内凹暗腔和有折面的外壳；面具用折出的金色喙部、两侧尖角和朱砂镜片识别。披肩为连续十二边截面，袍摆为不规则八边体；纸符、袖口、鞋、围巾与提灯都具有几何厚度。细小符号用简单几何实现，不依赖外部字体。

当前比例按反馈收窄躯干并拉长颈部以下，整体比首版高约 6%；披肩收窄，双臂更接近自然下垂。兜帽保留原高度，灯体保留原比例，并随右手内收调整提灯位置和待机摆动支点。

主体 **1,934 个三角面**，不计相机相关的描边几何。各部位为独立网格，这个数字不等同于单次绘制调用数；当前便于改形和配色，尚未做网格合批。

`lantern_traveler_palette.tres` 可复制为其他配色。衣色、暗褶、旧布边、朱砂、骨白、旧金、皮革、暗腔和灯芯独立可调。样模沿用深青灰、朱砂和旧金，灯为参考图的红橙提灯；环境鬼火仍由原场景控制。角色接收场景方向光与点光，灯芯发光并由实际 `OmniLight3D` 照亮地面；关闭提灯光不会隐藏灯的造型。

`Body`、`HoodAndMask`、`ScarfTails`、`CarriedLantern` 是几何分组，尚不是动画骨架。下一步若制作走路，需建立关节支点、手部持灯约束及衣摆分段；正式接入还需适配现有视野暗化、人物拾取与四向朝向。
