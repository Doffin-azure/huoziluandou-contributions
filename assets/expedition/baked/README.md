# 园林运行网格缓存

`manifest.json` 记录原型键与压缩 `.scn` 的对应关系。当前版本 v3，包括墙体、柱、厅堂与连廊、桥、陈设、灯、树、莲叶、莲花及节点设施。原型可共享不可变网格；屋顶保留独立控制，灯具保留无阴影光源插槽。

运行时优先加载这些资源，常用件后台预载。随机开间或岸线组合没有预烘焙时，在分帧装配中构建一次并存入本进程缓存；奖励返回复用整个地图，不会再次构建。缓存最多保留 128 个原型引用，与只保留一张当前幕地图的界面缓存独立。

修改源模型、着色器结构或轮廓烘焙后重新生成：

```text
<godot> --headless --path . src/tools/bake_garden_assets.tscn -- --rebuild-garden
```

该工具使用两个样本种子覆盖常用开间，并补齐家具和四类碑。文件采用 Godot 的压缩二进制资源，不应手工编辑。需要增加覆盖率时可扩展工具的种子列表；更新原型结构时同时调整 `GardenMeshLibrary.REVISION` 并更新清单。

静态件在烘焙时生成结构刻线，运行中不重新计算其轮廓拓扑。墙身按八格区域与材质合并，使用独立可见性索引保留逐件迷雾；重复陈设按区域使用 MultiMesh，屋顶独立处理遮挡。实际内存与绘制指标见优化记录。
