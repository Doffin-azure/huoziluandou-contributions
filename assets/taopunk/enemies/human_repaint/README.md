# 人形立绘参考改绘

根据用户提供的角色插画参考，通过内置 imagegen 改绘有脸的人形敌人：赊墨商、拓印师、钤印官、轮印师、对校官、万词编纂者、留白童。

方向是有取舍的墨线、骨白与冷灰面部切面、大面积墨黑衣褶及朱红点色。压低原版写实皮肤、均匀纸纹与细碎皱纹，分别强调狡黠、粗粝、傲慢和阴冷等神态。原来的衣服、道具、站坐姿势和主要关节位置保留。

本目录保留参考改绘版 PNG；后续按用户要求，6 位成人角色已重构为相邻 `object_creatures/` 目录的器物形体。留白童继续使用本目录原图。`TaopunkArt.PORTRAIT_FILES` 统一决定实际贴图，`RosterEnemyActor` 从同一注册表读取。本版人形的旧活动区域作为历史实现保留。

完整提示词、编辑目标、参考图路径、尺寸及 SHA-256 在 `manifest.json`。原生对照图、整身图和动作预览在 `docs/qa/human-repaint-2026-10-20/`。
