# 人形敌人青铜覆面

此目录为历史稿。之后曾改为 `zodiac_masks/` 的生肖面具；当前按用户确认的方向使用 `object_creatures/` 的非人形器物版本。留白童使用 `human_repaint/blank_child.png`。本目录不再由这 7 位角色引用。

按用户“不要让脸出现，像墨灵一样都带上青铜面具”的要求，使用内置 imagegen 编辑 7 个人形敌人。墨灵原图 `assets/taopunk/ink_guardian.png` 是面具造型、青铜与铜绿材质的参考。

面具遮住额头到下颌，耳侧和颈部使用深色包覆，不露人眼、口鼻或胡须。保留角色原有衣服、手、道具、站坐姿势和画幅，继续由现有头部关节及动作驱动。

`human_repaint/` 及更早源图保留。`manifest.json` 记录本轮历史稿的完整提示词、编辑目标、生成来源、尺寸和校验值。对应运行截图及动作预览位于 `docs/qa/bronze-masks-2026-10-20/`。
