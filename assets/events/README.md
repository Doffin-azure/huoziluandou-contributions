# 事件插图

2026-10-14 使用内置 imagegen 分别生成三张独立插图，完整提示词记录在 [prompts.json](prompts.json)。保留工具生成的原始 PNG 和透明通道，未用整张界面图替代控件。

2026-10-18 起事件目录扩展到 37 条，其中这三条保留插图；其余事件以文字呈现。庭院抽屉会显示有 `illustration` 的事件图；未配图事件只显示文字。旧版事件页在没有 `illustration` 时自动隐藏插图区，布局不受影响。

- `ink_pool.png`：墨池遗字，林间墨池与三枚半浸没的木活字。
- `broken_stele.png`：断碑，磨平字迹的残碑、深痕与落下的碑角。
- `old_bookshop.png`：旧书肆，旧木书架、残页与将熄的油灯。

使用统一的暖墨、浅灰洗染及克制的朱砂点色，主体以轮廓和留白组织。断碑以墨池为风格参考，书肆以断碑为风格参考。图片不包含事件文字、按钮、可读字形或签名；事件标题、正文和取舍仍由原生控件绘制。

事件页按事件数据中的 `illustration` 加载相应素材；横屏插图与文案并排，窄竖屏上下排列。TextureRect 保持完整长宽比，不裁切叙事主体，不接收输入，也不使用游戏随机数选择插图。素材导入启用 mipmaps，用于手机与窗口缩放。

验证：`<godot> --path . --resolution 1280x720 --fixed-fps 30 res://tests/event_art_test.tscn -- --capture`。Godot 4.7.2 实际渲染 70 项、headless 63 项通过。实机截图写入已忽略的 `shots/`，覆盖三事件的电脑、844×390 手机横屏和 540×900 窄竖屏，以及选项收益与删字取消。测试先固定初始窗口，避免 headless 默认的虚拟窗口尺寸影响布局判断；实体手机尚未测试。
