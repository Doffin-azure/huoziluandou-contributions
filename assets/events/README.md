# 事件插图

2026-10-14 使用内置 imagegen 分别生成三张独立插图，完整提示词记录在 [prompts.json](prompts.json)。保留工具生成的原始 PNG 和透明通道，未用整张界面图替代控件。

2026-10-18 起事件目录扩展到 37 条。当前 37 条事件均有配图：前三条保留旧暖墨插图，「无字灯」为风格样板，其余 33 条按 `prompts_batch_2026-10-19.json` 用本机 ComfyUI 生成首批图，等待美术微调。旧存档缺少插画字段时，页面按事件 ID 查询当前目录补图，不重抽事件内容。

同轮新增批量美术包：

- `prompts_batch_2026-10-19.json`：33 个未配图事件的场景、种子、目标路径和统一风格/负向词。
- `art_manifest.json`：37 个事件的图片路径和状态，待生成项为 `pending`。
- `src/core/event_art.gd`：只加载真实存在的图片；图片生成后自动接入事件页和庭院事件抽屉。
- `tools/event_art_batch.py`：向本机 ComfyUI 批量提交 prompt 的脚本，支持 `--dry-run`、`--only`、`--limit`。
- 33 张首批图已生成到 `assets/events/<id>_v1.png`；manifest 状态已改为 `generated`，仍需美术审图和替换。

- `ink_pool.png`：墨池遗字，林间墨池与三枚半浸没的木活字。
- `broken_stele.png`：断碑，磨平字迹的残碑、深痕与落下的碑角。
- `old_bookshop.png`：旧书肆，旧木书架、残页与将熄的油灯。
- `lantern_riddle_v1.png`：无字灯，本地 ComfyUI / Anima 生成、BiRefNet_toonout 抠图的朱砂灯与暗青园林样板，保留透明通道。完整提示词、工作流、参考和实机图见 [样板记录](../../docs/art-concepts/2026-10-19-event-art-sample/README.md)。画风待用户评审，尚未据此批量制作。

前三张旧插图采用暖墨、浅灰洗染及克制的朱砂点色，主体以轮廓和留白组织；本轮没有重画。新样板转向当前环境参考的黑色勾线、暗青、朱砂与旧金，细节集中在主体，露天火焰采用鬼火。图片不包含事件文字、按钮、可读字形或签名；事件标题、正文和取舍仍由原生控件绘制。

事件页按事件数据中的 `illustration` 加载相应素材；横屏插图与文案并排，窄竖屏上下排列。TextureRect 保持完整长宽比，不裁切叙事主体，不接收输入，也不使用游戏随机数选择插图。素材导入启用 mipmaps，用于手机与窗口缩放。

新样板标记 `illustration_style: "scene"`，由显示层稍微柔化外框边缘；原有透明插图不应用该效果。横屏紧凑布局收起重复眉题、缩小间距，并保持选项和离开按钮至少 48 像素点击高度。

验证：`<godot> --path . --resolution 1280x720 --fixed-fps 30 res://tests/event_art_test.tscn -- --capture`。Godot 4.7.2 实际渲染 70 项、headless 63 项通过。实机截图写入已忽略的 `shots/`，覆盖三事件的电脑、844×390 手机横屏和 540×900 窄竖屏，以及选项收益与删字取消。测试先固定初始窗口，避免 headless 默认的虚拟窗口尺寸影响布局判断；实体手机尚未测试。
