# 遗物接入说明（第一批）

> 当前庭院房间地图不使用旧远征的许愿池/熔炉入口；下方“熔炉许愿”和远征商店内容只记录旧系统。当前地图的遗物入口以事件、房间奖励和后续明确接入的遗物房为准。

日期：2026-10-16。对应代码：`src/core/relics.gd`，测试：`tests/relic_test.tscn`。
设计来源：`docs/遗物设计清单_2026-10-15.md`。清单里的“待定”项，本批先取下表的默认值，可随时改。

## 接入方式

- 遗物是常驻被动，管战斗；印章管地图。两者互不占位，遗物没有数量上限，同一件不能重复拿。
- 记录在 `GameState.relics`（按获得顺序）。主线和远征都会在战斗里生效。
- 取得：只在远征里，有三个地方：
  - 随身许愿机：开局就带着，每幕一次，在地图上随时打开（字匣里要有 2 个字）；规则和熔炉许愿一样，关掉面板不算用掉。
  - 熔炉许愿：在字匣里挑 2～3 个字投进去，见下一节。
  - 商店：每家货架上 1 件。按档次定价，常见 35、少见 50、稀有 70；卖回商店拿一半价钱，卖掉以后还能再得到。
- 精英、首领的奖励和原来一样，不给遗物。
- 遗物的随机数单独一条（`Expedition.relic_rng`），不改变原有地图、赏、印章、商店的随机结果。
- 绑定类（石板、化肥）：拿到后从字袋按字形挑一枚，绑在其中一枚永久实体上。那枚字被删或被熔以后，遗物不生效，地图上的提示会写明。

## 庭院宝箱

- `treasure` 房间现在直接掉落 1 件普通池遗物，不再三选一选字。
- 普通池为空时改为金币 +30。
- 事件选项带 `"spawn":"treasure"` 时使用同一套掉落逻辑。
- 事件专属遗物不会从宝箱掉落。
- 事件选项带 `"spawn":"battle"` 时在事件房间内触发一场战斗，胜利后完成事件房间。

## 熔炉许愿

- 每件遗物有 4～6 个「相关字」，不同遗物之间可以重叠，比如【火】同时关联火种和天火。相关字都在奖励字池里，地图上拿得到。
- 投进去的字里，和某件遗物对上 1 / 2 / 3 个，熔出遗物的总概率就是 25% / 60% / 90%（看对上最多的那件）。
- 具体出哪一件，按「对上字数² ÷ 档次」加权：对上越多越容易出，越稀有越难出。已经有的遗物不会再出。
- 没熔出遗物，就照旧熔成一个稀有字。熔炉面板会实时显示总概率和前几件候选。
- 熔炉只在「熔铸坊」主题里出现，每幕 1～2 座。抽样 200 局：31% 的局一座熔炉都没有，商店每局 3～6 家。
