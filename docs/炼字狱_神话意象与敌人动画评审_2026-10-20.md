# 《炼字狱》神话意象与敌人动画评审

**实施更新：** 用户随后确认“器物成精、无需强行关联生肖”，六只现已使用 `assets/taopunk/enemies/object_creatures/` 的非人形立绘，并适配器物活动区域和特效源点；留白童保留原样。当前总览、前后对照及验证记录位于 `docs/qa/object-creatures-2026-10-20/`。下文记录的是更早的人形/生肖版评审和当时的建议。

**后续澄清：整体敌人造型优先于动作。** 用户指出主要违和感来自敌人过于接近正常人，面具仍覆盖在常规人体与职业服装上。因此，下文动画审视保留作次要记录；下一轮应先处理物种、身体构成、非人比例与小尺寸轮廓。留白童保持原样。

**《杀戮尖塔》设计参考补充**

Mega Crit 在 [2024 年 10 月官方开发通讯](https://megacrit.com/news/2024-10-02-neowsletter-issue-3/) 中解释，一代曾因小尺寸下的人形姿态难以辨认而减少人形角色；美术总监还明确将少露整张脸、怪物是否足够怪异作为风格判断。该说明支持可读性与怪异感的设计取向，不支持把它解释成普遍的行业禁忌。官方也提到游戏仍保留盗贼、奴隶贩子等人形角色。

从敌人原作图像可提炼以下视觉判断，属于本项目的设计分析：

| 参考敌人 | 可借鉴的造型方法 | 对《炼字狱》的启发 |
| --- | --- | --- |
| 邪教徒 Cultist | 鸟形头部、羽饰与罩袍形成醒目轮廓，人脸退出主要识别区域 | 少量人形可以保留，但头身比例、脸部暴露与轮廓需有鲜明取舍。 |
| 地精大块头 Gremlin Nob | 红皮、夸张上肢和巨大骨棒，使身体本身具有怪物特征 | 仅换面具不足以非人化，需同时改变比例和材质。[原作图像参考](https://unduel.com/slay-the-spire/tier-list/the-hardest-elite-fights-3tTsLpF9TOfZHEoZzKWpT3) |
| 扎人之书 Book of Stabbing | 书本、触肢与刀直接组成敌人主体 | 账册、拓片、判牍和卷轴可成为生物本身，工具与身体融合。[原作图像参考](https://cdn.unduel.com/C7611974-F4A8-4B29-8282-6568B64D654C/book-of-stabbing.webp) |
| 哨卫 Sentries | 悬浮构件与核心构成非人体结构 | 铜印、字模、铅版可构成有间隙的悬浮身躯。[图鉴参考](https://slaythespire.org/wiki/enemies/sentries) |

当前六位成人敌人仍由常规人体、古装、裸露双手和职业工具主导，生肖面具只改变了局部。建议保留“赊、拓、钤、轮、校、编”等职司，优先将身体重构为账册、碑石、空袍、滚轮、案牍或卷轴构成的异物。生肖可作为局部识别符号，不必让六只继续共享相似的古装人体。整体怪物群应包含团块、爬行、悬浮、器械、残缺人形等不同结构，避免再次统一成人物立绘队列。本轮为参考研究，未执行这组造型重做。

评审日期：2026-10-20。结论：当前敌人动画达到可运行原型的覆盖程度，尚未达到《炼字狱》应有的主题演出质量。主要缺口是角色职司、动作语义与字盘结果的联系；继续增加贴图细节不能解决这些问题。

本次检查了当前生肖版原生导出的待机、攻击、施术、受击和死亡关键帧，以及角色动作、战斗回放、攻击特效与敌人机制代码；重点样本为六位成人角色，并对照墨灵、纸壳兵、连针蜂、倾砚、折页蛾的实现。未将之前的通用兽面历史预览混作当前生肖版。不是对全部 29 位角色每个技能的完整视频逐帧验收。此次只新增评审文档，不修改玩法、动画或美术。

**可借鉴的传统意象，以及游戏中的转译**

下表左列是资料支持的传统图像或表演元素；右列是本项目的创作建议，不是对传统仪式的复原。

| 意象 | 资料中的表现 | 可用于《炼字狱》的动作 |
| --- | --- | --- |
| 冥府审判、案牍与簿籍 | 十王及属吏、书案、卷册、笔砚构成地下审判场景。[大英博物馆藏品说明](https://www.britishmuseum.org/collection/object/A_1917-1106-1) | 翻簿、点名、核验、朱批、落印；明确每一步裁定如何改变盘上的字。官吏可以少动，但落笔必须有结果。 |
| 拘魂、械具与押解 | 敦煌十王图卷有文书记录者、驱赶亡魂的执役者及枷械。[大英博物馆十王图卷](https://www.britishmuseum.org/collection/object/A_1919-0101-0-80) | 字被点名后出现墨索、套住偏旁、收进卷册；用牵引和收束表达权力。无需靠人物不断扑击。 |
| 傩仪中的面具与身体表演 | 婺源傩舞同时使用角色面具、打击乐与屈膝下沉等有明确风格的动作。[中国非遗网：婺源傩舞](https://www.ihchina.cn/Article/Index/detail?id=12892) | 重心下沉、方正持器、突然定势、再落令；面具与仪式节奏共同建立神异感。游戏铜面具是设计选择，不应据此把所有角色称作传统傩神。 |
| 敬惜字纸与焚化 | 惜字坛的字纸焚化表达对文字的尊重。[永泰县政府：敬惜字纸习俗](https://www.yongtai.gov.cn/xjwz/zwgk/zfxxgkzdgz/ggwhty/whycbh/201909/t20190906_3032976.htm) | 纸缘卷曲、墨迹变红、笔画燃尽、余烬重新聚字。把“尊字的火”改写为“炼字之火”属于原创设定；资料中的焚化并非刑罚。 |
| 造字惊鬼神 | 仓颉造字的传说有“天雨粟，鬼夜哭”。[国立台湾文学馆相关文学文章](https://tln.nmtl.gov.tw/ch/M12/nmtl_w1_m12_s1_c_1.aspx?sid=183) | 文字成形时让鬼影退缩、轮廓被笔画割开，或让字本身获得支配力；把“字”表现成有力量的实体。 |
| 十二生肖与地支 | 生肖可与地支组合，形成一套有次序的形象。[台北故宫：地支十二生肖玉佩](https://digitalarchive.npm.gov.tw/Collection/Detail/48661?dep=U) | 保留六种面具的识别轮廓；若日后做轮转、时序或殿序，可让生肖进一步服务规则。现在不必强行让所有角色做动物攻击。 |

建议的项目主线是：文字具有灵性，官吏登记和裁定它，器械封禁或炼化它，残字可被重铸。这是基于题名、现有字盘玩法和上述参考提出的创作方向，不是已经确认的剧情设定。青铜统一材质，职司决定动作，字的变化呈现结果。

**当前做得成立的部分**

角色覆盖、行动触发、伤害时序、受击与死亡入口已经接通，减少动效也有对应处理。六种生肖面具解决了轮廓重复与外露人脸的问题。

墨灵的污染演出已经有从角色蓄墨、污染字飞向实际格子、落盘的过程，这种因果关系适合继续使用。纸壳兵的关节折合、连针蜂的腹针与振翅、倾砚的倾斜和液面、折页蛾的折角与合页都围绕自身结构设计，较能表现材质与行动身份。它们值得保留并作为标准，而不是一并重做。

**当前不达标的部分**

1. **技能的含义没有充分进入动作。** 新增角色主要通过同一个 `_action_clip` 生成攻击、施术、防御和转阶段，区别集中在角度、位移和少量器物轨道。`play_action` 主要按技能种类选动作，没有按 `mechanic_action` 为钤印、朱批、异文审校、重文校印建立专属表演。编纂者不同题型和对校官的不同批示因此缺少足够明显的动作区别。参见 [动作生成](/E:/gamejam10/huoziluandou/src/battle/roster_enemy_actor.gd:189)、[动作选择](/E:/gamejam10/huoziluandou/src/battle/roster_enemy_actor.gd:252)。

2. **动作仍偏向插画微摆。** 六位成人的待机、攻击和施术关键帧之间，大体仍保持原来的手势与构图。转头、摆臂和前倾确实发生了，但持印、持笔、持卷等道具还没有充分完成明确的起势、操作和收势。官吏可以庄严静止；应让少数动作非常准确，并在对应位置造成清晰结果。

3. **字盘上的因果联系不足。** 印区、红蓝签等标记已经存在，不能说游戏没有机制反馈。但除墨灵的专门污染演出外，很多动作缺少“从哪支笔/哪枚印发出—落到哪枚字/哪个区域—何时生效”的连贯过程。直接伤害特效又经常飞向生命值控件，容易读成攻击界面。参见 [回放与墨灵特例](/E:/gamejam10/huoziluandou/src/screens/battle_screen.gd:2437)、[直接伤害轨迹](/E:/gamejam10/huoziluandou/src/screens/battle_screen.gd:2493)、[已有规则标记](/E:/gamejam10/huoziluandou/src/core/enemy_mechanics.gd:365)。

4. **动作节奏尚未体现神异权威。** 通用动作的头、双臂、衣摆经常共享同一组时间节点和类似的回摆结构。落印的重量、批字的锋利、鬼卒的顿挫、炉火的积压与爆发需要不同节奏。优先建立可读的定势、瞬间释放和余势，不建议单纯扩大整张立绘的摇晃幅度。

5. **死亡过于统一，并暴露蒙皮限制。** 六位成人主要使用下沉、倾斜和淡出的共同死亡结构。当前死亡关键帧中，对校官书案随人物一起倾斜；编纂者长卷与下摆仍能看到局部变形痕迹。整图连续蒙皮容易把本应刚性的铜面、卷轴和书案带入软变形。之前缩小施术摆幅改善了该动作，不能据此宣称死亡等所有姿势均已解决。参见 [通用死亡动作](/E:/gamejam10/huoziluandou/src/battle/roster_enemy_actor.gd:174)、[当前死亡关键帧](/E:/gamejam10/huoziluandou/docs/qa/zodiac-masks-2026-10-20/motion-death.png)。

6. **面具差异还没有完全变成角色性格。** 鼠、牛、虎、马、蛇、龙已可辨认，但动作仍应首先服务赊账、拓印、钤印、滚印、批校、编纂等职司。动物轮廓可以提示速度、重量或危险感；让所有人都扑咬会削弱“字狱官署”的特色。留白童按用户要求保持当前立绘和原有动画，本评审不将其列入面具改造范围。

此前 429 项测试的通过说明资源、事件、状态和时序符合检查条件；这些测试没有证明动作语义、重量感、主题表达或所有姿势的形体稳定性达到美术标准。

**按现有角色推进的修改优先级**

以下均为演出建议，应严格使用已结算的真实事件与目标，不新增封格、伤害、吸字或其他规则。

| 优先级 / 角色 | 现状判断 | 建议的完整动作 |
| --- | --- | --- |
| P0 钤印官 | 印与手有动作，印区却缺少强烈的裁定过程 | 举印定势→印面朝向目标→下压→真实标记区域落朱印→手腕回收。朱批应有不同动作，不能复用为同一次盖章。 |
| P0 对校官 | 笔、签、书案具备审判意象，表演仍像坐姿摆动 | 核对→笔尖一顿→红/蓝签落到真实目标字→未解签在结算时被朱线批过。书案始终刚性，死亡也与身体分离。 |
| P0 炉腹兽 | 有炉形和热度规则，现有主体鼓缩不足以说明炼字 | 炉息时余烬聚拢、炉腹积压；喷焰时炉口短促开启、火字出炉；真实注入的【热】沿轨迹进入实际空格。 |
| P1 万词编纂者 | 龙面已有首领轮廓，异文、重文、收卷的动作身份不足 | 异文：两卷展开并核对不同字形；重文：同一印迹叠合；收卷：卷轴有力闭合。仅在规则要求时影响真实字盘。 |
| P1 赊墨商 | 鼠面已区别于其他官吏，催账仍靠通用摆臂 | 翻账、拨页、伸手索取；完成既有正价支付条件时盖收讫印，催账时将账页作为演出焦点。 |
| P1 拓印师 | 牛面与工具有重量潜力，拓印过程不够完整 | 压纸→拓包按压→揭纸显印→回收。较慢起势配短促按压，利用宽脸与重心表现沉着。 |
| P1 轮印师 | 马面识别强，角色和滚轮的力学联系仍弱 | 身体后压蓄力→手臂推轴→轮面滚印→惯性制动；材质与接地点共同表现重量。 |
| P1 共通受击 / 死亡 | 同一套下沉与淡出占比高 | 铜面先保持刚性；纸体可折落、墨体可散墨、炉体可熄火，官吏可失令收卷。分别设计，不要求人人爆炸或灰飞烟灭。 |

建议先完成钤印官、对校官、炉腹兽三只样板，对应“封、判、炼”。验收时隐藏角色名称和伤害数字，检查能否从动作辨认操作、目标与落点；同时保留意图文字作为规则依据。达标后再推广至其余角色。

**验收口径**

观察者应能分清攻击、封印、防御和转阶段；印与笔要对上真实目标；刚性物体不得软化变形；起势、落点和收势应有节奏差异；小屏幕下不靠额外巨大文字遮住字盘来解释动画；跳过演出和减少动效不能改变规则或随机数。以上是建议采用的验收标准，本轮尚未实施这些改造。
