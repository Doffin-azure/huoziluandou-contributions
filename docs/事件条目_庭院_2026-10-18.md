# 庭院事件条目

以庭院房间模式为基准整理。当前目录共 37 条事件，其中“借寿 / 讨债”用【寿契】遗物牵起跨事件债务，“础石留字”发放特殊字【础】。事件数据在 `src/data/event_catalog.gd`，结算在 `src/core/event_effects.gd`；庭院与旧节点地图共用同一份目录。

## 结构约定

- 每个事件固定 **3 个收益/交易选项**；纯益事件可额外显示“空手离开”按钮。
- 代价优先使用气血、删字或污染字；金币可以作为投入或门槛，但必须先用 `gold_at_least` 检查，并用 `spend_gold` 实扣，不能出现金币不足仍白得收益。
- `acts` 决定事件出现在第几幕；庭院按当前幕过滤事件池。
- `tags` 只用于检索和文档，例如 `risk`、`curse`、`heal`、`character`、`gold`、`removal`、`max_hp`。
- 同一次庭院远征中，已出现过的事件会优先避开；本幕事件全部用完后回退到完整池。
- 新事件默认不配插图。庭院抽屉会显示有 `illustration` 的事件图；未配图事件只显示文字。旧版事件页在没有 `illustration` 时隐藏插图区。

## 收益基线

用于后续加事件时避免数值膨胀：

| 收益 | 参考成本 |
|---|---|
| 10～16 金币 | 无成本，或作为离开选项的替代 |
| 18～25 金币 | 失 5～6 气血，或附带污染字 |
| 一枚常见字 | 失 4～8 气血，或纯选择 |
| 一枚稀有字（2～3 稀有度） | 失 4～10 气血，或高额金币的替代选项 |
| 两枚常见字 | 失 5～7 气血 |
| 20%～25% 最大气血治疗 | 无成本，或与金币/字二选一 |
| 最大气血 +4 | 第三选项，不回复当前气血 |

## 新增效果与事件结构

本轮为事件补了条件、遗物和连续节点能力，均已在 `EventEffects` 与 `event_system_test` 覆盖：

- `heal_percent`：`amount` 为最大气血百分比。
- `max_hp`：`amount` 为最大气血增减；当前气血不会超过新上限。
- `borrow_life` / `repay_life_hp` / `repay_life_max_hp` / `refuse_debt`：借寿、以气血还、以最大气血还、赖账。寿债记在【寿契】的 `life_debt` 计数器里，2 点寿债可折算 1 点最大气血。
- `gain_pollution` / `remove_pollution`：加入或清除污染字卡。`remove_character` 可选 `min_rarity` / `max_rarity`，用稀有度过滤待删字。
- `gain_relic` / `remove_relic`：获得、献出遗物；随机遗物可选 `chance`，失败可给 `fallback_gold`；事件专属遗物不会进入普通遗物池。
- `spend_gold`：事件内投入金币；必须配合 `gold_at_least` 条件，避免金币不足仍能结算。
- `has_normal_relic_choice`：普通遗物池里是否还有未持有的可抽项。
- `permanent_damage_reduction`：永久减伤成长。
- `if`：根据持有字、遗物、金币、气血、临时气血、污染字数量、稀有字或普通遗物池是否还有可抽项执行不同效果。
- `nodes` + `goto`：让一个事件在多个节点之间连续推进，当前节点和待续节点会保存。
- 选项可带 `board: true`：进入璇玑字盘子流程；字盘种子、字面和目标词保存在庭院运行态中。

“借寿 / 讨债”是第一条跨事件垂直切片：借寿事件发放【寿契】并记录寿债；持有寿契时，讨债事件才会进入概率池。还清后遗物和计数器一起移除。

## 特殊字【础】

`foundation_stone` 的主要奖励：

文案取《淮南子·说林训》“山云蒸，柱础润”，以及“石敢当，镇百鬼，压灾殃”的镇宅石传统。

| 字 | id | 稀有度 | 效果 |
|---|---|---:|---|
| 础 | `chu` | 3 | 打出后选择任意空格安放；固定本场，不受重力/位移影响；每回合可使用一次 |

- 它不是普通奖励字，带 `event` 标签，不会进入普通战斗奖励、商店或随机事件字池。
- 单字效果 `anchor_self` 使用 `EMPTY_TILE` 目标，先移动原实体，再把它设为 `pinned`。
- `pinned` 字在重力、旋转、换位等位移中保持不动，可作为版面调整的“垫脚石”。
- 当前不要求它参与词谱组词。
