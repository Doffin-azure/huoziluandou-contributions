## 本地路线实测

使用本机已有的 ComfyUI、`anima-aesthetic-v1.1`、`qwen_3_06b_base` 和 `qwen_image_vae`；未下载新模型。分辨率 1024×1024，Euler / simple，30 步，CFG 4，种子 2026101901。第二次生成约 76 秒；这是本机此次测量，不是对批量速度的承诺。

第一版有过亮的浅色灯面和额外挂件；第二版改为三盏朱砂灯，作为本轮接入样板。生成底图用文本描述约束配色与线条，**没有使用图像参考编码器或风格 LoRA**，因此不能据此认为几十张事件已经能稳定保持同一画风。另用已有的 BiRefNet_toonout 做本地透明背景处理。

- `lantern_riddle_anima_v2.api.json`：第二次底图生成的 API 工作流。
- `lantern_riddle_cutout.api.json`：抠图工作流。
- `lantern_riddle_complete.api.json`：串接生成与抠图的完整 API 工作流；两个阶段已分别实跑。
- `lantern_riddle_comfyui.json`：可在 ComfyUI 中打开的完整工作流，同时保留底图与抠图输出。
- `generation.json`：模型、提示词、选中版本和文件校验记录。

本机工作流目录中也保存了 `Lianziyu/lantern_riddle_sample_v1.json`。

## 给网页版的单张任务草案

先确认这张样板的方向，再整理完整批量美术包。本目录已备好参考、提示词、原始图与实机截图，可作为交接基础；尚未向任何网页服务提交。

**用途：**《炼字狱》事件「无字灯」的独立插画。交付一张 1024×1024 或更大的 PNG；人物、UI、文字、标题和选项均由游戏绘制。

**叙事：**冥府园林的廊檐下悬着三盏无字灯，灯里藏着谜题。主体为三盏灯、廊檐和少量池岸，辅以一簇鬼火、零星红叶。不画谜底、奖励图标、可读字形或伪书法。

**统一标准：**以 [环境参考](references/taopunk-courtyard.png) 的黑色勾线、暗青建筑、朱砂点色和旧金器件为依据，以 [当前庭院](references/current-courtyard.png) 检查在实际背景中的协调度。主体轮廓清楚，线条有轻微手绘变化；色块分明，控制在两到三层阴影。细节集中在铜帽、檐角等局部，避免整体堆砌花纹。允许轻微旧印刷颗粒，避免大面积水墨洗染、照片、塑料高光、写实 3D 或现代卡通图标感。

**色板：**环境 `#10262F` / `#18333B`，朱砂 `#BD5143`，旧金 `#C6AA70`，纸白 `#E6D8B6`。露天火焰为少量低饱和冷色鬼火；灯内暖光面积受控。

**构图与连接：**主体约占画幅中央 70%～85%，四边留余地，三盏灯大小与悬挂高度略有变化，保持各自完整且可数。绳索、挂钩、檐梁的连接要成立，黑线不能被抠图吃掉；在约 300 像素宽时仍能看清主要形状。透明区域保留干净边缘，不留实心黑矩形或白边。当前本地模型对悬挂结构、精细材质和批量一致性的控制仍需人工审图。

## 接入与验证

事件数据使用 `illustration` 指向图片；`illustration_style: "scene"` 只启用显示层的边缘柔化。旧存档缺少插画字段时，页面按稳定事件 ID 查当前目录补图，不重抽题目或奖励。

`tests/event_illustration_sample.tscn` 实机 21 项检查通过：真实页面、三个横屏尺寸、触控尺寸、离开按钮可见、谜面不泄露奖励、前三张旧插图保留原显示方式、旧存档补图和一次性结算。实机截图来自 Godot Compatibility 渲染器；横屏窗口检查不能替代安卓实机验收。
