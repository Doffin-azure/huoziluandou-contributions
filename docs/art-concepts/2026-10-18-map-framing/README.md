# 紧凑院落、近景取景与庭园舆图

这轮处理三个具体问题：院落间距过大，3D 镜头缩远后只剩黑色细线，以及游戏画幅与窗口／编辑器预览的关系不清。

## 地图与镜头

- 空间布局独立于玩法随机数。主分叉段从原来的 60–66 单位收至 42–46，三路横向汇合后的转弯留 6 单位缓冲；支路间距从 18 收至 11。起点与开场两院的中心间距从 12 收至 9，首领前间距从 14 收至 11。保留原来的路线拓扑、随机房型与内容种子。
- 默认近景按当前院落的实际边界、建筑高度、窗口比例和操作面板占用面积计算取景距离；人物在院内时只轻微带动镜头，走到桥上后正常跟随。
- 滚轮缩放限制为默认取景的 0.72–1.4 倍，保留中键拖看，不再将小模型缩到 180 的距离。
- “总览”改为独立绘制的庭园舆图。沿用真实房间、桥路坐标，自动适应窗口；当前庭院、已走路线、未知房间和封闭分支有不同标识。点击可达院落继续正常行走，滚轮向上或 Esc 返回近景。总览暂停详细 3D 视口绘制。
- 水面延伸超出导航边界，消除镜头边角处的硬切边；未探索水面与地面使用一致的深色迷雾。遮挡判断补充腿部与头部射线，避免只看见头、身体被门檐遮住。

## 屏幕与交互

- 地图 Control 铺满游戏窗口。3D 视口按实际显示像素渲染，大窗口不再放大一张逻辑分辨率的纹理；小窗口相应降低渲染尺寸。
- 世界投影统一换回逻辑 UI 坐标，点击射线统一换到渲染像素坐标；拖动、缩放和屏幕像素密度变化后仍使用同一个换算边界。
- 操作面板按内容收缩。横屏收在右上角，近景取景避开面板；窄高窗口将面板移至下方。总览隐藏操作面板，日志不常驻显示。
- 旧版保存的宽松空间布局在恢复时迁移至紧凑布局；保留房间种子、字袋、金币、选择和房间内容，人物回到当前院落的安全站位。迁移不覆盖其他房间进度。

## Godot 嵌入预览

用户截图的外围灰色是编辑器的嵌入游戏工作区，内部仍以 `--resolution 1440x810` 固定尺寸运行。该模式的固定画幅由编辑器控制，不能由游戏内的地图控件撑开。

在编辑器 **Game 页右上角下拉菜单**中，将 **Fixed Size** 改为 **Stretch to Fit**，然后停止并重新运行。若希望预览严格保持原比例，可选择 **Keep Aspect Ratio**。未修改用户的全局编辑器偏好。

依据：[Godot 4.7 — Game embedding / Embedded window sizing](https://docs.godotengine.org/en/4.7/tutorials/editor/game_embedding.html)。

- 限制缩放后重新检查取景；各尺寸下世界投影与地面射线交点一致。
- 舆图全房间位于画幅内，显示和点击使用同一转换；总览关闭 3D 持续渲染。
