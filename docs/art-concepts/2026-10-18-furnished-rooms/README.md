## 布置规则

- 房间在最终门位确定后再处理装饰，门内通路、门框和交互站位拥有优先权。转弯汇合改变入口方向时，重叠的可选内设会省略；主设施和敌人保留。
- 同一套房间数据同时生成可见模型与寻路障碍。柜、桌、石、树根和柱凳均参与避让，树冠与屋顶允许上方悬挑。
- 新方亭能正常走入。步行与鼠标拾取共享亭内石台、石阶的高度；没有把亭台抬高后仍让人物贴着原地面行走。
- 新屋顶、阁楼、洞石、字架和树冠纳入局部遮挡淡化。树冠淡化只影响叶片及其描边，树干保持原状。
- 未探索房间的新内设整件隐藏；服务、宝匣和敌人继续沿用原本的使用／清理状态。
- 布置是房间用途和门位决定的静态数据，不消耗游戏随机数，也没有给装饰家具增加额外交互。

## 新家具

补充了石桌双凳、书案、石长凳、铜香炉、荷花缸、字架六件原生模型。场景在 `res://assets/expedition/garden/`：

`stone_table.tscn`、`writing_desk.tscn`、`stone_bench.tscn`、`incense_burner.tscn`、`lotus_tub.tscn`、`type_rack.tscn`。

这些家具与上一批亭阁、树木一样使用世界单位，场景根缩放为 1，接受共享色板及实际灯光、阴影。荷缸复用原荷花模型；香炉没有新增粒子、烟雾或额外光源。

## 实现入口

- `src/expedition/room_template_catalog.gd`：八类房间的成组内设与门位避让。
- `src/expedition/room_interior_assets.gd`：新模型的占地、障碍、视觉高度与亭台地面。
- `src/map/garden_room_furnishings.gd`：六件新家具的原生几何。
- `src/map/garden_room_visual.gd`：实际房间装配、状态与遮挡。
- `src/tools/garden_furnished_rooms_lab.tscn`：与地图共用渲染器的房间工作台。

运行工作台可查看八类房间、门位变体、通行带和已使用状态；运行实际游戏继续庭院路线即可看到本批内设。旧存档会按原来的图和进度重建房间；若原站位被新增实体占用，会回到当前房间安全站位。

本次只改庭院路线模式，没有改变旧 12×8 远征模式的内设。尚在运行的游戏需要停止后重新运行，才能完整加载新场景脚本。
