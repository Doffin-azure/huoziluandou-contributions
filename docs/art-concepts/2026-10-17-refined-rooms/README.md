# 房间细化：完整墙院与开放水榭

本次解决房间边界逐边随意换用墙、栏杆的问题，并细化八类房间的内部落位。成果已进入 `codex/courtyard-room-map` 的随机房间地图，工作台与游戏实例化同一个 `GardenRoomVisual`，没有两套布局代码。

## 围合与构图

| 房间 | 尺寸 | 围合与内部组织 |
| --- | --- | --- |
| 起点：照壁门院 | 4×4 | 四面院墙、单月门；后照壁、侧字柜与箱匣、角部松石植床 |
| 事件：问碑小院 | 5×4 | 完整漏窗墙；碑龛立于石座，松石收于角落，月门折景 |
| 休息：息灯水榭 | 5×5 | 四面同款连续栏杆；开放瓦顶水榭、侧凳、鬼火、荷景 |
| 普通战：廊围石庭 | 6×5 | 完整墙院、西侧游廊、角部植床；中央保留空庭 |
| 精英：镇碑夹庭 | 7×6 | 兽面门与漏窗墙；高低碑组成两翼，碑座和松石明确落地 |
| 首领：墨渊终庭 | 9×7 | 完整大院、兽面门、成对碑座与鬼火；中轴铺装与仪式庭留白 |
| 宝藏：荷池藏榭 | 4×4 | 连续栏杆围台、开放入口；宝匣置于一座完整屋顶下，两侧可绕行 |
| 商店：青铜字肆 | 6×5 | 完整墙院；字摊靠后、字柜与箱匣靠侧，松石集中于角落 |

水边仍可有院墙，水的位置不再决定墙的种类。开放水榭不再嵌入孤立月门墙片，入口用两根同款栏端柱收口，开口宽 1 单位，与桥路对齐。生成器调整门位后会重新应用整个房间的围合约束。

铺装边带直接写入原有石地着色器，碑座抬高对应碑体；不叠加共面的地板。刻字共用同一铺装参数，避免刻字周围出现异色方片。

## 局部遮挡

删除“当前房间南／东两面完整墙换成矮墙”的逻辑。保留全部院墙与原高；缓存墙段、门和屋顶的世界空间包围盒，按真实相机到人物的射线判断遮挡，仅让人物附近实际遮挡的部件半透明。开放水榭的屋顶独立淡化，柱、梁、侧凳仍保留。地图按约 0.12 秒更新，兼容房间旋转、拖镜与缩放。
