# 廊桥地台衔接修复

原来游廊的生产缩放为 0.6，地板顶部局部 y=0.17，却通过实例偏移 −0.102 压回世界 y=0；桥面也直接位于 y=0。普通地形继续铺在同一个高度，桥头与廊下出现共面闪烁和三角形穿插斑块，基座厚度也被埋掉。

现在普通地面保持 y=0，廊桥上表面为 y=0.07。游廊保留可见台基，前方加 0.24 格长的石坡；桥两端各加 0.18 格长的石坡，接回普通地面。下方地形作为基础保留，表面不再与地台共面。新增坡面复用现有石材和轮廓材质，未增加灯光。

`garden_asset_layout.gd` 统一登记生产高度、坡面平面和占地；组装、人物落脚、首领移动、格子投影、射线拾取及地面提示从同一份表面定义取值。动画经过坡面时连续采样高度，切换地图前停止旧实例的动画。

桥和游廊的避让范围包含新增石坡。潮汐渠备用种子 3770554 在新净空范围下未通过完整生成校验，替换为验证有效的 5132031；回归检查扩展到全部 13 个备用种子。
