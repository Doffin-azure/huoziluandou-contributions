# 横向分叉节点图

主入口已切换为二维节点图，保留最早行旅界面的深青、旧金、朱印与字体。背景使用静态庭院图，地图没有 3D 视口、建筑装配、行走相机或探索迷雾。

## 推进与信息

- 每幕 55 个候选节点：15 列各 3～4 个节点，加起点与首领。实际选择一条路线前进 16 站，另含起点。
- 始终从左往右；全部类型和连线公开。选择下一站并确认后进入对应页面，不能返回、补走同列或领取另一条路线的奖励。
- 普通浏览时点选节点，再点“前往”只执行下一站；开启“预选模式”后，从左到右逐站规划，候选亮起并以红圈标记。点最后一站撤回，点更早的站截断后续计划；退出预选后查看已选节点不改变计划。计划随存档保存。
- 去掉常驻的候选数量、规则说明、图例、节点介绍和整条底栏。地图只公开节点类型和连接，不提前展示具体怪物、气血与奖励；“前往”及浏览操作以角落按钮呈现。
- 一键切换近览与全图，拖动与滚轮用于浏览。浏览位置在进入节点和返回时保留，打开字袋不改变地图位置。
- 新玩家仅第一次看到短提示，开始规划后收起并记住。窗口缩小后重新计算文字与触控尺寸，横屏按钮保持至少 48 个物理像素高。
- 每条路线包含 3～5 次奇遇；其余含普通战、精英选择、商店、休息、宝藏与幕末首领。

## 结算接线

复用既有冒险控制器及完整事件、商店、休息、奖励页面，不重新实现故事效果。支持连续事件、删字选择、灯谜、射覆、璇玑字盘，以及事件附带的战斗和宝藏。

战后奖励择一枚字直接收入字袋；跳过给 16 铜钱。商店刷新花费 5 铜钱，保存刷新后的库存并保留尚未购买的服务。精英先发一件遗物；第一、二幕首领回复 30% 最大气血并提供遗物二选一。遗物候选随存档保存，读档不重复发放或回血。宝藏显示领取说明，需要绑定的遗物继续使用选字浮层。

普通战与精英沿用同步后的三幕前／中／深区怪物池；数值读取现有 Excel 导入资源，不额外增加生命倍率。事件战斗同样使用新怪物目录。

## 存档、入口与保留内容

标题的开始、继续、自定义构筑使用二维节点图。继续旧存档时保留其节点关系、已选分支、字袋实体、遗物、事件与待领奖状态，仅迁移显示，不重抽新地图。新一幕使用新版节点生成器。

冒险已移除字匣与 2×2 版面构筑，以及版面提供的开场、经济和额外奖励加成。旧存档暂存于字匣和版面上的字会转回字袋；新存档不再保存这些字段。

AI 驱动保持 `mode: "courtyard"` 兼容入口，未指定布局时采用 `layout: "node_graph"`。`observe()` 包含整幕节点及连接、放弃状态、当前候选和预选路线；`enter_room` 直接进入下一节点，不再寻找实体道路。

3D 资产与程序化模型保留；旧地图屏幕保存在 `src/screens/room_map_3d_screen.gd`，不作为当前主入口。经典八节点界面和旧远征入口仍保留，历史 3D 展示工具本轮不继续维护。

已合并当前主线的路线预选模式、遗物图鉴、【加流】及遗物和事件数值更新，UI 精简、铜钱文案和事件配图一并接入主线。

- `node_route_test.tscn`：196 项通过。40 个种子验证候选数量、向前连通、无交叉、每条路线事件数；覆盖预选、禁止回头、跳过奖励、商店刷新、首领遗物、跨幕、二维存档及旧存档迁移。
- `node_route_runtime.tscn`：29 项通过；包含逐站预选、只读查看、不提前展示怪物、不改变图形位置、手机横屏触控尺寸、真实战斗入口、战后择字、事件删字、字肆刷新、休息和宝藏，节点返回复用同一二维地图实例。截图来自 Forward+ 渲染器实机运行。

- 推送前补检：战斗界面 58 项、字网图谱 34 项、标题菜单 16 项、词条解释 29 项、Buff 与解释布局 16 项通过。修复配置覆盖丢失词条边界说明、Buff 实际高度超过预留区域和词条浮层未避让状态栏的问题。
- 检查 1280×720、1920×1080、1600×720；未进行安卓实机性能验收。
