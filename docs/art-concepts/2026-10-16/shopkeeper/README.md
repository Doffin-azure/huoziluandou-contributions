# 店主画法校准

原低多边形店主与既有怪物的墨线插画不一致，本次替换为参考纸卫、锈笔画法制作的独立透明店主立绘，保留 3D 柜台及原有交互。

- [替换前](before.png)
- [桌面实机](desktop.png)
- [手机横屏实机](phone.png)

插画用 Sprite3D 放入场景，商品、印台与柜台自然遮挡人物；没有用全屏贴图覆盖游戏。素材路径：`assets/characters/shopkeeper/portrait.png`，内置 ImageGen 生成；完整提示词与参考记录在同目录 README 中。

Godot 4.7.2 原生 `object_stage_test` 截图模式：22 通过 / 0 失败，错误日志为空。图片均为实机原图。此轮仅更换人物呈现并补桌面截图记录，未修改敌人素材、价格、奖励和购买规则。未提交或推送。
