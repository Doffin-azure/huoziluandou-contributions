## 接入范围与原因

当前标题分支基于包含远征与后续词效的主线；之前青铜绘卷战斗表现留在 `feat/study-battle-ui` 的 `05579cc`，因此只有标题及行旅页换了风格，战斗仍走旧书房和宣纸表现。

本次从该分支恢复 `assets/taopunk/` 中的运行素材、表现脚本和相关测试，按函数接入当前 `battle_screen.gd`。恢复青铜框、纸面、独立怪物立绘、墨灵骨骼攻击 / 污染动作和其余八只的独立攻击姿势；字盘保留真实 3D 表现和投影交互。未重新生成或修改敌人图片。

原来的 `src/core/`、远征和数据资源没有改动。当前选区、出词、投放、精炼、结束回合及战后路线等十个函数与接入前逐字对照一致；字盘保留当前的目标排除、多选与防点击穿透逻辑。词效预览仍使用 EffectText 的完整词效和嵌套说明，未用旧分支的文本实现覆盖它们。

Settings 默认采用 `taopunk`。旧 `style=paper` 不覆盖新默认；玩家在新版明确选择的 `art_style` 继续有效。战斗中切换风格在离开后生效，避免重建战斗或重抽随机内容。字盘自定义字体入口恢复，字体切换不重建战斗。

正常入口由 Router 连接：标题庭院 → 行旅地图 → 青铜绘卷战斗。战斗时停用隐藏书房的 3D 渲染；没有 StudyStage 的独立入口也提供绘卷背景。
