# 状态可读性与敌人画法审视

## 状态修正

旧状态栏使用深色图形、透明底，原先适合宣纸；青铜绘卷把玩家状态放到场景上，产生对比度不足。本次仅在 taopunk 风格中给状态加不透明深墨底牌与细旧金边，图形使用米白 / 浅朱砂 / 旧金，计数仍为浅底深字。悬停、按下、键盘焦点均适配此表面。血条端点的两种防御增加旧金轮廓，保持内侧双线区分持久盾。

- [桌面实机](status-desktop.png)
- [手机实机](status-phone.png)
- `intent_design_test` 原生截图模式：54 通过 / 0 失败，错误日志为空。包括状态三色范围、图形与不透明底牌至少 4.5:1 的对比度、真实点击详情、输入隔离及 RNG 不变。

纸面上的意图和资源仍采用深色图形。没有全局替换 BattleSymbol 的颜色，避免修好场景状态却破坏纸面可读性。

## 敌人差距：美术观察

[同一显示框下的九只实际待机角色](enemy-comparison.png)。图由 Godot 的 InkSpirit / InkGuardianActor / EnemyAttackActor 原生渲染，使用相同显示区域、背景和截图时刻，保留当前运行时的裁切及缩放；未编辑图片素材。

| 项目 | 墨灵 | 其他敌人中较明显的问题 |
|---|---|---|
| 焦点 | 面具为集中的金色亮面，额心红点和眼睛形成聚焦 | 铜印的脸、印面、尾部、爪子都抢亮；混铅海眼睛偏小，巨口周围细节分散注意 |
| 大形 | 背环围住头脸，披风提供宽阔暗面，红带引导视线 | 铁画和纸卫细长尖角多；字魔的黑色身体与内部空洞在暗背景中分离不足 |
| 明暗与色块 | 大片墨青压住细节，旧金集中，红色主要沿飘带展开 | 铜印、铅版、混铅海的磨损亮边覆盖大量表面，局部反差反复出现；焦火的高饱和火焰占比较大 |
| 材质画法 | 面具硬边、布褶、青铜结构具有不同的线条与细节密度 | 不少角色把纸、金属、石面都处理成密集裂纹或尖锐折面，材质关系与场景的平涂分区不一致 |
| 上屏分量 | 半身像铺满并裁切到显示框 | 全身像还要容纳完整攻击姿势的共同边界，头脸缩小；姿势越展开，待机越显小 |

纸卫和锈笔已有各自明确的大轮廓，问题并非所有角色一模一样；但当前一批素材缺少与墨灵一致的焦点和细节分配标准。墨灵本身也有不少装饰，它好看的关键是复杂细节依附于清楚的大形，并有整块暗面承托。继续往其他角色上增加纹理不会补齐这个差距。

## 代码确认的显示差异

- 全部运行角色 PNG 均为 1402×1122；墨灵与其他角色的质量差距不能简单归因为源图像素尺寸不同。
- `InkSpirit.portrait_rect()` 对墨灵使用 cover，允许半身像底部和两侧裁切；其他静态立绘使用 contain。
- 其余八只启用 EnemyAttackActor 时，`_fit_actor()` 按所有攻击关键姿势的共同包围盒缩放，再绘制待机图。该策略避免动作裁切，但把待机视觉分量也一并缩小。
- 本次同尺寸框中，其他角色的待机矩形宽度占框宽约 52%～73%；墨灵宽度覆盖 100%，高度超出框后裁切。数据见 [实际测量 JSON](enemy-comparison.json)。这些是当前运行代码的测量，不是对绘画质量的评分。

## 后续校准标准

先分别制定每只角色的待机视觉分量与攻击留白；动画可以使用不同的显示安全区域，不能直接用所有动作的最大包围盒决定待机大小。缩放调整须同时检验攻击不裁切、脚底和头部锚点不跳动。

美术按墨灵的原则逐只校准：一个主要焦点、少量大色块、安静区域、只在结构需要处保留磨损。铜印先收敛满身高光，铅版先设计首领级的主轮廓与压印焦点，混铅海先组织巨口与眼睛的阅读顺序。保留各自身份，不照搬墨灵的面具、背环和披风。

仅换调色或再次降噪无法解决构型、焦点与裁切差异。本轮保留所有敌人原图，完成状态修复及实际对照分析。

复现：`godot --path . res://src/tools/enemy_visual_audit.tscn`，输出到忽略目录 `shots/`。工具只读取角色素材，不创建战斗状态或消耗游戏随机数。
