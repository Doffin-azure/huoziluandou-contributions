## 这版解决什么

当前路线只有三层平行支路：`fork → merge → fork → merge`，每条支路都是线性的，所以玩家感觉“只有一层支路”。

这版改成：

- **5 个主决策点**：F1、F3、F5 以及两个内嵌决策 F2、F4
- **2 个内嵌分叉**：F2 在东线折桂厅内，F4 在藏字水榭内
- 21 个节点，仍沿用主园的建筑位置，不重排整张园林
- 决策点不是专门围出来的房间，而是主园里的真实院门/廊口
- 两条支路都能在图上提前看到；当前计划用橙色实线，未选与内嵌支路用虚线

## 怎么避免 U 形

这版不是对称 U 形：

- F1 的东线内部再分 F2，西线保持线性，两条支路长度不同。
- F2 在折桂厅内部；先合到真经阁，再沿碑堂一侧汇入 F1 的主汇合。
- F3 的两条支路分别从听雨书屋和问字轩进入，汇合点在后殿前庭，不是正对分叉口。
- F4 藏在藏字水榭内部，用南廊 / 夹院两个小院完成分叉。
- F5 利用南岸山石林木分成听石轩和南岸两条不同方向的末段，最后一起进后殿。

## 临时改选

规则：

- 进入支路后、完成该支路第一间房前，可以退回决策点改走另一支。
- 完成支路第一间房后提交该分支，封另一支的两端。
- 已领取的奖励不回滚，已解决房间不重置。
- 计划路线只负责显示，不提前封印；封印发生在第一间房完成时。
