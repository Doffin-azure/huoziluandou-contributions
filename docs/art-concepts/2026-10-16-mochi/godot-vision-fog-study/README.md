## 三种状态

| 玩法状态 | 地图表现 |
|---|---|
| 未探索 | 不透明墨雾遮住地形信息，建筑、散字、敌人不实例化；体积雾补充边缘厚度 |
| 曾探索、当前看不见 | 保留已知地形和静态设施，暗化并关闭局部灯光，薄雾覆盖 |
| 当前可见 | 散雾，正常显示地面、字、设施、敌人与局部灯光 |

范围完全读取 `Expedition.visible` 和 `Expedition.explored`。沿可走路线的视野、看见墙的一圈、“开灯”“夜灯”“左右”及情报揭示沿用现有规则，不另设人物周围的圆形可视区域。镜头平移、缩放不会改变探索或视野。

信标继续只显示隔雾标记，不提前显示实际建筑。已通过情报揭示的伏兵使用隔雾标记显示。未发现的沉睡首领隐藏，不泄露巢穴位置；追逐中的方向与距离警告保留，实体进入当前视野才显示，路线只画在已探索区域。

## 实现入口

- `src/map/expedition_terrain.gd`：同一张RG遮罩保存历史探索与当前视野。
- `src/shaders/expedition_sight_veil.gdshader`：连续不透明遮蔽层，避免雾较薄或不支持体积雾时透出未知岸线。
- `src/shaders/expedition_low_mist.gdshader`：根据玩法遮罩决定浓雾、薄雾或散雾，不再按墨河位置或人物距离制造装饰性雾。
- `src/map/expedition_map_view.gd`：隐藏未知物件、更新记忆区暗化、隔雾标记与首领表现。

相机位置只用于避免前景雾墙挡住已经可见的地面，不参与视野计算。动画噪声只改变墨雾纹理，不会在未知区域随机开洞。紫灰夜色、分格石地、地板大字、暖灯和蓝紫鬼火沿用上一轮表现。
