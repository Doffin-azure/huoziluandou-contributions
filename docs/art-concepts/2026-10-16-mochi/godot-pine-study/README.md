# 冥府怪松 · 单体风格修订

2026-10-16。用户明确地图属于地府、冥府碑林，树的方向应接近怪松。此前圆簇红叶的单体被否定；本轮重新绘制造型与针叶，并放回原碑院小样检查。

## 当前约束

- **形态**：横斜、扭曲的主干，外露根部，枯折枝，疏密不齐的针叶。枝条之间保留大块负形，让骨架先成立。
- **配色**：树皮以灰青、枯褐为主，针叶用低饱和墨绿，亮面为少量灰青。与碑石、冥河和青铜建筑共用明暗层级。
- **线条**：主干外缘与枯折处较重，树皮裂线断续且收尖，针叶笔线更细。单树轮廓可独立调节，避免整体变成均匀粗黑边。
- **接地**：根部落在不规则石岸上；单体取消方形展台。石块仍使用场景的建筑材质与投影。

## 打开与调整

打开 `res://src/tools/expedition_tree_lab.tscn`，按F6。

可以切换外轮廓、内部笔线，调整线宽、树皮、针叶、亮面和墨线颜色；滚轮查看不同尺寸。运行时调整使用配色副本，不覆盖默认资源。

碑院场景 `res://src/tools/expedition_atmosphere_lab.tscn` 已使用新的怪松组件。仍是独立美术样板，未替换正式远征地图。

## 实现与检查

`src/map/expedition_tree_drawing.gd` 保存可编辑的轮廓、分色、裂纹和针叶扇簇；`expedition_stylized_tree.gd` 将它们绘制成有前后层次的平面网格，根部石岸为简化立体几何。墨线使用单独的屏幕线宽着色器，细线在端点收尖；配色位于共享调色板的Tree分组。

Godot 4.7.2 Forward+实机导出完成，错误日志为空；可见墨线采样、原始预设保护、玩法随机数隔离及九格拾取检查通过。本轮用于修正树的题材、配色与线条方向，绘画完成度继续以实际场景审视。
