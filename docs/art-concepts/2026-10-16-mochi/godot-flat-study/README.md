# Godot · 3×3平涂与描线样板

2026-10-16。在真实Godot 3D视口中验证SVG小样的色块与轮廓表现，并检查已有模型的复用方式。

后续已在同一场景加入 [火焰与局部光影小样](../godot-fire-study/README.md)。下方图片保留加入火光前的版本；运行当前场景时，可使用“点火”开关比较。

## 打开

在项目中打开 `res://src/tools/expedition_style_lab.tscn`，按F6运行当前场景。

也可运行：

```powershell
& 'D:/Apps/Godot/Godot_v4.7.2-stable_win64_console.exe' --path 'D:/Projects/Games/GameProject/huoziluandou' --scene res://src/tools/expedition_style_lab.tscn
```

控件支持：

- 左键点击石地，把字匣放到对应格；中键拖看，滚轮缩放，复位按钮恢复镜头和字匣。
- 切换字匣／旧闸门，验证同一套画法用于不同几何。
- 关闭“平涂描线”，对照同一份模型的普通材质表现。
- 打开“对齐线”，检查地面与物件方向。
- 打开“轻透视”，观察拖看时不同高度的相对位移。默认平行投影对照SVG；平行投影下单纯平移镜头不会产生深度视差。
- 点击拾色器调节背景、石面、箱身、箱盖、锁扣与描线；线宽可单独调整。提供墨绿、灰青两份配色。
- “保存配色”写入 `user://expedition_flat_palette.tres`；“截图”写入 `user://expedition_style_lab.png`。启动时复制项目配色，试调不会覆盖项目资源。

## 实际复用与新增内容

字匣、地面和锁扣沿用项目 `TypeMeshes.beveled_box` 的倒角几何生成。箱身在原网格上做少量收底变形，调整比例，保留原有建模方式。旧闸门直接调用 `ExpeditionMapProps.mechanism`，再覆盖材质和添加轮廓；切换画法不会重新制作或替换它的模型。

本次没有导入现成图片、调用生图或重新绘制多个角度。后续复杂设施可以采用合适的外部模型；平涂与轮廓模块接收已有三角网格。

表现分为三部分：

1. `expedition_flat_palette.gd`：可编辑Godot资源，集中管理面色、强调色、描线颜色及线宽；两份预设位于 `assets/expedition/palettes/`。
2. `expedition_flat_style.gd`：把已有模型套用到同一套表现，缓存几何边信息与共享材质。调色只更新材质参数，保留模型。
3. 两个着色器：面色着色器按面朝向分配平涂色；轮廓着色器将真实3D轮廓边绘成固定像素宽度、经过深度测试的线。没有把整件物体压成静态图片。

轮廓从相邻面的可见性确定，镜头或物件移动后刷新。这里采用CPU更新轮廓边，适合先验证画法；扩展到完整地图前应检查轮廓更新次数、裁剪与性能。

## 自检与范围

验证结果：Godot 4.7.2，Forward+／Vulkan，RTX 4060 Laptop GPU；原生视口检查29项通过、0失败。覆盖真实3D几何、三个位置的投影对齐、实际输入摆放、即时调色、配色保存重载、同模型材质切换、旧机关复用、轻透视视差、两种分辨率及像素线宽。

这版说明已有3D结构可以采用接近SVG的平涂表现，减少逐件绘图、投影适配与改色的重复工作。旧闸门仍是功能原型，形体比例需要继续设计；统一材质不能自动完成造型打磨或《九日》式手绘完成度。

本次为独立样板，尚未替换12×8远征地图、战斗界面或玩法数据。连续地形生成器与原地图资产保持原样，待此处画法确认后再逐步接入。
