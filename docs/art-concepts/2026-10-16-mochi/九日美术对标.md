## 转译到本项目的美术约束

以下为本项目的设计分析和建议，不是对《九日》制作管线的断言。

| 方面 | 本项目应采用的处理 |
|---|---|
| 线条 | 外轮廓明确，内部结构线有主次；细密雕刻集中在重要部位，保留大块安静色面 |
| 明暗 | 以绘制好的分色和阴影决定体积；材质光泽、立片阴影与地面处于同一套绘画逻辑 |
| 世界造型 | 仪式与设备共同构成设施结构。活字、印章、碑刻参与机械功能和空间组织 |
| 材质 | 石、铜、木、纸通过色面和选择性的笔触区分；磨损服务于结构，控制全屏碎纹与高光密度 |
| 色彩 | 每个区域建立主体色与强调色，并统一明度层级。四主题可有不同色相，角色与交互目标保持清楚 |
| 场景构成 | 前景形成框景，中景承载通行与交互，远景通过较弱对比退后；建筑、岸线和植物构成连续环境 |
| 空间表现 | 将上述手绘语言用于本项目的斜俯视地图；分层、遮挡与轻微视差提供深度，不以模型体积替代绘制完成度 |
| 界面 | 以用户上传战斗图的构图与信息需求为依据，统一纸面、字形、结构边框和强调色；地图侧栏也属于整屏美术的一部分 |

例如，字摊可以使用木质活字匣、青铜机械连接件、字模输送结构与少量朱砂导能纹，共同表达“印字设施”。持灯行者、冥府碑林与汉字题材继续保留。

## 当前版本的处理结论

现有地图是空间与交互原型，不能作为已经定稿的视觉基准。模型转成立片解决了部分空间表达问题，尚未解决整屏美术统一。

用户进一步明确工作顺序：先生成少量素材，实际组合成3×3预览，讨论小样后再扩展。最初的 [3×3纹理小样](tile-study-3x3/README.md) 把重点放在地砖与水面，细节过多，也没有验证物件融入环境。

随后制作的 [字匣与地面组合小样](prop-integration-3x3/README.md) 仍未达到要求：生成箱子的细节过多，内部透视与地面没有真正对齐。整张图的缩放和平移无法解决各个面的投影差异，该版保留为过程记录。

当前改用 [共用投影的3×3小样](projection-study-3x3/README.md)。地面与箱体各面从同一组空间坐标绘制，先保留纯色面、箱盖缝和一个锁扣，验证投影与简化画法，不再逐件调用生图制作这处样板。数学对齐与绘画风格分别评价，不能把几何正确等同于完成了《九日》式手绘美术。复杂设施可以使用现成模型作为结构来源，再统一绘制表现。

在此基础上增加 [Godot原生3×3平涂样板](godot-flat-study/README.md)：复用项目的倒角网格及旧闸门模型，在实际3D视口中应用共享面色、轮廓与可编辑调色板。默认平行投影与SVG比较，另可切换轻透视检查空间位移。先以这处实机样板验证渲染方式，不直接替换整张地图。

进一步加入 [火焰与局部光影样板](godot-fire-study/README.md)：用三层曲线色块、局部暖色受光、克制柔光与箱子落地投影，检查火光能否与平涂画法共存。光源和配色可调，保留实机点火／熄火短片；仍限定在单火源3×3样板中。

随后补充 [地图机关字与镶字美术评估](地图机关字与镶字美术评估.md) 及 [原生镶字地砖样板](godot-glyph-study/README.md)：梳理8个主题机关，要求功能地块保留贴地汉字，并以浅渠高低水位、低闸与固定铭牌验证状态表达。灼、镇、渡作为换字候选仅在小样展示，尚未改动远征机制。

本轮在同一3×3地面外围增加 [冥河碑院配色与建筑样板](godot-atmosphere-study/README.md)：以冷青环境、暖灰石地、少量暗铜和朱砂组织色彩，提供冷青冥河、暖灰朱砂两套区域预设及原灰绿对照。门阙、碑墙、残碑、铜导流构件与近景绸带采用统一平涂材料，远景退到雾色并取消重描线，保留真实近远视差的实机演示。程序造型仍是构图与材质验证，正式绘画完成度需要继续制作。

用户进一步明确植被应符合地府氛围，接近怪松。圆簇红叶树被否定后，重新制作[冥府怪松](godot-pine-study/README.md)：横斜枯干、虬根、枯折枝与疏针，采用灰青、枯褐和墨绿，轮廓、裂纹与针叶建立不同线条粗细。单体和场景中的树使用同一组件，结合实际碑院判断统一程度。

随后制作[问字龛3D建筑单体](godot-shrine-study/README.md)，用于与怪松同屏比较：封闭四坡屋面、厚台基、凹入龛室和前柱具备真实体积，灰青石、暗铜与墨线沿用共享配色。交付近景、侧背面、同屏及完整转看实机短片，作为建筑与立片植被混合表现的下一步评估。

针对单体画面发灰，进一步制作[天空与多光源小样](godot-lighting-study/README.md)：将绘制天空作为低强度环境光，建筑与怪松接入主光、冷色边光、前补光和龛内暖灯；墨线保持独立，屋面保留大片分色，地台压暗。提供旧版、熄灯、关闭边光及天空的原生实机对照，仍在单体范围内评估配色。

在相同受光与线条基础上，新增[息灯亭、青铜字摊与兽面门阙](godot-building-study/README.md)三种建筑。通过通透悬灯亭、柜体与朱砂棚、石柱与兽面铜饰区分轮廓；提供熄灯、收摊、解封开门状态，以及与问字龛的同屏对照。继续采用小范围资产检查，尚未替换正式地图布局。

新增[四种墓碑细化](godot-tombstone-study/README.md)：倾斜旧碑、带倒落碑额的残碑、瘦高碑和矮宽碑。保持深色石材，以真实厚度、倒角、断面和不同铭文布局区分造型，单体与碑院共用组件；已替换碑院样板的简化碑，保留原功能字格和拾取。

继续细化[奖励封匣、青铜灯柱与封印墨障](godot-prop-detail-study/README.md)。分别提供有真实空腔和后铰链的开匣状态、合罩熄灯状态、只留下低矮残骸的解除状态；材质保持深色，以少量旧铜和朱砂区分结构。灯柱已替换碑院样板前沿的简化路灯，封匣与墨障在独立样板中查看。

地图拼接、射线拾取、相机和规则数据保留为技术基础；运行素材和界面皮肤依据完整样稿重新制作。当前战斗实机也属于后续统一对象。

用户要求查看整体效果后，已将细化组件[接入正式远征地图](godot-map-integration/README.md)：建筑、封匣、墨障、四种墓碑、怪松、铜灯与火盆共用平涂受光与深色调色板。地面改为轻微冷暖色差和低对比错缝铺纹，继续沿用连续岸线。人物暂留原立片，完整战斗实机和其他主题素材仍待后续统一。

随后根据“很暗、偏紫夜色、分格更清楚、直接印地板、明火改鬼火”的反馈，完成[紫灰夜色与贴地体积雾](godot-night-mist-study/README.md)。原生雾体在墨河聚集、行者附近减淡；大地面字独立于模型比例，暖灯与蓝紫鬼火分开控制。当前版本属于这一美术方向的实机迭代，不把程序平涂与几何对齐等同于达到《九日》的最终手绘完成度。

用户澄清雾应服务玩法视野后，已将环境薄雾改为[真实视野迷雾](godot-vision-fog-study/README.md)：当前可见散雾、已探索视野外暗化、未探索遮住地形及物件；信标与情报只显示允许的隔雾标记。散雾直接读取现有玩法遮罩，视野加成不再依赖装饰性半径。
