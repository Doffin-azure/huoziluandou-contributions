## 这次具体改什么

旧箱子是明亮金边、密集装饰、独立道具图标的画法。新样本改为低矮木制活字匣，使用暗青木板、氧化铜扣件、一处朱砂封条；缩小金属亮边的面积，以大色面表达体积。

地面只保留大块低对比石面和少量接缝，细节密度低于箱子。石缝不沿九个逻辑格重复描框，整块地面使用同一个世界平面。没有加入水波、复杂岸线或更多设施。

字匣前沿、进深与地面使用相近的平行投影轴线。预览的地面单位轴为横向 `(240,35)`、纵深 `(-112,132)`；字匣置于逻辑坐标 `(1.64,1.63)`，占地宽约一格，画面宽280像素。其前沿脚点中点按源图 `(688,829)` 对齐，不按图片外框底边摆放。

组合顺序为地面、局部积尘、投影、贴地阴影、字匣、前景碎片。字匣素材自带的少量石屑和草尖与独立接地层共同打断底部整齐的剪影。前景小石片只遮住脚边少量像素，不遮挡锁扣、封条或可辨认轮廓。

## 素材与范围

字匣和安静石面分别由内置 ImageGen 生成，完整提示词随素材保存。透明字匣原图为1536×1024，保留原始RGBA像素；页面仅采样有效区域并缩放，不重绘原图。源图中很少量的石屑和草尖属于字匣的接地装饰，不是整块地砖。石面按统一平面投影；石缝、边缘厚度和独立阴影由组合页绘制。

这是两个独立素材与若干简单几何层的实际组合，没有生成一张完整场景后再假装拆成九格。页面只用于这一处静态美术检查；尚未替换运行地图，也不用于验收镜头视差或最终瓦片接边。

后续设施应按同一组透视、脚点、线条密度和明度层级绘制，再逐个加入小样；先确认物件融入环境的方向。
