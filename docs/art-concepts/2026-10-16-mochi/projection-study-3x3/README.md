## 本轮制作方式

箱体、箱盖、锁扣、投影与地面全部保存为空间坐标，由同一个正交投影函数绘制。前后移动箱子、缩放或修改尺寸时，重新计算各个面的屏幕位置。箱子的画面边线不再依赖独立图像里预先画好的角度。

默认相机方位12°、俯角43°；每个世界单位212像素。地面两个单位方向投影为 `(207.367,30.061)` 与 `(-44.077,141.424)`，高度方向也由同一相机基向量确定。箱盖长边与地面横轴共用方向，进深边与地面纵轴共用方向。

美术只保留平涂色面、外轮廓、箱盖缝和一个锁扣。箱盖边角做小幅切角，箱身略收底；没有木纹、铆钉、包边、雕花、颗粒或磨损。投影为单层低对比色块，依据箱子实际高度与占地计算。地面只有少量大石面分区，九格边界仅在辅助线模式显示。

本轮没有调用生图接口，也没有导入位图素材。独立字匣SVG可用于固定投影下的美术底稿；继续调整相机或形体时，应从几何源文件重新绘制。当前绘制器是小样工具，游戏运行层尚未替换。

## 自检结论

1. **对齐方式符合要求。** 检查27组位置与缩放组合，箱盖四条主边始终平行于对应的地面方向，脚点高度保持为零。带辅助线的实际浏览器截图也能直接对照。
2. **细节密度符合这次试验的要求。** 识别箱子依靠轮廓、箱盖厚度与锁扣，大色面保持完整。相比上一版生成图，已经去掉密集纹理和装饰。
3. **可以作为可控的制作底稿。** 尺寸、比例、配色、角度、各个面均可独立修改，也可以输出透明矢量素材。
4. **距离最终手绘画风仍有差距。** 当前线条规则、形体偏几何；这轮确认的是投影与简化画法，不代表已经达到《九日》式场景绘画的完成度。后续的笔触和轮廓调整应建立在这套结构上，逐步比较，不一次扩成整张地图。

检查覆盖数学对齐与静态浏览器渲染；这张小样不用于验收镜头视差、复杂设施遮挡或最终游戏画面。

## 后续使用现成模型

复杂设施可以采用合适的现成模型作为结构来源，再统一坐标、尺寸、相机、平涂材质与轮廓处理。选择模型时优先看轮廓和结构是否适合，不要求沿用其贴图与装饰密度；确认授权与来源后保存记录。本次箱体只有简单几何，没有额外下载资产。
