## 参考与本项目的取舍

继续对照[《九日》官方Steam页面的实机素材](https://store.steampowered.com/app/1809540/Nine_Sols/)。赤烛的[官方介绍](https://redcandlegames.com/presskit/sheet.php?p=nine+sols)说明了手绘环境与Taopunk的神话、道教、科幻融合；制作人在[Xbox Wire的开发说明](https://news.xbox.com/en-us/2024/09/27/nine-sols-how-we-brought-a-taopunk-world-to-life/)中强调世界、造型与美术需要协调，并介绍了动画、漫画对美术开发的影响。

以下是本项目据参考制定的视觉方案，具体色值服务于墨池地图。重点是让色面、结构、装饰和空间形成一致表达：冷青环境、暖灰通行区、暗铜仪式设备，以及小面积朱砂和灯色。保留用户提供的战斗目标图中的黑色轮廓、青铜与纸白语言。

区域可以有不同的色彩重心。本轮并排提供“冷青冥河”和“暖灰朱砂”，共用相同几何，方便直接比较；原灰绿配色作为第三项对照保留。

## 配色分工

默认冷青版的主要色值如下。色彩的面积和所在位置与色值同样重要。

| 用途 | 色值 | 执行规则 |
|---|---|---|
| 背景底色 | `#20363F` | 冷色覆盖环境，避免全屏平均铺灰绿 |
| 结构墨线 | `#111E24` | 近景和重要轮廓较深；远景取消重描线 |
| 通行石面 | `#777A6F` | 暖灰集中在中景可操作区域，亮于周围建筑 |
| 建筑正面／侧面 | `#304C54`／`#223944` | 大块安静色面表达体积，细线集中在接缝、面板和屋面结构 |
| 屋面 | `#223D48` | 维持深色轮廓；不把所有檐口镀金 |
| 暗铜 | `#917C58` | 主要出现在套箍、导流线、印记与灯架；深铜部分继续降低亮度 |
| 嵌字 | `#C2BA9C` | 灰铜与骨白之间，降低原先统一亮金的感觉；固定文字保留刻槽 |
| 朱砂 | `#A53F3C` | 用于绸带、少量红叶、印记与危险提示；状态提示仍需结构变化 |
| 冥河 | `#1D4149` | 低明度，主要承托石岸与建筑；边缘渐隐接入远雾 |
| 远景／雾色 | `#3A5D64`／`#577A7C` | 压低对比与线条密度，建立前后层次 |

灯光用小面积暖色面与克制光晕。单个前岸灯给邻近石面提供弱暖染色，使用之前样板的平涂受光函数；其他灯保留自发光色面与局部光晕，不等同于完整的多灯遮光系统。

## 外围装饰的构成

| 空间层 | 本轮内容 | 与玩法的关系 |
|---|---|---|
| 近景框景 | 深墨门柱、曲线枝干与小块红叶、朱砂绸带、悬灯 | 位于可操作地面外侧；可单独隐藏，避免遮住字砖 |
| 中景碑院 | 连续石岸、入口阶沿、低碑墙、门阙、残碑群、神龛、铜导流线 | 留出中央3×3功能区。地面、字、物件采用共同投影，装饰不增加逻辑格 |
| 中远景岸线 | 低对比的石岸剪影与小亭 | 用形状和疏密连接建筑群，河面边缘渐隐，避免露出一块矩形水板 |
| 远景 | 分层殿阁与碑林剪影、雾色背景 | 在不同空间深度中产生较小的屏幕位移；用于氛围与方向感 |

主要建筑将仪式结构与设备合在一起：门阙的铜印记、墙上嵌入的导流线、神龛的圆形机构，均作为建筑构件。造型避免把齿轮、符纸和金边均匀撒在所有表面。

当前设施字、散字的纸白材质与外围装饰字纹需要继续区分。外围残碑本轮使用抽象浅刻痕，避免增加会被误认为机关的大字。

## 运行与调整

打开 `res://src/tools/expedition_atmosphere_lab.tscn`，按F6。

- **配色下拉框**：切换冷青冥河、暖灰朱砂、原灰绿；保留同一套几何和文字。
- **外围建筑**：显示／隐藏完整装饰，隐藏时关闭前岸灯的暖色受光。
- **近景框景**：单独移除近处门柱、树枝与绸带。
- **墙面、屋面、朱砂、远雾**：实时调整环境色。下方原有嵌字、刻槽、石面、水色控制保留。
- **中键拖看、滚轮缩放、复位**：查看深度关系，固定镜头朝向。默认轻透视，可切回平行投影比较。
- **原有机关控制**：叠放机关、消耗后、换字候选、前进1步均沿用。潮水与电闸读取原有周期，不因镜头或动画消耗探索时间。

两个预设分别保存在 `assets/expedition/palettes/mochi_dusk.tres` 和 `cinnabar_hall.tres`。运行时复制资源再试调，不覆盖项目的原始配色。

## 验证与当前边界

Godot 4.7.2 Forward+／Vulkan、RTX4060 Laptop GPU。原生检查覆盖配色与材料同步、换色保留原文字节点、隐藏灯具恢复受光、镜头移动产生真实近远视差、装饰不改变九格拾取、机关周期及玩法随机数隔离；错误日志为空。原镶字样板检查和20项火光检查继续通过。

这是配色、外围构图与模块拼接的小样。建筑目前由程序几何、曲线剪影与少量结构线组成，造型和绘画完成度仍需继续细化。尚未替换整张地图，也未实现完整场景的自动摆放、遮挡淡化、迷雾联动和多光源投影。

实现文件：

- `src/tools/expedition_atmosphere_lab.gd/.tscn`：运行场景与调色控制。
- `src/map/expedition_stylized_surroundings.gd`：外围构件、前中远景、局部灯色与背景。
- `src/map/expedition_flat_palette.gd`：新增建筑、屋面、远景与雾色角色。
- `src/shaders/expedition_moat.gdshader`：低对比河面边缘渐隐。
- `tests/expedition_atmosphere_lab_capture.gd/.tscn`：原生截图、视差短片帧与交互核对。
