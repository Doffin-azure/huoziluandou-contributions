# 墨池 · 3×3纹理拼接小样

仅制作基础纹理与九格组合，供判断画法、石板尺度、水纹密度及岸边衔接。没有继续制作整张地图或修改游戏运行层。

原始材质图由内置 ImageGen 一次生成，1254×1254，按四个627×627分区读取：干石地、潮湿石地、墨水和石岸立面。保留生成像素，原图未修改。

预览由页面实际合成五格石地、四格墨水，布局为 `SSW / SSW / SWW`。使用同一组基础材质重复采样，石地与湿地沿岸混合，岸边用独立石墙表面表现小幅高度差；不是生成一张完整场景图再切成九格。

当前使用镜像重复控制接缝，仍需观察镜像纹样是否过于明显。源图是材质小样，尚未制作成具有匹配边缘约束的最终无缝瓦片或完整岸线图集。本轮只比较基础地形画法和组合效果。
