# 石地凹刻字

地图的散字、设施字和机关字已从亮色文字层换为贴合石地的凹刻材质。暗槽、细窄切边和少量磨损表现刻痕，字内保持同一块石料的色相和颗粒，不再使用纸白填色。

刻字与连续地面共用 `expedition_stone_surface.gdshaderinc` 的世界坐标石材取样，包括三种石色、格缝和岸边湿色；法线模拟浅凹切面，使用实际灯光和物件阴影。近乎共面的薄面承载材质，不改通行高度或地形碰撞。单字遮罩直接读取 Godot 字体栅格缓存并复用，不增加逐字视口或玩法随机数。

“火”字增加五枚分散、间歇浮动的小火星，使用低亮度冷蓝灰色，与鬼火方向一致。火星不改变地面照明，只有在当前视野内且未消耗时显示；散字拾取后随实体移除。其余字先保持统一刻痕，没有批量添加醒目特效。
