# 镶字地砖 · Godot 3×3样板

完整的功能、命名候选与美术成本见[地图机关字与镶字美术评估](../地图机关字与镶字美术评估.md)。

后续配色与外围环境的实机迭代见[冥河碑院样板](../godot-atmosphere-study/README.md)。本目录六张图保留为镶字初版对照。

打开 `res://src/tools/expedition_glyph_lab.tscn`，按F6。当前是8个主题机关与1个墨障的对照页，未接入完整远征地图。

- 左击查看该字当前的基础功能；中键拖看，滚轮缩放。
- **叠放机关**：比较纯嵌字与低矮物件组合。
- **消耗后**：模拟泉、炉、桩、流耗尽；纸、焰保留常驻效果。真实地图的强化次数将在接入时读取。
- **换字候选**：比较焰→灼、桩→镇、潮→渡；不会改动实际地图规则或字数据。
- **前进1步**：独立推进小样的探索时间，读取现有潮水4／4、电闸3／3周期，改变水位与门条位置。
- **嵌字、刻槽、石面、水色**：实时调色，关闭小样后不覆盖项目默认调色板。

主字与刻槽是贴地文字，不是朝向相机的悬浮字。文字、物件、浅渠、门条使用同一个世界坐标与镜头。当前浅渠为平色水位造型验证，没有水波或流体模拟。

截图来自Godot 4.7.2 Forward+／Vulkan、RTX4060 Laptop GPU。`tests/expedition_glyph_lab_capture.tscn` 可进行原生拾取和规则时序检查，附加 `-- --capture` 会导出本目录的六张实机图。所有检查通过，错误日志为空。

当前物件只是占地、比例和遮挡用的简化原型；本轮用于判断镶字方向与状态表达是否可继续制作。
