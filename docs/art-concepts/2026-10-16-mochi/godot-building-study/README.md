## 三种建筑

| 建筑 | 造型重点 | 状态变化 |
|---|---|---|
| 息灯亭 | 四柱通透亭体、封闭四坡屋顶、柱脚铜箍、两侧坐凳、六面悬灯、地面【休】镶字 | 暖灯熄灭，挂出【歇】牌；坐凳与开口保留 |
| 青铜字摊 | 六格字模抽屉、柜台、三只活字匣、小压印机、压条固定的朱砂棚布、地面【市】镶字 | 收起柜台字匣，闭合柜板，铭牌由【字】改为【歇】，熄灯 |
| 兽面门阙 | 厚石柱、嵌铜纹、外挑灯架、厚门扇、门环、兽面浮雕与中央封条 | 移除封条，两扇门绕实际铰点开启，保持侧灯 |

这些状态是美术表现接口。本轮没有新增门阙地图规则，也没有把字摊绑定成一次性商店；实际状态应由后续玩法接入决定。

## 风格与遮挡处理

三种建筑共用同一调色板、轮廓系统、天空环境与主光/冷边光/前补光。灯具使用真实局部点光源和低强度HDR辉光；墨线保持独立受色，材质关闭镜面高光。大色面先读清，刻线集中于柱体、铜构件、柜体和屋顶结构。

屋面复用问字龛的大片四坡法线处理，增加可调宽深与屋脊长度。四坡屋顶具备上下面及封闭檐口；建筑侧面、柜体、坐凳、门扇也均有真实厚度。

第一轮实机中，棚布遮住柜体、屋檐挡住兽面。已提高并缩短字摊遮棚，让字模抽屉与压印区露出；兽面前移到檐前的支座上，避免角尖穿过屋面。棚布增加独立可编辑颜色，压低早期偏橙的亮红。与问字龛的同屏模式留出完整画幅，四座建筑均可看全。

## 打开与调整

打开`res://src/tools/expedition_building_lab.tscn`，按F6。

- 下拉选择三种单体、三座同屏、与问字龛同屏。
- 左键拖动转看，滚轮缩放；前侧、侧面、背面按钮快速切换。
- **使用后／解封**：检查熄灯挂牌、收摊、移除封条和开启门扇；关闭即可恢复。
- **设施暖灯**、**结构刻线**：分别比较照明与细节密度。
- 灰石、屋面、墨线、棚布、线宽与曝光可调。
- 继续保留旧配色与固定染光对照、天空环境光、冷色边光、辉光开关。

当前是并排资产检查台，地面用于检查接地与投影。它不表示正式地图布局，也没有替换整张远征地图。

## 源文件与复用

| 文件 | 内容 |
|---|---|
| `src/map/expedition_building_base.gd` | 共用几何、封闭屋面、刻线、镶字、灯具、调色和表现状态 |
| `src/map/expedition_rest_pavilion.gd` | 息灯亭独立组件 |
| `src/map/expedition_type_stall.gd` | 字摊独立组件 |
| `src/map/expedition_beast_gate.gd` | 门阙独立组件和铰点门扇 |
| `src/tools/expedition_building_lab.gd/.tscn` | 可运行建筑检查场景，复用问字龛样板照明 |
| `tests/expedition_building_lab_capture.gd/.tscn` | 原生截图与状态检查 |

组件使用`new()`、加入3D世界后调用`setup(shared_style)`建立模型。`set_alternate_state(bool)`切换表现状态，`set_lamps_enabled(bool)`与`set_details_enabled(bool)`分别调整照明和刻线。组件监听共享调色板变化，后续修改配色无需重建几何。

`footprint`记录检查台制作单位中的台基尺寸，`map_scale`给出后续压到约一格占地时的建议比例（亭0.50、摊0.49、门0.45）。它们只是美术接入建议，尚未改变逻辑占格、拾取、视野、存档或地图数据。
