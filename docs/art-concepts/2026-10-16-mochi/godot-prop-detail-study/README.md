## 造型与状态

| 物件 | 细化重点 | 使用后／解除状态 |
|---|---|---|
| 奖励封匣 | 深色木体、两道旧铜箍、浅斜匣盖、后铰链、侧握把、跨过盖沿的朱砂封条；地面保留【赏】 | 真实匣盖开启105°，显示四壁与空腔，完整封条移除，只留断封条 |
| 青铜灯柱 | 铜绿柱身、石座、旧铜套箍、【引】铭牌、六面灯笼、墨青灯帽、小范围暖色原生灯光 | 关闭点光和灯芯发光，六面笼内合上实体灯罩，状态从内部结构也能区分 |
| 封印墨障 | 三块不等高的墨黑石体、少量裂纹、交叉朱砂封条、中央封印；地面保留【障】 | 高石体和完整封印隐藏，原位只留低矮碎石及断封条，镶字暗化 |

深色大面保持安静，铜饰与封印只占少量面积。灯柱的暖光是Godot局部点光，灯芯可产生克制的HDR辉光，柱体和帽檐仍沿用无镜面高光的平涂材质。墨障使用当前墨青屋面颜色与受光响应，避免直接光把黑石抬成浅青。

三件的接地点、比例、投影与建筑共用同一世界。开匣单体镜头为盖子预留高度；状态切换只变换匣盖及替换少量显示部件，不重新生成全部模型。

## 打开与调整

打开`res://src/tools/expedition_prop_lab.tscn`，按F6。

- 下拉切换三种单体、三件同屏、与问字龛同屏。
- 左键拖动转看，滚轮缩放；前、侧、背面按钮检查结构。
- **使用后／解除**：同时切换开匣、合罩熄灯、墨障解除；单体模式标明对应状态。
- **地面镶字**：独立开关【赏】【障】，便于以后复用现有字格标识。
- **灯柱暖光**：单独比较照明；结构状态仍由使用后开关控制。
- 旧铜、铜绿、屋面、墨线、线宽、曝光和受光可调。

## 源码与接入范围

- `src/map/expedition_reward_casket.gd`：空腔、匣盖、封条和开启状态。
- `src/map/expedition_bronze_lamp.gd`：灯柱、灯罩和局部照明。
- `src/map/expedition_sealed_barrier.gd`：高石体、交叉封印和低矮残骸。
- `src/map/expedition_flat_palette.gd`：增加铜绿`patina`颜色，其余沿用共享调色板。
- `src/tools/expedition_prop_lab.gd/.tscn`：原生检查场景。
- `tests/expedition_prop_lab_capture.gd/.tscn`：截图与状态检查。

组件创建后加入3D世界并调用`setup(shared_style)`。使用`set_alternate_state(bool)`切换表现状态，灯光和刻线分别由`set_lamps_enabled`、`set_details_enabled`控制。封匣与墨障的`floor_marker`可以关闭，也可以由字格层统一显示。

灯柱已替换碑院美术样板中前沿的两盏简化路灯，按原位置缩放。封匣和墨障保留在独立物件样板中。本轮未接入正式远征的掉落、奖励大小、障碍清除或步数规则；现有逻辑和数据不变。
