## 调整

此前屋面采用较亮的青色底色，接受与其他材质同强度的直接光。大片屋顶被多灯和色调映射抬亮，明亮色面占比过大。

- **屋顶**：默认底色从`#28515A`改为`#122A2C`，将直接受光响应设为0.65。屋脊、檐口构件也同步使用屋面受光响应。
- **石面与木柜**：收暗顶面及正侧面，避免青灰建筑变成浅粉彩。
- **铜饰与棚布**：铜色从亮黄收为旧铜，棚布改为暗朱砂。
- **全局灯光**：主光1.4→1.15、冷边光0.65→0.38、前补光0.22→0.14、天空环境光0.28→0.16。曝光仍为1.0。
- **可读亮点**：保留灯芯发光、灯具局部点光、镶字与文字的可读亮度。

新参数`roof_light_response`独立控制屋面直接受光强度；天空环境光仍正常参与屋面照明。其余调色板默认值保持1.0，旧平涂材质路径不受该参数影响。

## 操作与源码

打开`res://src/tools/expedition_building_lab.tscn`或`res://src/tools/expedition_shrine_lab.tscn`按F6，默认使用本版深色配色。

**屋面**拾色器改变底色，新增**屋面受光**滑杆改变受光强度。配色保存在`assets/expedition/palettes/mochi_lantern.tres`；真实受光材质通过`diffuse_response`接受该参数。三个新建筑与问字龛监听同一调色板，实时同步。
