## 四种造型

| 样式 | 主要结构 | 细化重点 |
|---|---|---|
| 倾斜旧碑 | 约1.5高、0.64宽的旧碑，碑体与碑文共同绕碑脚倾斜 | 沉脚、侧面磕缺、两组主裂纹、残框与少量苔迹；铭文“无名之墓” |
| 断裂残碑 | 约0.84高的碑根，旁边有倒落碑额和碎块 | 不规则断口具备前后厚度，断石材质区分切面；碑根仅保留“之墓”和上方残笔，碑额上有“冥” |
| 瘦高碑 | 约1.91高、0.53宽的窄长碑，双层碑座 | 分出的碑额、窄边框、竖向铭文“故人之墓”、侧后面刻线 |
| 矮宽碑 | 约0.90高、1.10宽的厚碑，低宽碑座 | 宽肩碑额、横向“长眠”铭文、边缘缺损与局部苔迹 |

占地的完整尺寸还包括碑座与碎片；上述高度是制作单位，未规定最终地图比例。

碑体、倒角、碑脚、断口和落片均为有厚度的3D网格；倾斜、倒落使用真实三维变换。大轮廓用较重墨线，边框与结构纹较细。断口的浅石色只用于少量新断面，不把整座墓碑提亮。碑面、断口和刻字有独立颜色参数。

文字采用贴合碑面的暗色字层与极窄切口边缘模拟阴刻，受碑体深度遮挡并随碑体倾斜。没有对每个汉字做实体布尔雕刻，也没有将装饰铭文作为可拾取的玩法字。

## 打开与复用

打开`res://src/tools/expedition_tombstone_lab.tscn`，按F6。

- 下拉切换四种单体、四碑同屏、与问字龛同屏。
- 左键拖动转看，滚轮缩放；前、侧、背面按钮快速检查厚度。
- **铭文／刻纹**：开关铭文、裂纹和结构笔线；主体轮廓保留。
- **碑石、断口、刻字、墨线、线宽**可实时调整。
- 默认关闭局部暖灯；**暖光对照**检查石材在暖光下的表现，天空、冷边光与曝光沿用建筑样板。

`src/map/expedition_tombstone.gd`是共用组件，`Kind`含`LEANING`、`BROKEN`、`TALL`、`WIDE`。创建后先指定`variant`，加入场景，再调用`setup(shared_style)`。`set_details_enabled(bool)`控制铭文与刻线。颜色属于共享`ExpeditionFlatPalette`，修改后无需重建碑体。

四种墓碑已替换`ExpeditionStylizedSurroundings`中原来的简化碑，并加入第四种矮宽碑；按原碑院位置缩放、错位，保持功能字格在原位。该接入仅针对现有碑院美术样板，未替换正式远征地图规则或新增墓碑交互。
