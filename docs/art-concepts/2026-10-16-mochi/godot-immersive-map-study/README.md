# 全屏地图与自然夜色

本轮直接修改可玩的地图表现和交互，没有更改地图生成或玩法随机数。

## 界面与操作

- 地图铺满画面，去掉顶栏、标题介绍、常驻右侧版面、日志、镜头按钮和操作说明。
- 点击行者或按 I 展开行囊，生命、金币、墨、字匣和印章一起显示；字袋、排字、行记、图例和菜单按需进入。
- 点击弹层外先收起行囊，本次点击不会移动；再点人物或按 Esc 也可收起。行囊内滚轮只滚动面板，不缩放地图。
- 排字功能保留在行囊的二级入口中。事件仅在触发时展开；熔炉同时展开字匣，继续支持选两枚字熔炼。
- 普通日志以约 2.5 秒的短提示出现；幕的背景介绍只保留在行记中。首领警报仍短暂显示，完整状态在行囊内查看，追逐路线与边缘提示继续保留。
- 滚轮缩放，中键拖看，移动恢复跟随；Home 回到行者，M 总览，行囊也提供这两个入口。

## 配色与视野

地板以暗灰褐石色为主，木材保留褐色、建筑保留低饱和铜绿，屋面为近黑蓝灰。中性月光负责显示材质原色，低强度紫色侧光与蓝紫鬼火局部补色，灯笼为暖金光。天空环境色也改为低饱和蓝灰，避免整屏紫色覆盖。

玩法视野规则继续沿用：未探索区域遮蔽，已探索但当前不可见的区域暗化，当前可见处散雾；信标和情报揭示不额外透露建筑。
