# 炼字狱封面首版

工作树：`huoziluandou-room-map`，分支 `codex/courtyard-room-map`。没有提交、推送或开启连字入场。

## 接入内容

- 正式项目名称与标题改为“炼字狱”。标题使用独立透明字标，来源和两轮完整 ImageGen 提示词见 `imagegen-prompts.md`。字标按参考生成，没有把整张参考当作游戏背景。
- 移除标题下方的小字。主操作使用金色细框、菱形和朱砂选中底；继续冒险入口按已有存档显示。构筑、图谱和旧版远征移到底部，原有回调和路由保留。
- 桌面保留竖向菜单；小高度横屏采用两列，保留至少 48 屏幕像素的按钮高度，标题和辅助入口不叠在菜单上。
- 原有三维庭院、相机推进与真实水面倒影继续运行。新增两盏前景灯具和各自带阴影的暖色局部灯，框架产生实际遮挡和投影；前景木板单独增加局部光响应，其他建筑沿用原配色。
- 52 枚贴在地板上的枫叶采用一次 MultiMesh 装配。原飘落物改用同一枫叶轮廓，远近位置分层；减少动效时仍暂停和隐藏动态落叶。
- 金纹云使用可编辑的 `gilt-clouds.svg`。天空着色器按视线方向采样，因此云纹随天空出现在真实倒影中，建筑轮廓也会正常挡住它。
- 独立审阅场景 `src/tools/title_art_sample.tscn` 同步使用新字标；F2 面板新增“前景灯光”调节。

## 查看

正常 F5 启动项目即可看到正式封面。F6 运行 `src/tools/title_art_sample.tscn` 可单独看庭院和调光。

`title-1280x720.png`、`title-1920x1080.png`、`title-960x432.png` 均为正式入口运行截图；`courtyard-no-ui.png` 是同一场景去掉界面后的画面。`courtyard-foreground-lights-off.png` 仅关闭新增局部灯，供观察暖光与投影差异。

## 检查

`tests/title_branding_runtime.tscn` 的 76 项检查通过，涵盖项目名、PNG 真透明、副标题移除、两个投影灯、地面落叶、天空云纹、玩法随机数不变、全部旧入口保留、三种分辨率的触控与布局、设置浮层、开始／取消和减少动效。通过渲染画面对比确认灯光实际改变了前景地板，报告见 `runtime-checks.json`。

`tests/title_menu_test.tscn` 的 16 项检查通过，包含正式启动、图鉴／设置浮层、旧构筑与图谱路由、减少动效切换和离开标题后的资源释放。没有改动玩家存档文件。

本轮重点为风格和接入。字标仍可替换独立 PNG；云纹、两侧灯光和落叶可以单独调整。未做安卓实机性能验收。
