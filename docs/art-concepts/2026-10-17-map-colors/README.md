# 地图配色调整 · 朱砂丹青

本轮在现有地图模型与光照结构上调整颜色，参照主界面庭院和卡牌奖励场景的颜料体系。地图继续保持夜景，地面格缝与刻字保留原有表现。

| 用途 | 配色方向 |
| --- | --- |
| 屋顶、梁柱、园林窗格 | 深丹青、墨蓝阴影，减少灰绿 |
| 封条、红绸、莲花 | 朱砂与暗红，集中作为小面积点缀 |
| 铜饰、匣扣、交互标识 | 旧金高光，避免灰褐色糊成一片 |
| 石地与墓碑 | 暖灰石色与少量冷灰变化，保留雕刻和接地阴影 |
| 行囊文字与按钮 | 共用 JourneyStyle 的纸色、旧金与朱砂色 |

光照沿用主界面和奖励场景的线性色调映射，主光为暖纸色，辅光为低强度灰蓝，去掉原本偏紫的补光；保持暗部与屋顶的明度范围。发光仍集中在灯笼和鬼火。

色板资源：`assets/expedition/palettes/mochi_night.tres`；荷叶与花色：`assets/expedition/lotus/lotus_night.tres`。水面、岸壁与雾色从同一色板读取。石地与镶字仍共用 `expedition_stone_surface.gdshaderinc`，不会出现刻字周围另铺一层颜色不同的地砖。
