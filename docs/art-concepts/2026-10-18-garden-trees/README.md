# 园林树木 · 红枫与幽林

本批为五件可直接放入 Godot 的原生立体树木，与上一批凉亭、假山、二层小阁共用光照和色板。本页保留单体与组合样板；红枫、怪松、垂柳、枯槐现已随[八类房间内设](../2026-10-18-furnished-rooms/index.html)接入庭院路线模式，斜生红枫仍保留为可选资产。旧 12×8 远征地图树木没有替换。

| 场景 | 造型 | 根部预留范围 |
| --- | --- | --- |
| `red_maple.tscn` | 深朱砂红叶，弯曲主干，疏密分层的锯齿叶簇，少量掌形叶与落叶 | 1.30 × 1.25 |
| `leaning_red_maple.tscn` | 偏向一侧的红枫，横枝与不对称树冠 | 1.30 × 1.25 |
| `crooked_pine.tscn` | 曲干、横向枝条、疏落扁冠与少量针叶墨线 | 1.50 × 1.45 |
| `weeping_willow.tscn` | 临水树形，长短交错的垂叶，顶部保留成片叶簇 | 1.35 × 1.30 |
| `bare_locust.tscn` | 裸露分叉、错落枯枝、浅树洞与根部裂纹 | 1.70 × 1.60 |

场景都在 `res://assets/expedition/garden/`，根节点缩放为 **1**，直接使用世界单位。地面原点统一为 `Vector3.ZERO`。模型高约 3.5–3.9，行者沿用实际地图比例。树冠允许超出根部范围；接入生成器时需同时考虑 `visual_bounds`，避免撞墙、穿屋顶或堵住门口。

## 使用

打开 `res://src/tools/garden_tree_kit_lab.tscn` 运行：下拉选择五种单体或完整庭院，左键转看、中键平移、滚轮缩放。底部可调整红叶、松叶、柳叶、树皮颜色，并切换根部占地和树冠透视。

场景自带默认色板，运行后生成网格；放入现有地图表现层时，可调用 `setup(shared_style)` 使用同一份 `ExpeditionFlatStyle`。树叶默认从共享色板取得颜色；需要单独变色时，可修改 `foliage_tint`（透明表示沿用共享色板）。实体接收原生灯光与阴影，轮廓沿用园林建筑的像素墨线。

树皮为有厚度的七面锥形分段网格，叶簇为不规则立体轮廓。少量掌形叶、落叶和柳叶使用双面几何薄片，既能产生空间视差，也不会给内部三角形描边。没有贴入预烘焙视角图片。

`footprint`、`solid_footprints`、`ground_contact`、`visual_bounds` 均为模型元数据，未生成物理碰撞体。庭院房间接入时由 `room_interior_assets.gd` 管理树根的寻路预留范围，`GardenRoomVisual` 负责叶片遮挡淡化和未探索隐藏；独立工作台仍可用 `set_canopy_faded(true)` 手动预览。

程序随机性仅使用树木自身固定种子的 `RandomNumberGenerator`，不会消耗地图与战斗随机数。本批没有动态摆叶或风场，便于先确认静态造型和配色。
