# 实际地图 · 荷花与闭合园墙

本轮将之前独立预览中的盛莲、花苞、残荷与伴生叶片接入远征地图，并将外围由两段背景墙改成沿真实边界四边闭合的园林围墙。截图来自原生 Godot Forward+；总览和近看使用全揭示状态检查美术，正常游戏仍沿用探索视野。

植物模式不重复生成水面或方形岸沿。花丛优先放在主要池塘，叶心、叶缘、花瓣和建筑净空都作位置检查，并对齐 `layout.water_height`；不额外占用逻辑格。围墙按边缘格揭示和暗化，局部淡化基于世界坐标，旧图也有完整围合。
