# 冥府园林 · 独立模型样板

新增月洞门、碑纹照壁、双间游廊和平拱石桥，以及六种栏杆构件、六种围墙构件，共十六个 Godot 场景。延续现有平涂立体物件的配色、深色屋面、铜绿和明确墨线；几何镂空与实际阴影提供厚度。

本轮未接入游戏地图，也没有修改地图生成、寻路、战斗或事件。组合庭院是独立的资产预览。

## 资源与拼接

模型位于 `assets/expedition/garden/`；尺寸、连接点和调用方式见 [资产说明](../../../../assets/expedition/garden/README.md)。独立预览入口为 `src/tools/expedition_garden_lab.tscn`。

边界的整段为一格，栏杆另有半格段。自动拼接把段体与柱分开，同一柱位置只生成一次；转角使用共用柱，墙帽保持相同截面高度。残损段保留标准连接口，月洞门的两侧也提供连接标记。桥上的栏杆直接调用同一套拼接方法。

## 验证

捕获场景 `tests/expedition_garden_lab_capture.tscn` 共 42 项通过、0 失败，检查建筑建立、闭合与开口路径、无重复柱、段体连接口和柱中心重合、两种分辨率预览、十六个预制场景独立实例化及游戏状态隔离。截图已检查正背面、漏窗、转角、桥下开口和模块页取景。
