# 纸壳兵动画样板

[局部连续预览 GIF](animation-closeup.gif) · [完整战斗画面 MP4](animation-battle.mp4) · [关键姿势](animation-keyframes.png)

本轮仅制作纸壳兵，没有生成其他敌人或调用图像生成。使用当前 v05 的透明图作为唯一角色纹理，复制到 `assets/taopunk/enemies/paper_shell_soldier.png`；原概念和墨灵素材未修改。

## 动作

| 动作 | 表现 | 时长 / 结算点 |
|---|---|---|
| 待机 | 头部与前臂小幅错相转动，纸片保持刚性 | 3.6 秒循环 |
| 攻击 | 收臂蓄势，前脚跨步，肩肘依次展开刺出，再收回 | 1.06 秒 / 0.40 秒 |
| 补盾 | 双臂在胸前合折，旧金弧线短促响应，再解折 | 1.00 秒 / 0.34 秒 |
| 受击 | 躯干退让，头部与前臂延迟回弹 | 0.48 秒 |
| 退场 | 四肢失去支撑，沿关节折落，纸身收窄并淡出 | 1.20 秒 |

`PaperShellActor` 采用同一纹理的十五个刚性纸片，通过父子关节驱动。腿部用两段逆向运动约束脚底，突进时只有明确跨步的一脚移动，纸片长度不拉伸。退场保留关节连接，避免只缩窄贴图后手脚悬空。减少动效开启时停止连续动作，保留短结算时间和静态战败状态。

## 接入与边界

角色 ID 为 `paper_shell_soldier`。`InkSpirit` 识别这个 ID 后创建纸片演员；`EnemyView` 将攻击、补盾、受击与死亡反馈传给演员，避免叠加整图挤压。攻击使用现有纸片材质轨迹，并与真实伤害事件对齐。

背景弱化和紧凑顶部纸签仍然只在独立预览场景中启用。新怪尚未加入正式遭遇名单；本轮没有实现名单里新的护盾补至上限规则，预览/测试从 0 盾验证一次实际 +8 护盾。不能把动作接入视为整只新敌人的机制接入完成。

演示片为逐帧采样的动作展示，HUD 数值固定；实际结算连接由下列真实战斗测试另外验证。连续预览共 184 帧、30fps、约 6.13 秒；MP4 保留 1980×792，GIF 展示敌人局部。帧来自 Godot 原生绘制，FFmpeg 仅负责视频/动图编码。

## 验证

共 229 项通过：

- 纸壳兵专项 37：原纹理逐字节一致、十五片有效三角化、动作区别、采样全程落脚、真实回合攻击 6、真实护盾 +8、返回待机、死亡停止、减少动效，以及待机不消耗战斗随机数。
- 墨灵动画 27：原有骨骼、攻击和注字路径。
- 其他八敌人攻击 113：各自姿势、命中时序、特效与原图保留。
- 原生战斗 UI 52：选择交互、异步队列、伤害与防御数值、浮层和界面切换。

旧 UI 测试的投影命中需要实际渲染器，最终使用 Compatibility 原生运行通过；八敌人动作测试按 30fps 运行，覆盖其记录窗口内完整的多段命中。最初在 headless / 60fps 下的这两项测试分别有四个投影命中断言和一个特效观察窗口断言失败，未修改这些旧测试来绕过失败。旧套件仍可报告退出时的 ObjectDB 清理警告。
