# 敌人美术参考研究 · 2026-10-17

本轮只做外部参考检索、图像观察与现有素材诊断，没有生成新图，没有替换正式敌人或修改游戏代码。以下设计判断是对图片的视觉分析，不是原作者的设计说明。

## 实际查看的参考

- [官方游戏与风格说明](https://redcandlegames.com/presskit/sheet.php?p=nine+sols)

已在浏览器中查看图像：重装身体向前压，后腿撑住，长兵器建立明确攻击轴线。红色大甲片与暗色躯干先构成形体，装甲内部没有处处用高亮雕刻填满。轮廓先说明重量与行动方式，再读局部。

适合铜印学习：承重、蓄势、动作方向，以及把文化造型转化成能够行动的身体。不能直接把英招的比例或兵器复制过来，也不能拿动作帧和我方待机帧作公平的动作质量排名；这里只分析可用于待机设计的力线。

### 九日：勾芒战斗中的两名随从

- [实机截图来源：GamesRadar](https://www.gamesradar.com/games/action/nine-sols-review/)
- [原尺寸截图](https://cdn.mos.cms.futurecdn.net/yXZ5Vy6tX7ZLtHvdqrF75Z.jpg)

已在浏览器查看：左侧随从宽肩、粗臂、长裙形成下沉重量；右侧随从窄身、细臂、横伸手形成另一种姿态。二者共享服饰、平涂与勾线语言，却不用相同身体套上不同装饰。脸部也没有靠统一的发光红眼证明“这是怪物”。

适合全体敌人学习：统一画法而非统一模板；不同轮廓、身段与性格仍然属于同一个世界。截图用于视觉分析，评论文章的观点不作为本项目美术结论的依据。

### 暗黑地牢：收藏家

- [角色图与出处页面：Bogleech 的敌人图鉴分析](https://bogleech.com/halloween/hall17-darkestdungeon)
- [所查看角色图](https://bogleech.com/vgmonsters/dd-collector.png)

角色图由第三方图鉴展示，非本次找到的官方资产发布包。已在浏览器观察：头部高而窄、披风展开很宽，下身收紧；披风内的人头非常密，但大量内部形状沉入黑色。苍蓝小亮点与头笼引导注意。细节不等于噪音，关键是能否归并为一个整体。

适合我方学习：主动合并暗部、集中亮部、让复杂内容服从一张大剪影。不能把粗黑阴影和恐怖题材整体搬来，替换已经确定的九日色系。

### 空洞骑士：Team Cherry 早期 Lesser Mantian

- [官方开发文章与原始动图](https://www.teamcherry.com.au/blog/the-creatures-of-hallownest)
- [所查看动图](https://images.squarespace-cdn.com/content/v1/606d4deb4db8c15ea53b3624/1619052141525-2WLQ9OLDA60FXD8GIQ93/ff9403b43619400f7aeb9ef4ba0deb91_large.gif)

这是官方早期开发展示，不冒充最终发行素材。已在浏览器观察：很小的头、极长的颈部、弯曲腹部和折叠前肢；颈部与身体、双腿之间的空隙仍然清楚。形体比例就能形成辨识度，不依赖纹理。

适合我方学习：大小与长短比例的明确取舍、轮廓留空，以及能延伸为动作的关节结构。其简洁程度不作为强制要求；墨灵已有的丰富细节应该保留。

## 我方素材诊断

对照：`assets/taopunk/ink_guardian.png`、`assets/taopunk/enemies/bronze_seal.png`、上一日原生敌人对照图及两轮未通过铜印稿。

### 为什么墨灵成立

1. 金色面具是第一视觉中心，红额眼为更小焦点；青黑披风占据宽大连续暗面，托住面具。背环虽然细密，但亮度与色相压在面具后面。
2. 尖角、圆背环、宽肩与长红带有不同的尺度和形状，形成刚柔、收放变化。红带跨越主体，连接构图，而非各处重复同一种花纹。
3. 面具、垂肩、低头与向前看的目光共同表达庄严、压迫的角色气质。待机不需要大动作，也有明确态度。
4. 披风褶皱用少量形状阴影说明布料，很多区域允许保持平静；金属内部线条与边缘不是统一亮度。
5. 原生展示采用近景裁切，脸和肩直接占据敌人区。这是优势之一，但不是画法质量差异的全部解释。

### 铜印的问题

1. **题材停留在贴饰。** 主体首先被读成传统铜狮，胸前加了一块印面。“铜印”尚未决定角色的受力结构、行动方式与攻击面。第二轮改成方盒也没有解决连接关系，只把装饰拼贴换成体块拼贴。
2. **待机像陈列品。** 四爪整齐落地，躯干均匀摆开，头与背部保持铜雕陈列姿势。可以设计沉静、正面的镇守者，但这里还缺少有意识的压肩、偏重、目光或关节蓄势，静态没有角色态度。
3. **亮部平均分配。** 脸、肩、爪、尾巴和背脊都有近似的金边、倒角与铜锈。尾端第二个兽头甚至重复主脸焦点。面部、胸印和尾头互相争夺注意力。
4. **形状节奏重复。** 鬃毛、肩膀、肘部、后腿、尾端反复出现同尺度卷曲与鼓包。不是单纯“细节多”，而是缺乏大直面与小曲线、硬形与软形的对照。
5. **上色更像材质渲染。** 铜锈斑块、包边亮线与小渐变遍布身体，制造浮雕感；墨灵主要依赖大色面、选择性的阴影与墨线。只共享青、金、红三色不足以统一画法。
6. **动画设计基础弱。** 铸壁、印击、蚀版分别需要防御面、打击接触面和污染释放位置。目前只能后加特效解释技能，身体没有清楚的动作支点。美术与动作应一起构思。

“AI 味”是上述均匀堆饰、材质泛化与结构拼接的观感描述，不是仅凭图片能够鉴定生成来源的方法。

### 其他敌人的共性与差异

原生对照图说明它们已经有不同物种轮廓，不能笼统说成同一剪影。问题是许多角色仍共同使用红亮眼、尖锐口部、碎裂边缘、铜锈和局部小高光来表达危险，缺少更具体的个性。

- 铁画、纸卫：大量细尖折面均分注意力；需要能先读到的头、躯干或主要武器形。
- 锈笔：画笔是有意义的道具，但背壳裂边、骨架与笔杆的材质刻画强度相近，主体关系仍弱。
- 焦火、混铅海：尖刺、碎块与火舌叠加后，面部和主要力量方向容易被吞没。
- 铅版：物件身份比铜印明确，但过度均匀的磨损让它更像有血条的道具，角色性需要通过姿态和运动结构建立。
- 字魔：长曲线剪影有自身方向；内部明暗碎纹仍要服从流动主线。

另一个独立问题是运行时展示：墨灵按近景裁切铺满敌人区，其他敌人按所有攻击姿势的联合范围容纳，待机仅占区域约 52%–73% 宽度，铜印约 73%。后续需统一观看距离和主体可读尺度；不能简单将所有敌人都放大到同样高度，也不能用放大掩盖设计问题。

## 下一轮铜印的设计门槛

保留墨灵。先停止为铜印增加饰物、纹理或整图精修。

1. 根据“防御—印击—污染”确定主体结构与三个动作的受力位置。每个新增构件都要有形体或行为用途。
2. 先比较三种真正不同的剪影与姿态，而非同一铜狮的三种装饰。可探索低伏前压的印兽、偏重巨臂的执印者、悬提重印的祭器；这些只是待验证方向，不是已确认定稿。
3. 用黑白块先检查：第一眼能找到头/主作用面，暗部连成大块，主体在真实游戏尺寸下仍有辨识度。
4. 先画待机、印击预备、落印三个关键姿势，确认身体确实能够完成动作，再做墨线、平涂与少量磨损。
5. 直接在真实战斗背景和手机尺寸中评审。通过结构评审后，再以墨灵校准墨线、青黑暗面、金色焦点和朱红强调，避免把墨灵的面具与背环复制成全员制服。

上面的门槛是本轮研究产出的制作建议；本轮没有执行新的重绘或替换。
