# 凉亭、假山与二层小阁

五件 Godot 原生模型，使用现有墨池调色板、暗瓦、丹青构件、石材平涂与清晰墨线；重点保留轮廓、梁柱、窗格和少量旧金收口。已经和现有围墙、荷花、持灯行者放在同一预览庭院中比较比例和光照。

接入更新：五件模型现已随[八类房间内设](../2026-10-18-furnished-rooms/index.html)用于庭院路线模式；本页保留制作阶段的单体与组合预览。

| 模型 | 落地占地约 | 造型 |
| --- | --- | --- |
| 四柱方亭 | 2.7×2.9 | 低石台、入口台阶、四柱与斜撑、三面坐槛、回纹梁枋、宽四坡瓦顶轮廓 |
| 六角凉亭 | 2.7×3.0 | 六角石台、六柱、攒尖瓦顶、挑起的檐角、石桌凳、背侧坐槛 |
| 低矮假山 | 2.9×1.9 | 偏置主峰、两侧陪石与前部低石，保留少量大石面和折线 |
| 洞石假山 | 2.75×1.9 | 瘦高错峰轮廓、不规则穿洞、厚实孔壁与低矮根石；洞口是真实开放网格 |
| 二层小阁 | 3.5×3.25 | 双层挑檐、二层环前阳台、窗格、门框、石阶、小灯笼与一处朱砂封条 |

屋面可跨出落地占地。所有模型接受原生灯光、接地阴影；亭与阁楼的屋顶支持独立淡化，结构仍保留。没有使用图片卡片或烘焙透视来代替建筑。

## 文件与使用

制作脚本：`src/map/garden_landmark_kit.gd`。

独立场景：

- `assets/expedition/garden/square_pavilion.tscn`
- `assets/expedition/garden/hex_pavilion.tscn`
- `assets/expedition/garden/low_rockery.tscn`
- `assets/expedition/garden/hollow_rockery.tscn`
- `assets/expedition/garden/small_loft.tscn`

本批按直接世界单位制作，场景根缩放为 **1**；不要套用旧围墙模块的 0.5 缩放。根原点是接地点 y=0，提供 `footprint`、`ground_contact`、`solid_footprints` 和入口连接点等元数据。凉亭额外标明石台面高度；阁楼为两层外观模型。

直接实例化会使用根节点的 `palette_source`。组合使用时，调用 `setup(shared_style)` 共用当前地图色板；原有石材、屋面、铜绿颜色选择器可继续调整这批资产。`set_roofs_faded(true/false)` 用于查看亭内结构与楼层关系。

## 预览

在 Godot 打开并运行 `res://src/tools/garden_landmark_lab.tscn`：

- 六种模式：五件单体 + 完整组合。
- 左键转看，中键拖看，滚轮缩放。
- 可切换暖灯、屋顶透视和落地占地。
- 单体旁保留同一个持灯行者作比例参照；组合沿用现有园林围墙与荷花。

`--capture` 可输出本目录的原生截图。01–05 为单体，06 为组合，07 为阁楼屋顶淡化，08 为地图约 52° 俯视角，09 为占地标记。

本轮完成模型与独立组合样板，尚未放入随机房间生成器，也没有新增二层行走规则或自动碰撞。未改地图玩法，未提交、未推送。
