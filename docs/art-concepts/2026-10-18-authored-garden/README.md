## 这张图如何组织空间

主池位于中西部，连着南面的水尾，以及北侧伸到息灯水榭下方的小水湾。东岸藏字水榭部分临水；南侧石桥只跨水口，池岸不再散布一圈独立奖励平台。

东侧与北侧是建筑密集区。门屋、照壁前庭、迎字厅和转廊构成入口组团；问字轩、转廊与南廊围出夹院；字肆后库、碑堂、书斋和折桂厅之间留下不同尺度的院地与夹道；北侧阁、堂与后书院紧邻布置。共用界墙，避免每个节点都自带一圈完整院外空地。

西岸与南岸以山石、怪松、红枫收边。听石轩和西南游步道承担对景与尺度变化，本稿没有将其开放为玩法支路。这一区域不是另藏一组奖励房，后续需要在灰盒中判断是否值得保留为可达的无奖励观景支路。

北侧后殿及其临池前庭形成终点组团。它和开始区域可以隔水相望，实际推进经东岸建筑内部抵达。视线的距离与行走的距离因此不同；观景箭头不代表穿墙可见或无视玩法迷雾。

## 玩法节点怎样落入园子

全图 18 个可选节点，三次二选一；共有 8 条完整路线，每条经过 12 或 13 个节点。入口保留两场普通战，首领前保留必经休息节点。这里使用固定内容排布来检验空间关系，未计算最终数值与奖励平衡。

| 顺序 | 空间表现 | 节点 |
| --- | --- | --- |
| 入园 | 门屋→照壁前庭→迎字厅→折入转廊 | 01 起点、02 普通战、03 普通战 |
| 第一支 A | 沿南廊到临水亭，过水口短桥 | 04 普通战、05 火堆 |
| 第一支 B | 夹院→问字轩，出侧门见水榭 | 06 普通战、07 事件 |
| 第一汇合 | 南门和东门分别进入藏字水榭 | 08 宝藏 |
| 第二支 A | 沿池廊转入字肆，过共墙月门进书斋前院 | 09 商店、10 事件 |
| 第二支 B | 沿池入听雨书屋，侧出镇碑夹庭 | 11 事件、12 精英 |
| 第二汇合 | 一支穿堂，一支侧入折桂厅 | 13 普通战 |
| 第三支 A | 短夹道到镇碑堂前庭 | 14 精英 |
| 第三支 B | 后书院→北侧阁楼与短廊 | 15 事件、16 普通战 |
| 第三汇合与终点 | 息灯水榭→后殿临池前庭→后殿 | 17 火堆、18 首领 |

三组选择借用的空间关系不同，不把三个分支都做成围绕一个小池的双翼模板。所有连边以四向折线记录，但目前仍是概念坐标，不能视作已经验证的通行格。

## 门禁与边界

- 三组分支各有入口和汇合端门禁，共 12 处支路门禁。选择一支时，未选支路的两端一起封闭；预览中以红色封门表示。
- 第一组利用南廊背墙、问字轩和转廊分隔两支；第二组利用书屋、字肆后墙和东西院界分隔；第三组利用后书院界墙及藏经阁背墙分隔。
- 空间相邻、隔窗看见、共用背墙均不自动增加游戏连边。堂内、廊下和院地的节点须以出口开放条件保证结算。
- 图上的屋面只表示建筑体量；墙体开洞、屋檐悬挑、柱网、地面扣水与可走净空需要下一阶段灰盒共同落实。不能直接把本图的浅色地面全部设为可走，也不能仅凭预览封门效果宣称防绕行已完成。

本稿补过夹院与南廊之间、夹院与书斋支线之间的分隔，并为阁楼连廊留出院界缺口。仍须用实际模型检查通廊宽度、转角与入口尺寸，届时允许局部挪墙和扩台，不改变主要空间意图。

## 已有素材如何复用

| 空间 | 现有素材用途 |
| --- | --- |
| 临水节点 | `water_pavilion`、`square_pavilion`、鬼火、荷花与大小莲叶；水池由连续岸线组织 |
| 成组建筑 | `small_loft`、亭阁、门阙；后续补能够相接的厅堂屋面和立面段 |
| 廊与界墙 | `covered_walk`、园林围墙和漏窗；改为连续段与共同边界，角柱不能重复叠放 |
| 内设 | 字摊、后库、书桌、字架、墓碑、香炉、灯和石凳按空间用途摆放 |
| 岸边与借景 | 怪松、红枫、其他树木、低假山、洞石；保留岸边停留点，不均匀铺满四周 |

暂不新增美术模型。屋顶下的厅堂结构及连廊接缝是否需要新模块，应在手工灰盒中确认。

## 后续随机化应保留什么

本图是一个人工设计的空间骨架，不能直接当作所有种子的固定答案。若方向成立，应另做具有不同主池位置、建筑组团与入口关系的骨架，再从中提取变化约束。

可先变化节点内容、同组团中的门位、短廊开闭、部分阁楼／侧院用途、岸线小湾和植物位置。主厅朝向、水榭接岸、主要对景、分支分隔与净空应作为联动关系保留，不能逐个模型独立打乱。
