# 字网图谱交互

从标题页选择“字网图谱”进入。页面采用用户提供的 taopunk 参考包中的环境底图，搭配深青铜板、切角字块、暖金与朱砂配色，主题仅作用于图谱页。

## 浏览

- 滚轮或右上角 ＋ / − 缩放，缩放围绕鼠标位置进行。
- 拖动空白或按住中键拖动，平移画布。
- 字块可以单独拖动；松开后周围字块会让开，保留最小间距。
- 点击字块查看单字效果、相关词语和前后连接字；点击连接字可以继续浏览。
- “只看相关”隐藏与当前字没有直接连接的字；“总览”清除选择并重新显示完整网络。点击空白也可清除选择。
- 输入字或完整词语，回车或点击“寻字”定位；按词查询会打开完整词效。
- 相关词语使用精简说明，点击词名或悬浮关键词可查看完整规则。
- “全部”“已实现”和“初始字袋”从数据库读取；初始范围只包含起始字袋能完整组成的词。

箭头 A → B 表示词中 A 后紧接 B；一条关系可被多个词共用。字块色调对应字的主要体系，大小随连接数量略微变化。

## 布局修复

原布局会在容器尚未完成排版时，把节点坐标缩放进过小的可用区域；后续每次 resize 又继续缩放已改变的坐标，造成节点聚集及相互覆盖。

现在使用确定性的世界坐标布局和节点间距约束，窗口适配只改变相机位置与缩放。查询、选择及浏览不创建游戏实体，也不消耗游戏随机数。
