# 遗物接入说明（第二批）

日期：2026-10-19。对应代码：`src/core/relics.gd`，测试：`tests/relic_batch2_test.tscn`。
设计来源：`docs/遗物设计清单_2026-10-15.md`。清单里的待定项先按第 7 节的讨论建议取默认值，下表逐条列出，都可以再改。

主分支（#14）已经实现了其中 7 件：空铅盒、留字蜡（不稳定字模）、朱砂印泥（树脂）、补字鬼手（魔术手）、裂墨瓶（坏电池）、褪墨（临期食品）、乱文骨骰（混乱转化）。本批补上剩下的 13 件，命名沿用主分支「冥府镇物、葬仪与庭院旧物」的风格。至此清单条目全部接入。

取得方式：经典模式走精英、首领、事件、商店；新的横向路线（房间地图）和远征走各自的奖励与商店。三处都用普通遗物池（`Relics.normal_pool()`），事件专属遗物照旧只由事件发放。需要挑字或许愿的遗物，拿到时会弹出选择：经典模式和房间地图关窗就随机挑，远征用面板选。

|---|---|---|---|
| R01 消消乐 | 连字环 | 稀有 | 每次出字后全盘下落，和其他重力遗物一起按获得顺序结算。每场开局自动出词：长词优先，同长度按左上起点，打完补回腾空的格子再找，最多 30 次。要选目标、要付费、要额外交互的词，还有【死亡】，都留给玩家 |
| R04 ？字 | 问字签 | 少见 | 开局给 3 枚候选，优先能和盘上字组成二字词的。选中的字作为本场临时字落到随机空格；盘满时放到袋顶 |
| R05 金字 | 泥金笔 | 少见 | 拾取时挑两枚永久实体镀金（按实体算，不影响之后拿到的同字形） |

## 已知问题

- 【死】【亡】【月】标成彩蛋字，不进奖励池，只能靠遗物拿到。【死亡】【反死亡】在图鉴里照常可见，没有做「发现前隐藏」。
- 问字签的选择只在战斗界面弹出；自动对局（harness）不会替玩家选，候选会一直留着。
- 卖掉许愿笺以后愿望效果停止，但已经发生的改变（字袋变字、生命上限 1）不会恢复。
- 连字环开局连出的词不播放出字动画，只写战斗日志。
