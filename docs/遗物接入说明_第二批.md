# 遗物接入说明（第二批）

日期：2026-10-19。对应代码：`src/core/relics.gd`，测试：`tests/relic_batch2_test.tscn`。
设计来源：`docs/遗物设计清单_2026-10-15.md`。本批补齐清单剩下的 16 件原案和 4 件补充提案。清单里的待定项先按第 7 节的讨论建议取默认值，下表逐条列出，都可以再改。

取得方式和第一批一样：经典模式走精英、首领、事件、商店，远征走中赏、大赏、商店。需要挑字或许愿的遗物，拿到时会弹出选择。经典模式关掉选择窗就随机挑；远征模式用面板选。

## 已知问题

- 【死】【亡】【月】标成彩蛋字，不进奖励池，只能靠遗物拿到。【死亡】【反死亡】在图鉴里照常可见，没有做「发现前隐藏」。
- 问字签的选择只在经典战斗界面弹出；自动对局（harness）不会替玩家选，候选会一直留着。
- 卖掉愿文以后愿望效果停止，但已经发生的改变（字袋变字、生命上限 1）不会恢复。
- 连珠盘开局连出的词不播放出字动画，只写战斗日志。
