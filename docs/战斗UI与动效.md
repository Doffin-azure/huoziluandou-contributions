# 战斗 UI 与动效

## 视觉与交互

采用已确认的宣纸、木活字、朱砂方向。字盘是主体，词效预览和结果共用独立区域，战报默认收起，鲸鱼不出现在战斗界面。字块箭头和序号表示路径；污染、临时、融合、镀金仍有文字标记。

电脑横屏采用左词效、中字盘、右战况。触屏或宽高比至少 1.95 时改为左战况、中字盘、右词效；结束回合移到左下侧，避免和出字误触。主操作至少 48 逻辑像素；窗口缩小到手机尺寸时增加字体与触控区域，844×390 渲染验证中主操作至少 48 屏幕像素。真实触屏输入支持拖动、回退、取消和松手即出字，不重复处理系统生成的模拟鼠标事件。

再次点击选中的字撤销该字及后续路径，保留其前面合法的相邻路径；再次点击首字清空选择。点击取消后的轻微鼠标或触点移动不会马上重选同一枚字，也不会误触松手出字。拖动回退仍保留经过的字，与点击撤销区分。

玩家气血使用独立的大号数值与生命条：电脑放在左上角，手机放在左侧战况最上方，受击和治疗同步更新。战斗只保留右上角一个「菜单」入口，字袋、战报、设置、返回主界面和退出游戏收进同一个菜单；底栏显示字堆数据、操作提示或手机 Buff 图标。设置关闭后返回菜单，菜单转入字袋/战报时保持正确的输入锁，不重复叠加菜单。

## 表现时序

- 选字抬起约 80 ms；无效词轻抖，保留原路径并给出原因。
- 有效出字释放约 110 ms，词语沿短弧线投向真正目标约 200 ms。
- 每个实际结果间隔约 160 ms；敌人行动前蓄势约 120 ms。伤害、格挡、拆盾与治疗按顺序反馈，多段攻击逐击显示。
- 血条前景收缩约 120 ms；伤害残影延迟 100 ms 再用 300 ms 追上。击败后留出 350 ms，再进入奖励或失败界面。
- 补字淡入和小幅落位，已有字按实体 UID 从原位置移动，约 180 ms。不同规则结果不靠解析战报字符串猜测。

设置“减少动效”关闭空间移动、墨迹爆发、桌面震动及血条残影，保留数值与结果；不改变战斗规则或随机数。全程不修改引擎全局速度，不做全屏闪白。

## 2026-10-14：减法与发动接入

“出字 / 发动”和“清除”从左侧纸面移至字盘下方，结束回合仍与主操作分开。降低木面反光、磨损和字块纹理对比，撤去备用活字、金属印台及主操作下面的散纸。保留书房光影和纸木材质。

状态与能力由 `StatusDisplay` 汇总，用小型字印显示层数；悬停或点击查看说明，超出容量时集中到详情页。手机将玩家 Buff 移到底栏，避免挤占气血、敌人生命和意图。

目标选择规则原本仍在规则层，但战斗页遗漏了 3×3、整行目标和六种 interaction 接入。现补齐 2×2 / 3×3 / 整行的区域预览、鼠标和触屏改选、回车发动及 ESC 取消，同时接入急转、左右、收放、火急、收回和收复。选择途中不消费发动材料；取消火急退还揭示字。两个格子和多选字使用独立目标高亮，改变普通连词会取消旧的待发动动作。

单字“重”及实际触发重力的词在落字表现后触发约 240 ms、最大 7 px 的短震动。3D 桌面与原生 HUD 同步移动；重击为较弱的 3.5 px 震动。退出战斗和减少动效都会复位，不改全局时间流速。

`BattleAudio` 缓存六种原创合成音色：选字、出字、受击、格挡、重力落字、回复，每种三种变化，八路播放器复用。使用独立美术随机数，伤害音效按真实结果队列播放；设置提供持久化音效音量和静音。本轮未加入背景音乐，当前音色是用于检验手感的基础版。

新增回归：`tests/battle_presentation_regression.tscn`。使用 `--capture` 导出实际桌面、手机、区域选择和 Buff 图标截图及 `shots/battle-audio-preview.wav` 试听；同样只生成在已忽略的 shots 中。

## 结构与验证

`Combatant.feedback` 报告已结算的生命和护盾结果，`BattleState.enemy_acting` 报告敌人行动顺序。战斗屏仅在自己的操作结算期间收集事件。规则仍同步结算，输入在短表现队列期间锁定。视图长期复用，切屏时取消等待并断开绑定，所有瞬态节点和 Tween 随战斗场景释放。

目标点击索引会转换为规则层使用的存活敌人索引，避免前面敌人死亡后攻击错目标。模态浮层阻断字盘快捷键和触点，选择回调仍可提交明确目标。

验证命令（用本机 Godot 可执行文件替换 `<godot>`）：

```text
<godot> --headless --path . res://tests/logic_test.tscn
<godot> --headless --path . res://tests/battle_ui_test.tscn
<godot> --headless --path . res://tests/battle_presentation_regression.tscn
<godot> --path . --resolution 1280x720 --fixed-fps 30 res://tests/battle_presentation_regression.tscn -- --capture
```

最后一个命令运行实际渲染回归，把截图及音效试听保存到已忽略的 `shots/`。现有 battle_ui_test 覆盖快速连点、敌方多段攻击、格挡与破盾补字、死亡后的目标索引、原生触屏选择与撤销、菜单/设置/工具浮层切换、随机数隔离和动画中切屏。新增 presentation 回归覆盖区域改选、八类遗漏交互、结阵、能力图标、震动复位、静音和手机音量菜单。本机 Godot 4.7.2 / Forward+ 的 presentation 实际渲染 70 项、原有 UI 实际渲染 69 项通过；规则测试 246 项、词效测试 88 项通过。手机检查使用真实 844×390 窗口渲染尺寸，未在实体手机上测试。
