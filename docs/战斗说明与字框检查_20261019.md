# 战斗说明、状态与字框检查（2026-10-19）

## 范围与结论

检查当前 main 工作区的162个词、10种状态、4种污染，以及状态栏登记的62个能力名称（其中辅助标识不另占图标）。修复显示与解释入口，不新增永久镀红、镀蓝等玩法。

- 常驻界面展示名称、当前数量或短词效；完整规则通过悬浮展开，点击固定。
- 字框/字块状态仍只在点击对应格后出现在左侧；普通字和无标记空格不显示无关说明。
- 污染属于字块的负面状态；保留实体所有权，不误记为玩家身上的全局Buff。
- 162个词和61个单字已逐条重写为绑定当前参数的玩家文案；复杂词提供更短的战斗说明，细则留在词条。原始策划说明不再直接呈现给玩家。

## 镀金及颜色的含义

镀金已实现。战斗内「精金、投资、再投资、复利投资」通过实体UID选择一枚未镀金字；远征休息点、商店也有修饰入口。镀金保留到后续战斗，每次有效单字或组词按gild_gold获得金币，默认1；融合实体只计一次，单纯弃字不计，临时复制不继承。

| 视觉 | 实际含义 | 持续方式 |
| --- | --- | --- |
| 金框、金标签 | 镀金实体 | 跨战永久强化 |
| 红色选中框 | 当前出字路径 | 取消选择即消失，不是伤害强化 |
| 目标选区 | 当前技能指定位置 | 跟随选目标流程，不是实体强化 |
| 红/蓝签框 | 对校官标记 | 按对应怪物任务解除 |
| 签/爆/印/转框 | 其他敌方目标或区域标记 | 按实际制造怪物的当前任务解释 |
| 临、词、融合、叠层、精炼、固定 | 字块属性或本场强化 | 分别按对应词条的使用、回袋和战后规则处理 |

暂不建议仅为增加颜色而新增永久镀红/镀蓝：红、蓝已经承担交互及敌方标记。未来若增加新的永久强化，应先确定独立收益、消耗、期限、叠加/互斥规则，再配置名称、图标及颜色；不能只凭颜色猜效果。

## 后续实战反馈：折页蛾解签伤害变0

用户实战反馈后，从经典地图真实候选池开战复现：解签前8，打出带签字后意图0，真实攻击也扣0。并非单纯的数值显示问题。

原因是经典地图的ActData/MapNodeData嵌套引用原始EnemyData资源，数据库加载Excel时生成的配置副本没有替换这些引用。经典开战拿到的tuning为空，读取resolved_damage与reward时缺省为0，原始文字描述却仍保留5伤害和3奖励。因此，之前直接使用Database.get_enemy()的测试通过，真实地图入口仍有缺陷。

修复：数据库完成配置后复制经典地图，将候选池与固定敌人绑定到完成配置的怪物。不修改原始缓存资源、不强行把0替换成5。其他依赖机制参数的经典怪物也使用这一统一入口。

新增encounter_balance_test，从真实地图选敌并实际出字、结算敌人攻击：

- 修复前复现expected=5 / actual=0，且成词解签奖励同样丢失。
- 修复后默认配置：解签后意图5、实际扣5，成词解签奖励3。
- 自定义有效配置11：意图与实际伤害均为11。
- 自定义有效配置0：意图与实际伤害均为0，保留策划合法的零值。
- 覆盖所有经典地图候选池/固定遭遇的资源引用、重新加载、原始缓存不被污染。
- 新增回归74项通过。旧检查记录的1968项结果不代表曾覆盖此真实地图入口；此处明确补齐了测试盲点。

正在进行的旧战斗不会自动更新，需要重启游戏并重新进入战斗。

## 玩家文案重写

重写并接入162词、61字、名词/状态/污染解释，以及所有怪物说明。以效果、条件、期限为顺序，不用内部编号和参数清单解释玩法。普通签按来源分别显示折页签、双面签、压轨签；清心、净化与解签明确区分。

实际起始字袋也绑定统一玩家说明，避免数据库正确而开局仍使用旧文案。大量战斗结果仅常驻3行，其他结果可点击查看，完整结果不丢失。

词条中增加“即时效果”“持续能力”“净化”“负面状态”定义。常规效果直接显示参数；同为默认1的多个效果可分别调值，不再通过替换旧数字猜测含义。长词加成在配置启用时单独说明。
