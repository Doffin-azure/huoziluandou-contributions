# 事件：无字灯

日期：2026-10-18。状态：已接入，替代旧「飞花令」`feihua_ling`。

## 定位

一个随机灯谜池事件。玩家看到的只有谜面，不显示谜底，也不显示具体奖励；选中一盏灯后，才按谜底发字并结算隐藏收益。

- id：`lantern_riddle`
- 幕：1、2、3
- 权重：0.6
- 标签：`character`、`riddle`、`game`
- 出处：《文心雕龙·谐隐》

> “谜也者，回互其辞，使昏迷也。”
> 廊下悬着三盏无字灯，灯腹里各藏一道字谜。鬼火说：射中哪一盏，哪一盏就归你。

## 抽题

- 数据：`src/data/lantern_riddles.gd`
- 当前 16 个谜底、33 条谜面。
- 每次先从简单/中等/困难各抽一个不同谜底，再从该谜底的多条谜面里随机取一条。
- 三道题答案不重复。
- 选项只显示谜面 + “（打一字）”，不显示谜底和效果。
- 事件开始后把抽到的选项写入 `event_data`，退出重进不会刷新。

## 谜题池

### 简单

- 合：一人一个口不能分开走 / 拿不出手 / 去一人还有一口，去一口还有一人
- 分：八把刀
- 灯：大小参差光照人 / 男儿一生有离合 / 用火一定要小心
- 加：动嘴又出力
- 连：坐滑板的车
- 清：情人无心空流泪水 / 沱江水 / 绿化西湖

### 中等

- 回：表里如一 / 格外大方
- 火：烟消日出不见人 / 人间牛女双星 / 丢人现眼
- 电：卷尾猴 / 俺大人不在 / 太阳照在金钩上
- 破：一边软如纸，一边硬如铁，软的做鞋穿，硬的把墙砌 / 石头太顽皮
- 停：一人站在小亭边 / 人在亭边歇
- 超：招手不见走来
- 速：方木运走一半

### 困难

- 重：千里相逢 / 千里姻缘一线牵
- 心：斜月三星洞 / 一钩残月带三星 / 片云残月带三星
- 金：一得之余 / 一个人他姓王，口袋里装了两颗糖

## 隐藏收益

所有选项都先发谜底字；如果字袋里已有这个字，奖励不同。

| 难度 | 没有该字 | 已有该字 |
|---|---|---|
| 简单 | 获得谜底字，金币 +6 | 额外金币 +10 |
| 中等 | 获得谜底字，金币 +8 | 额外回复 8 气血 |
| 困难 | 获得谜底字，回复 12 气血 | 额外最大气血 +3 |

选项文案不显示这些数值。

## 实现

- `LanternRiddles.fill(event, rng)`：事件开始时生成三道动态选项。
- `RoomRunState._start_event()`、`RunHarness._start_event()` 和老版 `EventScreen` 都会调用 `fill()`；庭院事件数据会保存已抽到的题。
- 选项效果由现有 `if` / `has_glyph` / `gain_character` / `gold` / `heal` / `max_hp` 组成。`if` 在 `gain_character` 之前检查，保证“已有该字”的判断成立。
- 不新增 UI；仍然使用普通事件的三按钮。
