原始 Control 点击入口统一补充原生触屏处理：自定义字块、图鉴卡片、奖励/商店字块、路线节点、图谱节点、敌人目标。以手指释放且未滑动/取消为一次点击，忽略该触屏对应的模拟鼠标事件，保留真实鼠标与键盘操作。

合计 385 项通过。最终日志归档在 [logs](logs/)，无脚本错误。测试过程发现的卡片输入遮挡、关闭后延迟布局回调与词条外点穿透问题均已修复后重测。

APK 集成时另发现：Godot 的模拟鼠标按下先于原生手指按下。旧写法会先打开说明，随后同一手指事件落入新浮层背景并把它关闭；普通加字也可能执行两次。最终改为原始 Control 始终忽略触摸生成的模拟鼠标事件，只响应原生手指释放，真实鼠标不受影响。测试从仅派发 Viewport 事件升级为完整 Input 输入流，已复现旧故障并验证修复。

滚动列表中的原始点击控件使用 PASS，让尚未确认为点按的输入可以传到 ScrollContainer。成功的原生点按才消耗事件。Android 实际滑动已验证列表位置发生变化且字袋计数保持不变。

复现触屏专项与截图：

```powershell
godot --path . --rendering-method gl_compatibility res://tests/touch_access_audit_test.tscn -- --capture
```
