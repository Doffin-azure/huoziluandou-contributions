# 日志精简与手机负载修复 · 2026-10-19

战斗和远征保留最近的结果记录。减少常驻文本和控件创建，缩小存档携带的历史数据；保持伤害、治疗、状态、词效等消息原有含义。

## 修改对照

| 项目 | 修复前 | 修复后 |
| --- | --- | --- |
| 战斗模型日志 | 最近 120 条 | 最近最多 32 条 |
| 战斗界面日志 | 最多 80 个独立 Label；关闭时仍逐条创建，并为每条消息等待下一帧滚动 | 关闭时只更新小型记录；首开前 0 个文本控件；打开后复用 1 个 Label，同一批消息合并刷新 |
| 远征日志 | 最近 40 条；地图刷新时逐条销毁并重建 Label，手机隐藏页也一样 | 最近最多 32 条；隐藏页不更新文字；打开后复用 1 个 Label，内容相同则跳过赋值 |
| 日志文本预算 | 只有条数限制 | 每条最多 160 字，每份记录合计最多 4096 字；超出时移除最旧消息 |
| 重复消息 | 重复占用多行 | 连续相同消息显示为 `格挡 +2 ×32`，不同结果保留原顺序 |
| 存档 | 把全部现存日志随模型编码/解码 | 写入时裁剪副本；旧档先选取近期条目再解码，不改变原有字段结构 |
| 战报浏览 | 每条消息都创建一次滚动等待 | 批量刷新；排版完成后滚至最新消息，保留滚动查看功能 |

战斗日志按时间正序显示，默认滚至最新消息；远征日志保持最新在前。日志裁剪不参与战斗规则或随机数计算。

## 验证结果

- 日志专项：28 项通过、0 失败，含一万条消息压力检查、单条/总字数限制、重复折叠、手机战报布局与自动滚动、关闭期间零文本创建、远征页切换、控件复用、旧档迁移、模型与 RNG 不变。
- 战斗交互回归：60 项通过、0 失败。
- 自动存档回归：44 项通过、0 失败。
- 词效回归：411 项通过、0 失败。
- 远征回归：159 项通过、0 失败。

合计 702 项检查通过、0 失败。

本机原生 Compatibility 渲染器的专项压力检查中，关闭战报时同步写入一万条模拟消息约 77 ms，结束后保留 32 条；首次打开只创建 1 个 Label。该数字用于检查有界处理开销，并非手机真机帧率数据。

构造的旧档样本中，战斗/远征各含 5000 条日志，重新保存后整个模型图由 306284 字节缩至 35948 字节。该比例仅适用于此压力样本，普通存档的缩减比例取决于原有日志量。
