# 内置字盘字体验证

保留默认宋体，新增楷体、草书；手机无需上传或选择文件。设置只保存白名单 ID，旧外部路径自动清除，运行时不解析外部字体。字体仅改变字盘；正文和数字继续使用原内置宋体。新增字体许可、下载来源及 SHA-256 保存在 assets/fonts/，三份许可均已确认进入 APK。

| 选择 | 实际字体 | 当前游戏字库缺字 |
|---|---|---|
| 宋体标准 / 细体 / 粗体 | 思源宋体，650 / 450 / 850 字重 | 无 |
| 霞鹜文楷 | LXGW WenKai Regular v1.530，楷体 | 无 |
| 龙藏草书 | Long Cang Regular，草书 | 无 |

字体覆盖检查遍历全部 61 个游戏汉字。源码、资源和场景共 1240 个非 ASCII 字符由内置宋体完整覆盖；草书缺少的部分符号可回退到内置宋体。各字体均关闭系统字体回退。两个原来依赖系统字体的叉号已改为字体自带的 ×。

手机安装包：build/android/20261018-builtin-fonts/huoziluandou-builtin-fonts-arm64.apk。测试签名与此前包一致，可覆盖安装。版本号 2026101802。文件大小和 SHA-256 见 verification.json。

Android 截图来自真实 Android 模拟器，使用 GL Compatibility 与 host GPU；未连接实体手机。测试期间模拟器曾离线，重启后恢复；另尝试的软件渲染器因 GLES uniform 限额而未能正常绘制，已恢复 host GPU，该失败画面未作为通过证据。手机 APK 保留默认渲染方式。
