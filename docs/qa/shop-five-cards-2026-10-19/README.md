# 商店五张卡牌与金币文字对比度

经典及远征商店每批出售的字卡从 3 张增加到 5 张，刷新也补齐 5 张。经典商店新增后排陈列架，将五张卡牌以 0.78 倍大小排开，前排保留三件遗物，服务印台仍位于右侧。购买后保留原槽位；减少动效不会把紧凑卡牌恢复成旧尺寸。

价格、余额及刷新费用使用亮米金色 `#fff2b0`、深墨色描边和阴影，在受光纸面、木面及暗部都可读。颜色调整限定于相关货币标签，未改全局装饰金色。

五卡陈列按相邻投影中心划分点击边界，避免透视边框重叠导致误点。旧存档的服务/遗物槽位迁移到新布局，保持库存与已付费用；不会重复迁移。旧三卡货架保留至下次刷新，再补成五卡。

固定种子快照只更新 `shop` 与 `shop_rng`：新增两张卡会推进商店 RNG，因此后续服务报价也按同一随机流变化。原有奖励、事件及对应随机状态逐项保持一致。
