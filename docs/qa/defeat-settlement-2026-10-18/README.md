# 失败结算 · 2026-10-18

战斗生命归零后，等待当前表现步骤结束，转入独立的「力竭」结算页。经典冒险和墨途远征均适用。

## 行为对照

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 失败展示 | 通用「力竭」选择浮层，仅有重开、返回 | 独立结算页，显示模式、幕、遭遇、总分及六项明细 |
| 动画 | 无结算表现 | 明细逐项显现，总分逐项累加，约 1.92 秒；按钮和回车可跳过 |
| 减少动态效果 | 无对应结算动画 | 立即显示完整明细与最终总分 |
| 手机横屏 | 通用浮层 | 短横屏采用两列明细，三项操作均保留至少 48dp 触控高度 |
| 规则说明 | 无 | 动画结束后「跳过动画」变为「计分规则」，点按可阅读算法 |
| 结束存档 | 直接清档 | 先生成纯数据快照，再发出一次失败结束事件，由存档管理器清档 |
| 模式重开 | 在旧战斗页处理 | 从结算页重开对应模式，失败局不能继续存档 |
| 远征跨幕成绩 | 无结算记录 | 换幕前将已处理地点、已击退伏兵归档到现有 `visited` 字段 |

## 分数规则

总分为下列六项的和，均为非负整数：

| 项目 | 规则 |
| --- | --- |
| 行旅足迹 | 经典模式每个已完成节点 100；远征每个已处理地点、已击退伏兵 100，同幕同地点只计一次 |
| 破关 | 每个已经击败首领的幕 500 |
| 末战击倒 | 失败战斗中，每名已经倒下的敌人 30；先前胜场通过完成节点计分 |
| 末战攻坚 | `floor(末战敌方净损失气血之和 / 敌方最大气血之和 × 战斗基分)`；普通 30、精英 75、首领 150 |
| 收集遗物 | 当前每件遗物 40；不包含远征印章 |
| 余金 | 剩余金币 × 5，最高 300 |

末战攻坚读取当前净损失气血，忽略护盾、伤害日志和回合数；反复造成伤害再治疗、空过回合、来回走动不会反复加分。岔路的精英挑战同样使用 75 的基分。攻坚明细显示精确的损失气血/最大气血，避免百分比取整造成的公式误差。

例如：完成 3 个地点、通过 1 幕、末战击倒 2 名敌人、获得 75 攻坚分、持有 1 件遗物和 20 金币，则总分为 `300 + 500 + 60 + 75 + 40 + 100 = 1075`。分数不兑换局内货币。

兼容说明：沿用现有存档字段，不改变存档结构。升级前已离开的远征幕没有保留地点清单，无法追溯那些地点分；已过幕的破关分仍可按幕数计算。从这次改动后的换幕开始保留完整地点记录。
