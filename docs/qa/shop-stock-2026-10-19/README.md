# 随机遗物现货与紧凑刷新转轮

> 后续已将商店字卡数量从三张增加到五张，并增强金币文字对比度，见 [五卡商店](../shop-five-cards-2026-10-19/README.md)。遗物现货与稀有度定价规则继续沿用。

移除上一版本的通用「买遗物 · 45金」大按钮。经典与远征商店改为随机抽取至多 3 件尚未拥有的遗物，商店只能购买这些现货。物品和价格随存档保存，查看说明不重抽；买走一件只移除该件，其余现货保留。经典商店用稳定展示槽留下空位，主动刷新后才补货。候选池不足 3 件时只上架剩余件数，全部拥有时不再生成。

价格读取项目已有 `Relics.TIER` / `Relics.price`：常见 35、少见 50、稀有 70 金币。移除统一 45 金币常量；旧经典商店存档中保留的遗物现货也按当前档次价格显示与结算。

经典商店逐件展示 3D 器物，共为现有 15 件遗物建立小型几何模型。每件陈列显示名称、价格和稀有度，点击该件查看效果并确认购买，绑定类沿用选字流程。余额不足仍可查看说明。模型采用现有铜、纸、墨、石材质；本次没有新增 PNG 贴图。

刷新移到柜台左侧的小型铜制转轮，用回转符号、小字「换货」和当前费用标识；不再占据柜台正面。保留每家店 5、10、15……的递增费用和服务保留规则。

## 验证

Godot 4.7.2；截图来自真实桌面 OpenGL Compatibility 渲染器。三档窗口覆盖鼠标、触控事件和键盘操作，点击区保留至少 48px。未构建 APK、未做安卓真机验证。渲染器只有既有景深/体积雾不支持提示。

|---|---:|---:|
| `shop_actions_test` 原生：随机现货/分档价格、20 种种子 RNG 隔离、15 件模型构建、指定物品购买/取消/绑定、售罄空位、真实存档恢复、递增费用、三档原生输入与 10 张截图 | 108 | 0 |
| `classic_relic_test`：经典奖励、三件现货、按价扣款与五档横屏 | 60 | 0 |
| `shop_refresh_test`：经典/远征递增费用与服务保留 | 24 | 0 |
| `object_stage_test`：实体物件、动效、购买及布局 | 18 | 0 |
| `autosave_test`：经典/远征真实存档恢复 | 44 | 0 |
| `relic_test`：全部遗物效果、远征三件现货购买、绑定与守恒 | 120 | 0 |
