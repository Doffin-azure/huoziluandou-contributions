# 商店刷新与出售遗物

> 此版本已废弃。用户澄清需求为「买遗物」，经典商店的出售入口和相关实现已经移除。当前实现与验证见 [购买遗物与刷新货架](../shop-purchase-2026-10-19/README.md)。以下仅为历史记录。

经典商店右下角显示「刷新货架 · 5 金币」，刷新字与遗物、保留未购买服务；余额不足时禁用。

右上角新增「出售遗物 · 数量」按钮。列出持有遗物、效果与售价，选择后再次确认；确认才移除遗物并发放 `Relics.sell_price(id)` 金币（现有档次价格的一半）。出售清除对应绑定、胜场计数，保留一局一次的赠字标记。没有遗物时禁用按钮。打开出售窗口期间不允许刷新、购买或离开；取消不改变状态。出售结果自动存档。

远征商店已有刷新及逐件出售入口，继续沿用。

Godot 4.7.2 验证：

- `shop_actions_test`：原生窗口 43 通过 / 0 失败，含取消、重复确认、出售后解锁刷新、绑定/计数清理、货架与 RNG 不变、真实存档恢复和三档横屏布局；截图 9 张。
- `shop_refresh_test`：17 通过 / 0 失败，覆盖经典与远征刷新、余额不足、服务保留。
- `classic_relic_test`：60 通过 / 0 失败，覆盖遗物领取、购买、刷新、存档及五档横屏。
