# 商店实体机关与递增刷新费用

> 本版本的两个大型机关与统一遗物价格已被替换。当前实现为随机三件遗物现货、按稀有度定价和紧凑刷新转轮，见 [当前商店](../shop-stock-2026-10-19/README.md)。以下为历史记录。

经典商店的「买遗物」与「刷新货架」入口改为柜台前沿的 3D 铜框机关牌。边框、底座、可动面板为实际网格，名称和价格为 Label3D；透明原生输入控件跟随相机投影，保留鼠标、触控、键盘和悬停说明。按下有机械下沉反馈，减少动效立即停止。余额不足及售罄时面板和文字变灰。原顶部购买按钮和右下角刷新按钮已移除，购买仍展示遗物完整说明并保留确认、绑字和自动存档流程。

刷新费用每家店从 5 金币开始，成功刷新后增加 5：5 → 10 → 15 → 20……。支付不足、弹窗、绑字或购买动画期间不扣款、不刷新、不涨价。经典商店的计数随货架存档；远征商店按地图位置记录，离开后返回保留费用，新商店从 5 开始。旧存档缺少计数时默认 0 次。未购买服务保留，已购买服务不补回。

为避免商品价格覆盖机关，字的价格移至字牌上沿；遗物价格显示在购买机关上。
