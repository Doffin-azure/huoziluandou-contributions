# 自动存档验证（2026-10-18）

本次新增一个本地自动存档槽，主线、自定义字袋开局与墨途远征共用。标题页有存档时显示「继续冒险」；暂停菜单提供「保存并返回主界面」。开始新冒险替换存档；通关或失败清除存档。

## 保存范围

| 项目 | 保存内容 / 恢复行为 |
| --- | --- |
| 主线 | 幕、节点、已完成路径、生命、金币、投资到期、永久能力 |
| 字袋和遗物 | 实体 UID、强化后的效果、镀金、遗物绑定与计数 |
| 墨途远征 | 原地图、迷雾、位置、首领追击、步数、版面、字匣、机关、商店与待处理面板 |
| 战斗 | 字盘、抽字袋、弃字堆、敌我生命/护盾/异常、敌方意图序号、回合、持续能力和随机序列 |
| 奖励 / 商店 / 事件 | 当前选项、价格、售出记录与随机序列，继续时不重抽 |
| 未完成操作 | 动画播放、选字、放置或未完成购买期间，不覆盖上一完整操作的快照；恢复时整笔回退 |
| 配置 | 字体等设置沿用独立设置文件，不随冒险存档回滚 |

使用 `user://adventure.save` 和 `.bak` 交替保留两代数据；先写 `.tmp`，刷新并关闭后替换目标槽。载入时校验 SHA-256、格式版本和模型类型，优先恢复最新有效数据；中断写入或最新文件损坏时使用其余有效副本。校验用于检测损坏，并非防作弊加密。解码仅允许固定的游戏数据模型，不从存档加载脚本、路径、场景或通用 Object。

只在完成操作/进入界面时捕获快照，相同数据不重复写盘；文件写入由后台线程完成。切到后台、关闭窗口、菜单退出时等待已排队的写入完成。Android 覆盖安装使用 `adb install -r`，保留设置和存档；卸载或清除应用数据会移除本地存档。不提供云同步。
