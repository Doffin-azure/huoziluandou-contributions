# 商店购买遗物与刷新货架

> 后续已将两个入口改为 3D 实体机关，并将刷新费用改为每次递增 5 金币。当前实现及验证见 [商店实体机关](../shop-physical-2026-10-19/README.md)。以下为上一版本记录。

按用户澄清，将上一轮新增的出售入口改为「买遗物 · 45金」。点击展示本次货架遗物的名称、完整效果及售价，确认后调用原有购买/绑定流程。取消不扣款，余额不足时禁用，购买后显示「遗物售罄」。右下方「刷新货架 · 5 金币」补充尚未拥有的遗物与字，未购买服务保留。商店的出售入口及新增出售代码已移除。

购买结果、货架和金币自动存档。弹窗期间阻止底层刷新和购买，重复确认不重复扣款。压字石等绑定遗物进入选字流程，关闭按原规则随机绑定。

Godot 4.7.2 验证：

- `shop_actions_test`：原生 41 通过 / 0 失败，覆盖购买按钮、取消、余额不足、重复确认、库存耗尽/刷新、绑定流程、实际存档恢复、三档横屏；含 6 张截图。
- `shop_refresh_test`：17 通过 / 0 失败。
- `classic_relic_test`：60 通过 / 0 失败。

合计 118 项通过。测试使用独立配置和存档，未构建 APK。
