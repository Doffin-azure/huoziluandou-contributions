# 控制台遗物测试

调试构建按 F1 / 反引号打开控制台。

| 命令 | 行为 |
| --- | --- |
| `/relic-test` 或 `/relic-test all` | 运行全部 15 件遗物的效果自检，显示实测值与预期 |
| `/relic-test 天火` 或 `/relic-test skyfire` | 只验证指定遗物 |
| `/relic-status` | 查看持有与本场实际遗物、绑定 uid、额外次数、繁殖母本、下次重力方向、胜场进度 |
| `/relic-bind 压字石 击` | 绑定字袋中未被其他遗物占用的【击】 |
| `/relic-bind slab #123` | 精确绑定永久实体 uid |
| `/relic 天火`、`/relic all`、`/relic - 天火` | 原有领取、全部领取、移除功能；改动请求自动存档 |

战斗中领取、移除、换绑在下一场生效，避免重复叠加开局效果。两件绑定类遗物自动领取时会选择不同的实体；没有可用实体时，可通过状态命令发现缺失并手动绑字。

自检采用固定种子、临时字袋和模型，覆盖真实出字、回合推进、下落、繁殖、拾取及胜场钩子；不会切换场景。同步执行期间阻塞 EventBus，结束后恢复 GameState 原对象引用、随机序列、实体 uid 分配器和原信号状态。

## 验证

环境：Windows，Godot 4.7.2，桌面 headless；未启动手机调试、未构建 APK。

- `tests/debug_relic_test.tscn`：41 通过，0 失败。包含 15 件遗物整批/逐件中文名调用、活跃远征与战斗完整快照不变、原对象引用不变、随机序列与 uid 不变、无事件泄漏、磁盘存档哨兵原样保留、绑定冲突/错误参数、本场绑定不变以及当前调试规则不受影响。
- `tests/autosave_test.tscn`：44 通过，0 失败。
- `tests/relic_test.tscn`：119 通过，0 失败，包含全遗物组合的 5 个种子、各 12 回合的守恒与稳定性检查。

自动自检是效果冒烟验证；原有遗物回归套件进一步验证与词、状态、复制层、固定、远征、商店和熔炉的交互。
