## 逐项机制与例子

### 1. 纸壳兵

- **数值**：第一幕普通，生命32，初始护盾8。
- **行动循环**：攻击6 → 护盾补至8。
- **机制**：补盾不攻击，也不是每次+8；当前盾已达8时不再增加。没有额外减伤、反伤或新甲片。
- **例子**：纸壳兵8盾，玩家用基础8伤、拆盾效率×2的击破，先拆8盾，剩余折算成4生命伤害，并触发击破的破盾补1字。若之后盾剩3，补盾行动只增加5。
- **应对词／操作**：击破、破甲、破、基础攻击。
- **选入理由**：拆盾教学，规则成本低。
- **原稿编号**：D01。

### 2. 连针蜂

- **数值**：第一幕普通，生命34，初始护盾0。
- **行动循环**：攻击3×3 → 蓄势、不攻击 → 攻击10。
- **机制**：三段小伤与单段重击交替。新版御只减下一次伤害2，不逐段生效；反单字在整次敌攻击结束后反击6一次，不逐段触发。提前建立的跨战防御力才逐段减1。
- **例子**：玩家无盾，单打御后承受3×3，三段为1、3、3，共损7生命。若只有此前已生效的防御力减1，三段各为2，共损6生命。
- **应对词／操作**：防御、御、反、提前建立的防御力。
- **选入理由**：展示伤害段数与减伤差异。
- **原稿编号**：D02。

### 3. 倾砚

- **数值**：第一幕普通，生命34，初始护盾0。
- **行动循环**：全盘向左重力 → 攻击7 → 中央2×2顺时针旋转 → 攻击7。
- **机制**：方向与旋转区域提前显示。重力只压缩该方向的空隙，不打乱相对顺序；固定字不移动，旋转遇固定字时整次跳过。没有额外的重击加成。
- **例子**：某行原为【击、空、空、破】，左倾后变为【击、破、空、空】，玩家下一阶段可直接连出击破。
- **应对词／操作**：重、转、左右、收放。
- **选入理由**：引入空间操作的正面收益。
- **原稿编号**：B01。

### 4. 折页蛾

- **数值**：第一幕普通，生命32，初始护盾0。
- **行动循环**：折页攻击5／8 → 攻击7。
- **机制**：折页前标记一枚非固定己方原实体。该字成功组词、单打或被玩家效果移出盘面，折页为5；未处理为8。通过组词解除时，额外对怪物造成3机制伤害。仅换位置不解除；原实体组词后因额外使用留盘也算完成。
- **例子**：【击】被标记，玩家用这枚击组成反击，折页从8降为5，蛾额外受3机制伤害。若只把击从左上移到右下，折页仍为8。
- **应对词／操作**：组词使用标记字、单打、重连。
- **选入理由**：区分使用实体与清空格子。
- **原稿编号**：C01。

### 5. 留白童

- **数值**：第一幕普通，生命36，初始护盾0。
- **行动循环**：留白攻击6 → 攻击8。
- **机制**：留白攻击前只检查一次：空格≥3，怪物受到3机制伤害；空格＜3，怪物获得4护盾。随后正常攻击6，不额外封格或减补字。
- **例子**：盘上14字、2空格，直接结束会使怪物得4盾。玩家打掉一个字且不补回，变13字、3空格，怪物改受3机制伤害，仍攻击6。
- **应对词／操作**：单打腾位、收心、重连、爆破。
- **选入理由**：教留空，不限制补字流。
- **原稿编号**：C03。

### 6. 墨蚀蠹

- **数值**：第一幕普通，生命38，初始护盾0。
- **行动循环**：攻击6 → 注入2枚刺痛【蚀】。
- **机制**：只向空格注入指定字形；该怪制造且仍在盘上的蚀最多3枚，满额不再补，不进入永久字袋。玩家可以单打蚀、净化、分流或借它组成心蚀。指定字形注入属于新增机制，不能直接沿用通用随机注字当作完成。
- **例子**：盘上已有2枚本怪的蚀，本次最多再放1枚。玩家先清洗，再用其中一枚蚀与心组成心蚀：没有刺痛伤害，怪物获得4层心蚀，此后每次行动后受4机制伤害，层数不自然衰减。
- **应对词／操作**：清洗、分流、心蚀、单打蚀。
- **选入理由**：污染有代价，也提供材料。
- **原稿编号**：D03。

### 7. 饕餮

- **数值**：第二幕普通，生命52，初始护盾0。
- **行动循环**：攻击10 → 吞1枚弃字并获得4护盾 → 攻击10+腹中字数、最高13。
- **机制**：腹中最多3枚己方原实体，移出当前循环但完整保存；吞取前展示目标，腹满或无弃字不吞、不加盾。玩家一次出字造成任一段实际生命伤害≥10，或一个词实际消耗≥3枚材料，吐一枚至袋顶；每次出字最多吐一枚。战斗结束全部归还。
- **例子**：腹中有2枚，末步攻击预计12。玩家一击打掉其12生命，吐回1枚，腹中变1，末步预计攻击降为11。若12伤全被盾挡住，不满足生命伤害条件。
- **应对词／操作**：回购、回收、单段HP伤害≥10。
- **选入理由**：考察真实实体循环与抢救。
- **原稿编号**：B07。

### 8. 炉腹兽

- **数值**：第二幕普通，生命44，初始护盾0。
- **行动循环**：攻击6后使玩家升热2 → 攻击8后使玩家升热2。
- **机制**：每次攻击前读取玩家热度，热度≥8则本次攻击+4；攻击后才升热2，走正常溢热生成污染规则。本次攻击后的升温不会追溯增强刚才那次伤害。
- **例子**：攻击6前玩家热度8，本次攻击10，随后热度到10。若玩家先用火爆清掉8热，造成8+4×8=40基础伤害，炉腹兽剩4生命，本次只攻击6，随后热度从0升至2。
- **应对词／操作**：火爆、热能、冷热、清热。
- **选入理由**：热度同时是风险和输出资源。
- **原稿编号**：D04。

### 9. 余电獾

- **数值**：第二幕普通，生命48，初始护盾0。
- **行动循环**：获得6护盾 → 放弧攻击10／6 → 攻击10。
- **机制**：只统计放弧前这一玩家阶段：实际储能消费减去对应这些消费的实际退款≥2，放弧前移除怪物最多6普通盾，攻击降为6；不足2则攻击10。阶段外旧消费的退款不反扣当前任务，储能正常获得不抵消消费。
- **例子**：本阶段花4储能，再复电返还2，净支出2，完成；若只花3再返2，净支出1，未完成。前一种情况下先拆最多6盾，再承受6攻击。
- **应对词／操作**：放电、蓄力、电热、合资支付。
- **选入理由**：为储能支付与退款安排时机。
- **原稿编号**：C05。

### 10. 赊墨商

- **数值**：第二幕普通，生命48，初始护盾0。
- **行动循环**：获得8护盾 → 催账攻击10／6 → 攻击8。
- **机制**：催账前一阶段内，第一次成功支付折扣后大于0的通用费用，取得收讫印。催账前有印则移除怪物最多8普通盾，催账降至6。临时资金、合资储能和金币支付均有效；失败、取消、折后0费均无效。每次挂账重置旧印。
- **例子**：玩家有5临时资金，回购实际付2资金并放回一枚原字，获得收讫印；催账前拆最多8盾，攻击6。若1费操作被币减为0费，不取得收讫印。
- **应对词／操作**：投、购、资金配付费词、投放。
- **选入理由**：给经济与付费调位实战价值。
- **原稿编号**：C06。

### 11. 双面简

- **数值**：第二幕普通，生命50，初始护盾0。
- **行动循环**：翻签 → 合简攻击12／9／7 → 攻击9。
- **机制**：标记同一行两枚非固定己方实体A、B和原坐标。玩家阶段内使两者完整互换原坐标，或用一个词同时使用两者，即完成，怪物受5机制伤害，合简降至7；仅将其中一枚单打／移出盘面，合简为9，无奖励；未完成则12。完整解优先于离盘降级，不能因组词消耗目标而误判为9。无合法目标时翻签得4盾，合简固定9。
- **例子**：A=充在第1列，B=电在第4列。玩家用左右交换两者，任务立即完成，简受5机制伤害，合简为7；若只单打电，则合简为9。
- **应对词／操作**：左右、急转、流利、普通组词。
- **选入理由**：直接检验新版空间操作。
- **原稿编号**：C07。

### 12. 铸巢蛾

- **数值**：第二幕普通，生命52，初始护盾0。
- **行动循环**：获得6护盾 → 啄字攻击11／7 → 攻击9。
- **机制**：啄字前阶段内，将真实己方原实体通过补字或回收效果放入盘面，再成功用它组词，移除怪物最多6普通盾，啄字降至7。开窗前已完成的基础补字不计；临时生成字、纯移动和重连返还不计。每题只拆一次盾。
- **例子**：玩家回购弃字堆的一枚击，再用这枚击组成反击，拆最多6盾，啄字为7；若用再生成临时击并组反击，词效正常，但啄字仍为11。
- **应对词／操作**：回购、收复、回放、流速。
- **选入理由**：体现真实回流与临时复制区别。
- **原稿编号**：C08。

### 13. 爆印机

- **数值**：第二幕普通，生命48，初始护盾0。
- **行动循环**：标记两格并把护盾补至6 → 攻击8后引爆两格。
- **机制**：两格选在同一2×2内，提前显示；标记绑定坐标，不跟随原字。引爆只摧毁仍在标记格的非固定字：己方原实体进弃字，敌方／临时字移除；防爆生效时原实体改回字袋，每救回1枚得1持久盾。叠层按一个格位处理，但其中原实体逐枚按规则回收。
- **例子**：标记格内分别有击、防，玩家移走击，又有新电补进原标记格。引爆摧毁电、防，不追踪已移走的击；若已启用防爆，两枚原实体回袋，共获得2持久盾。
- **应对词／操作**：收放、急转、爆破、防爆。
- **选入理由**：引入坐标标记，与实体标记区分。
- **原稿编号**：D06。

### 14. 拓印师

- **数值**：第二幕精英，生命62，初始护盾0。
- **行动循环**：攻击10 → 拓 → 攻击10。
- **机制**：拓读取其前一个玩家阶段最后成功的多字词，按固定优先级执行：攻击类→攻击10；防御类→得盾8；补字／空间类→注1枚堵塞敌字；经济类→得盾6；其余或没出词→得盾3。同一词多类取前者；不复制玩家实际爆发数值。单字不改记录。
- **例子**：玩家先打火爆造成40伤，最后打防御。拓只给怪物8盾，不复制火爆40伤。若最后是火爆，拓攻击固定10；精分可使这10攻击转向怪物自身。
- **应对词／操作**：控制收尾词、降温词、精分。
- **选入理由**：考出词顺序，避免复制爆发失控。
- **原稿编号**：B14。

### 15. 钤印官

- **数值**：第二幕精英，生命60，初始护盾0。
- **行动循环**：标记一个2×2印区 → 朱批 → 攻击10。
- **机制**：印区按坐标固定，朱批伤害=8+2×区域内剩余占用格数，最高16；只检查一次，不改变字的归属。流速补回的新字也算占格；区域内原地旋转不减少占格。新一次标记替换旧区域。
- **例子**：印区原有4格字，玩家打掉其中2格后没有补回，朱批为8+2×2=12。若流速把两格补回，仍占4格，朱批为16。
- **应对词／操作**：爆破、重连、收心、单打腾位。
- **选入理由**：集中考版面清理和补位取舍。
- **原稿编号**：B16。

### 16. 轮印师

- **数值**：第二幕精英，生命66，初始护盾0。
- **行动循环**：获得8护盾 → 压印攻击14／8 → 攻击5×2。
- **机制**：压印前阶段内，同一枚己方原实体参加两次成功多字词，即造成8机制伤害、压印降至8。只看原实体身份；相同字形的新复制不替代。合击中共享原实体参加两个实际结算词可完成；词效重演不增加次数。每题一次。
- **例子**：一枚精炼后的击有额外使用次数。玩家先用它出反击，再用同一枚出重击，满足两次；若第二次换成另一枚击，不满足。同一词内一枚融合体提供多个字形，也只算使用一次。
- **应对词／操作**：精炼、回购、回放、合击。
- **选入理由**：验收额外使用与材料共享。
- **原稿编号**：C09。

### 17. 漏电水蛭

- **数值**：第二幕精英，生命52，初始护盾0。
- **行动循环**：攻击8 → 攻击10。
- **机制**：只有该次攻击实际扣到玩家生命，才偷最多2储能；偷到每1点使怪物得2盾，盾最高8。满盾仍能偷，但不超盾上限；没储能不改扣生命。心力挡住致命伤导致实际生命未减少时，不偷能。
- **例子**：玩家3储能、6临挡，承受攻击8后损失2生命，怪物偷2储能，玩家剩1，怪物得4盾；若玩家有8盾完全挡住，则储能3不变，怪物不加盾。
- **应对词／操作**：防御、回防、放电、电热。
- **选入理由**：对囤能施压，完整防守可阻断。
- **原稿编号**：D05。

### 18. 对校官

- **数值**：第一幕Boss，生命88，初始护盾0。
- **行动循环**：一阶段：获得6护盾 → 朱批基础8 → 攻击6×2。二阶段：获得8护盾 → 朱批基础10 → 攻击7×2。
- **机制**：转阶段：生命≤当前生命上限50%，初始半血线44。 朱批前标记两枚不同的非固定己方原实体。红签：成词、单打或离盘解除；蓝签：以上方式或移动到另一格解除。每枚未解除签使朱批+2，所以最高12／14。每枚通过成词解除的签，额外造成3机制伤害。只出一签时最高只+2；无目标则基础攻击。
- **例子**：一阶段Boss已有校勘的6盾，红签在防、蓝签在御。玩家用两枚目标组成防御，同时解除两签并触发共6机制伤害，正好拆6盾；玩家得到10临挡，朱批降为8，被完全挡住。
- **应对词／操作**：普通组词、单打、投、流利。
- **选入理由**：一幕考使用与调位，保留简单解。
- **原稿编号**：C10。

### 19. 铅轨机

- **数值**：第二幕Boss，生命124，初始护盾0。
- **行动循环**：一阶段：压轨基础10 → 获得8护盾 → 攻击6×2。二阶段：压轨基础12 → 获得10护盾 → 攻击7×2。
- **机制**：转阶段：生命≤当前生命上限50%，初始半血线62。 压轨前标记一行最多3／4枚非固定己方原实体。结算时每枚仍留在原行，攻击+2，最高16／20；回袋、消耗、暂存或移到其他行算撤离。原格补入新字不算旧实体残留；同一原实体成词后因额外使用留在原行仍受计数。全部撤离则压轨攻击后再移除Boss最多8普通盾。空题不发拆盾奖励。
- **例子**：二阶段标记4枚，玩家将3枚移出该行，只剩1枚，压轨为12+2=14。若4枚全部真正离开，原格又补满新字，也只攻击12，随后拆最多8盾。
- **应对词／操作**：重连、收心、急转、急流、组词消耗。
- **选入理由**：二幕考实体离盘与原格补字。
- **原稿编号**：C11。

### 20. 万词编纂者

- **数值**：第三幕Boss，生命168，初始护盾0。
- **行动循环**：异文审校 → 重文校印 → 收卷。前两项基础攻击一阶段12、二阶段14；收卷为6×3／7×3。
- **机制**：转阶段：生命≤当前生命上限50%，初始半血线84。 异文要求当前阶段出2种不同多字词；重文要求当前阶段同一个多字词主动成功出2次。完成当前题：Boss先受6机制伤害，再攻击8／10；未完成：攻击12／14，随后得6／8盾。每题一次，计数阶段间清空。连击这个词只登记“连击”，重演上词不等于再提交上词。
- **例子**：一阶段异文，玩家出防御、充电，完成，Boss先受6机制伤害，再攻击8且不加盾。下一重文阶段玩家只出击破、连击：虽然击破效果执行两遍，但没有同名词出两次，任务未完成，Boss攻击12后加6盾。
- **应对词／操作**：流转、精力、精炼、反复、回放。
- **选入理由**：终局同时验证多样性与重复引擎。
- **原稿编号**：C12。
