# 经济简化与字框说明（2026-10-18）

普通金币是唯一货币。临时资金、股权、锁定投资、战后本金返还、跨战金币百分比增长均已移除。

## 镀金

镀金绑定一枚实体（UID），不再强化同字形所有副本。永久字袋中的该实体跨战保留镀金。每次有效单打或参与有效词语获得1金币；融合单位按实体只计一次，复制层、固定字的有效使用同样结算。仅弃字、无效出词与效果重演不额外触发镀金。

精金、休息与商店修饰可镀金。精金选字器列出具体实体；取消或无效目标不扣费、不消耗施词字。已镀金的实体不能重复选择。

## 原经济词的当前效果

|字或词|效果|
|---|---|
|资|获得2普通金币|
|资金|获得5普通金币|
|投资|支付3金币，为一枚实体永久镀金|
|再投资|支付3金币，为一枚实体永久镀金，再补2字|
|复利投资|为一枚实体永久镀金，立即获得3金币|
|利息|立即获得2金币|
|复利|立即获得2金币、补1字|
|炼金|立即获得3金币、补1字|
|合资|每2储能抵1金币，余款用普通金币|

保留投资相关词面作为镀金入口，没有股权、本金或延迟收益。旧远征词谱中的投资/利息说明已移除。序列化枚举中的两个旧槽位保留数值序号以免影响其他资源，不再产生资源。

## 字框共9种用途

其中只有第1种是永久强化框，其余为交互提示与敌人预告，不能理解为9种镀金强化。

|框或标签|用途|
|---|---|
|金框＋金|实体镀金，每次有效打出+1金币|
|红框＋数字|已选中，数字表示出字顺序|
|金色选区|技能作用范围，操作确认后框内生效|
|红|对校官红签：单打、组词或离盘解除；组词另有任务奖励|
|蓝|对校官蓝签：红签方式及移位均可解除|
|签|敌人任务目标；具体要求取当前怪物配置和预告|
|爆|引爆时处理该坐标仍在的非固定字；移走可避开|
|印|钤印区域；区域剩余占格影响朱批伤害|
|转|敌人即将旋转的2×2区域|

按后续交互要求：左侧不提供全部类型图例。只有点击某枚字，才显示该字实际拥有的镀金、污染、临时、仅组词、融合、叠层、精炼、固定/已用状态及关联怪物任务说明。悬停与拖动经过其他字不切换说明；普通字、空格和清除选择不显示额外说明。2D和3D均采用镀金金框、选中红框。
