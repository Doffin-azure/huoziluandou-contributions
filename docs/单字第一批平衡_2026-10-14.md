# 单字第一批平衡 · 2026-10-14

按讨论确认的范围实现十一枚单字，优先平衡单字收益、成本和持续时间。重、左、右保留整盘移动，继续承担前期基础调位。此次没有新增同一实体每回合只允许单打一次的限制。

| 字 | 当前效果 |
|---|---|
| 充 | 储能 +1，下回合多补 1 字，不立即补回自身 |
| 力 | 下一次攻击总伤害 +2；多段或群体攻击只在首个伤害段增加一次，触发后清除 |
| 御 | 下一次受到伤害减免 2 点，触发后清除，不再减免本回合每一段伤害 |
| 甲 | 下回合开始获得 2 点格挡，仅一次 |
| 清 | 选择原格四邻的一枚字，清除一个污染标签；按该字现有标签顺序移除第一个 |
| 能 | 本回合下一次正数储能获得额外 +1，仅一次 |
| 连 | 本回合下一次成功组词后补 1 字；单字不触发，出词后兑现一次 |
| 转 | 选择原格四邻的一枚非固定字，将原实体移入本字腾出的格子 |
| 放 | 不消耗储能造成 2 伤；可选择消耗 1 储能改为 8 伤 |
| 洗 | 选择原格四邻的一枚字，清除该字全部污染标签 |
| 强 | 本回合伤害 +1；下回合开始清除，强力词的持续加成独立保留 |

清、洗保留目标字的实例与归属，其他邻字不受影响；没有有效目标时仍可直接打出腾位。转不能移动固定字或覆盖未腾空的原格。界面只允许选择有效四邻目标。

放没有储能时直接进行普通攻击，有储能时提供「释放／普通攻击／取消」。选择前不消耗字与储能；取消保留盘面，选择释放但资源不足时在消耗前拒绝。结阵在实际结算前再次检查储能，自动化接口也提供两种攻击动作。

能、连未兑现的标记在新回合清除。甲兑现后不再续发格挡。HUD 显示对应待触发收益和强的临时加成。词条资源、内容生成器、GDD 和字表已同步。
