## 动态预览

`src/ui/effect_preview.gd`只读取BattleState，不执行效果，不创建字，不抽牌、不退款、不消费标记或随机数。

| 情况 | 显示信息 |
|---|---|
| 再 | 上一手成功出字的完整内容及末字；例如“上一手【防御】，末字【御】；本次生成临时【御】”。无历史、上一手为再、只能组词的临时复制分别解释 |
| 连击 | 最近可重演的即时攻击词；无可重演来源时明确提示 |
| 回放 | 上一个词、当前仍可返回的原实体及空位限制 |
| 重回／回收 | 当前仍在弃字堆的合法实体，避免把历史记录当成现存材料 |
| 复电 | 最近实际消费、已有退款、本次可退金额；已用过复电时提示0，需要新的消费 |
| 加强／过分 | 本场下一次计数及对应力量或基础伤害，不提前推进计数 |
| 电击／火力／放电／蓄力／热力／电热／火电等 | 当前资源对应的基础收益；追加伤害与临时标记单独解释 |
| 放／化／利／息／反超／回击等 | 当前是否有储能、热度、收入、血量或前序攻击，是否满足收益条件 |
| 精／购／投放／回购 | 当前候选原实体；选好后显示实际所选字及优惠后的费用，确认前不消费 |
| 当前待生效标记 | 所选词将触发的合、速、连、反复、复合、超能、超载、重复、力、热力、蓄力、连载、过火等；区分首段、每段、整次及材料消耗 |
| 冷心禁防 | 提示本次无法获得新护盾，避免只看基础转换值误以为能获盾 |
| 合击结阵 | 显示当前已结算状态，并说明最终按发动时队列顺序结算，避免把历史快照当作必然结果 |

选好目标进入待发动状态时重新生成预览；同一已选词刷新或切换敌方目标时也读取最新状态。只能组词的临时复制不会预告被禁止的单字收益。
