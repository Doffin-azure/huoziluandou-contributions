# 怪物机制与 Excel 配置适配

2026-10-18，在桌面 `huozi-art-design-20261017-bugfix` 副本上完成。

## 机制与配置

- 远征四种直接塞字怪继续使用蚀、重、连、热。仅向空格注入；防护、护、加收、净化与实际组词污染代价共用正式结算逻辑。
- 蔓生复制按回合快照结算，子代不在同一次结算继续复制；支持独立配置首次等待回合、每枚复制数、同源盘面上限。新实体继承制造来源和复制规则，已净化或消耗的实体不复制。
- 现有怪物机制中的67项数值已从逻辑常量改为配置读取，包括条件任务、奖励、偷能、吞字、首领阶段和成功／失败伤害。默认值保留原规则。
- 29只怪物、80个行动、67项机制参数、4种污染进入同一本Excel。只有实际影响该招式的数值标黄；无效字段禁止修改，避免“表改了但不起作用”。
- 怪物说明、战斗意图、战前行动循环与实际结算使用同一份运行时配置。词库本轮未扩充。

## 数据通路

`策划配置/怪物数值.xlsx` → 标准库导入工具 → `data/balance/enemies.json` → 数据库加载资源副本 → 战斗结算。

`data/balance/schema.json`保存字段、原始默认值、允许范围及不可修改的行标识。导入工具全表校验后原子替换配置，并保存一份`.json.bak`备份。运行时再次校验；无效配置整表回退默认值。不会覆写原始`.tres`或叠加上一次重载的修改。

源码的默认参数注册在`tools/balance/build_schema.py`。这是程序维护工具，日常调数值不用运行。开发者修改资源结构或增加参数后，须重新生成契约并同步生成新版Excel；不应用它重置策划已调好的工作簿。

两个导出预设已显式包含`data/balance/*.json`。已实际导出资源包并从独立空项目挂载，检查默认契约与导入配置两个JSON均存在且可解析。策划导入后再导出，即可携带所调数值发布。
