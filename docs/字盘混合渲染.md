# 字盘：3D 表现与 2D 连词输入

宣纸主题采用混合表现。桌面、木框、槽底、16 枚字块、选中标记和左右纸张是真实 3D 表现，字块字体由 Label3D 动态绘制；文本说明、连线箭头、按钮和输入保持原生 2D。墨芯主题继续使用原有 2D 字盘。

字块使用共享倒角网格，表面采样四种空白磨损材质；材质差异根据实体 UID 选择，不消耗游戏随机数。选中、释放、补字、重力移动和无效选择反馈沿用现有表现时序。3D 层映射这些视觉状态为抬起、落下、缩放和移动，实际投影由实时灯光产生。

输入没有改成自由移动字块。鼠标和触屏仍按四邻接连词、回退和确认。命中区域通过相机投影到固定的字格表面，选中后的抬起不改变格子边界；箭头跟随字块真实投影中心。外框和格间缝隙不视为字格。

战斗在书房的桌面近景展示。`BattleTableScene`、字盘与左右纸张共享 `StudyStage` 的世界、相机和灯光，字盘自己的显示视口在此模式停用。窗格、树冠与桌面物体产生实时投影；木框抬起后的投影、字块之间的遮挡以及木框向旁侧纸面投影使用同一渲染器。

木框使用独立旧木材纹理、沿木纹排列的 UV、细凸线和内侧压边；材质有纹理驱动的微法线、粗糙度差异和磨损色。纸张使用透明裁切保留自然边缘，在桌面上接收及产生阴影。低角度暖色主光配少量冷色环境填充，保留环境反射、接触遮挡与前景景深。TAA 用于稳定投影采样，原生 2D UI 保持清晰。

树影由 `TreeShadowCanopy` 的连续渐细枝干、分叉细枝、叶柄和收尖卵形叶片投射。叶片沿枝条交错生长，长度、朝向和密度有变化，使用独立固定种子的美术随机数；枝梢随缓慢摆动改变真实投影，减少动效时停止摆动。投影集中在桌面与纸张左上边缘，避免覆盖主要词效。原来的独立矩形叶片投影已移除。

`ArtPaper` 保留控件位置和角度，3D 纸张的顶点由相机射线与纸张平面相交得到；字盘同样按控件区域映射到桌面。字盘的输入投影回到原生 UI 坐标，始终以未抬起的字格表面命中。纸上文字和插画从桌面视口采样其下方纸面的受光色，数值与文案仍由游戏状态实时绘制。

核心文件：`StudyStage` 管理持续场景、相机和主光；`BattleTableScene` 管理近景陈设、投影物和纸张；`BoardPresentation3D` 管理字块并按环境选择共享场景或独立视口；`TypeMeshes` 提供倒角几何；`BoardView` 保留原有路径和输入逻辑。无书房环境时仍使用独立字盘和 2D 纸面回退。切屏时字盘与纸面由各自控件主动释放，避免留在持续书房中。

验证覆盖几何有效性、16 个字块投影命中、拖动与回退、触屏松手模式、模态浮层阻断、目标选择、格挡/破盾、多段攻击、随机数隔离和动画中切屏。实际桌面渲染使用 Godot 4.7.2 / Forward+；手机横屏尺寸经过窗口验证，实体手机性能未验收。

新增验证检查字盘与纸张是否位于同一渲染世界、是否停用重复视口、切屏是否释放共享模型；实际截图的纸面像素在关闭场景投影时变亮，用于确认投影不是烘焙贴图。手机截图断言真实输出为 844×390，关键信息完整可见。

左右纸张使用独立的空白宣纸素材，保留透明纸边、轻微角度和柔和落影；字块纹理仅用于活字表面。词效按当前连词、效果、目标和污染代价自然排布，关键数值用朱砂强调，长说明可滚动查看。手机横屏的战况使用连续纸面衬底。

墨灵已换成以选定样稿为参考生成的透明角色插画，保留双眼、纸巾和朱砂印；其他敌人继续使用各自字形区分。敌方生命数值显示在血条旁边，并随真实反馈同步更新。全部文案和数值仍来自原战斗状态。

实现参考：[Godot 相机射线与投影 API](https://docs.godotengine.org/en/stable/classes/class_camera3d.html)、[Spatial shader 材质与透明裁切](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)、[环境反射与色调映射](https://docs.godotengine.org/en/stable/classes/class_environment.html)。
