# 玩家文案核对表

此表为默认数值。游戏中的数字读取当前 Excel 配置。

## 写法

- 先写效果，再写触发条件和持续时间。
- 数字写明单位；同一种规则只用一个名称。
- 单打、组词、用掉字块和移出盘面分别表述。
- 战斗界面显示短句，细则放进可悬浮、可点击的词条。
- 不向玩家展示内部编号、参数清单或程序术语。
