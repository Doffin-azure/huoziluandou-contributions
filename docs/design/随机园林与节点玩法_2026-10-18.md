# 随机园林与节点玩法

## 入口

- 正常运行项目，标题界面选择「开始新冒险」。新开局默认 `random_garden`，自动保存完整布局与节点进度。
- 独立试玩：打开 `src/tools/random_garden_sample.tscn` 按 F6。每次启动新种子，不覆盖正式存档；场景的 `map_seed` 可填写非负整数复现。
- 原来的 `authored_garden_sample.tscn` 仍是种子 29 的固定总平面，用于对照。
- 继续旧存档保留其原来的模式和地图；随机园林存档进入下一幕继续生成随机园林。

## 本轮随机范围

以已经确认的总平面为组团语法。保留主池、厅堂、共墙、曲廊、水口和前后庭的空间关系，同时随机：

1. 园林入口朝向：四种正交朝向，所有几何及玩法同步转向。
2. 组团尺寸：沿共同的横纵控制带改变建筑、庭地与通路间距，不逐栋随意移动，共墙和屋檐接续关系保留。
3. 池形：西侧开敞园林的岸线凹凸、水尾轮廓变化，东岸窄通路与水榭落脚点保留净空。
4. 支路节点：每幕 18～21 个可选节点，一条实际路线经过 13～16 个节点（含起终点），事件 3～5 次。新增首战后、首次汇合后与第二次汇合后的三个共享事件停靠点，不减少战斗。部分建筑变成不停车的通路，其占地随相同边的权限开闭，不残留隐藏遭遇。
5. 节点组合：前段安排战斗与休整/事件，中段商店与精英分支对照，后段出现短精英支路或较长的战斗/事件支路。保证整张图有商店、精英、宝藏与休整，但不保证玩家选定路线经过所有类型。
6. 树木的种类、比例与装饰变化。

本轮仍有三处分叉再汇合，每处分支二选一。不是任意散点连线：建筑组团关系受同一套总平面语法约束，拓扑变化主要来自停靠点的增减及遭遇组合。以后新增其他总平面语法，可以沿用当前生成、通行和节点接口。

## 节点如何玩

| 节点 | 进入与结算 |
| --- | --- |
| 起点 | 门屋整备，点击行者管理行囊、字匣和版面，出门进入迎字厅。 |
| 普通战 / 精英 | 实际走入触发遭遇，点击开战进入真实战斗；胜利结算金币与择字奖励，返回同一地图位置并开放出口。 |
| 事件 | 使用当前幕的事件目录、正文和真实选项效果，支持后续选字；完成后开放出口。 |
| 火堆 | 回复气血、删除一枚字或为一枚字镀金；也可离开。本节点只结算一次。 |
| 商店 | 购买活字、删字、复制和治疗，购买后商品从库存移除；离开后节点结算。 |
| 宝藏 | 直接打开真实择字界面；选字收入字匣，字匣满时进字袋，跳过获得金币。只结算一次。 |
| 首领 | 固定终庭战斗，无追逐；胜利领取奖励后进入幕末，前两幕生成下一张园林，第三幕结束冒险。 |

跨过支路门就记录选择，另一支路两端封闭。封门标识、可点击目标和实际通行格共用同一份状态；已解决节点不重复发奖。

## 数据、通行与存档

- `src/expedition/random_garden_plan.gd`：控制带映射、岸线、节点组合和支路停靠点生成。
- `src/expedition/authored_garden_plan.gd`：共享组装器，按场地保存的格距构建通行格、建筑落脚点、桥栏杆和内设避让；新版一砖一格，旧布局保留四分之一单位格距。
- `src/map/authored_garden_visual.gd`：从同一场地数据装配建筑、岸壁、园林设施、莲叶和节点内容。旋转后的桥、屏风、亭子与通行避让保持一致。
- `src/expedition/room_run_state.gd`：真实玩法状态机，三幕加载、节点触发、分支封路、结算及保存。

布局生成使用独立随机数，不推进战斗、事件及奖励随机数。节点内容种子与布局重试独立。生成时校验每条连接在对应房间及通路内可达，不通过就按确定顺序重试。第 7、8 个候选保留原始间距，仍保留本种子的朝向和节点组合。

存档直接保存整份生成场地、图结构、节点内容及选择，不靠继续游戏时重新生成。生成算法后续迭代不会让旧随机存档换图。

新版移动、共墙装配、实例复用、预烘焙及手机档见[园林地图优化实施记录](园林地图优化_2026-10-18.md)。

## 调试接口

`src/tools/run_bridge.gd` 的 `mode: "courtyard"` 默认同样使用随机园林：

```json
{"mode":"courtyard","seed":17,"actions":[]}
```

可显式使用 `layout: "authored_garden"` 回到固定样板，或 `layout: "procedural"` 回到旧随机房间。`observe` 增加 `layout` 和 `generation`，保留 `next_rooms`、`legal_actions`、节点阶段及真实结算接口。

## 验证

- 8 个种子 × 8 条路线：可达性、封闭支路、全部节点类型、购买库存、领奖防重、休整、首领幕末、精确通行格恢复及跨幕生成。
- 同种子重复生成一致，布局生成不消耗玩法随机数，不同种子改变地形与停靠图。
- Native Vulkan 实机：随机朝向门屋实际行走、真实战斗到奖励再回图、事件/火堆/商店控件、宝藏、分支选择、舆图点击和行囊相机稳定性。
- 固定样板与原随机房间路线回归。
