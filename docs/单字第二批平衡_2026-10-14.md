# 单字第二批平衡 · 2026-10-14

按用户确认的方案实现十枚单字。反采用方案 A：在攻击者完整行动结束后反击，完全格挡也触发；多段只反击一次，污染掉血不触发。本回合未遇到敌人攻击则失效。反击伤害独立结算，不消耗力等主动攻击标记。

| 字 | 当前效果 |
|---|---|
| 反 | 本回合下一次受到敌方攻击后，在该攻击者整次行动结束时反击 6 伤，仅一次 |
| 破 | 先移除敌人最多 4 点护盾，再造成 2 伤 |
| 蓄 | 下回合开始获得 2 储能，仅一次 |
| 收 | 随机补 1 字，排除本次打出的实体；没有其他可补字时不补 |
| 再 | 临时复制上一个词／字的末字，禁止复制再本身 |
| 币 | 本回合下一次字／词的金币费用减 1，最低为 0，仅一次 |
| 利 | 本回合此前实际获得过金币时再获得 2 金币，否则无收益 |
| 投 | 支付 1 金币，将原格四邻的一枚非固定字移到指定空格 |
| 急 | 立即补 1 字，热度加 1；补字排除本次急实体 |
| 息 | 热度减 1；本回合尚未造成伤害时再回复 1 生命 |

反优先回应本回合首个实际攻击自己的敌人，纯防御、增益、注入行动不触发；精分让敌人攻击自己时也不触发。等待整段行动结束才反击，不中途打断多段攻击。原有反击、盾反、防反的词效继续使用各自规则。

收与急按实体身份排除施放材料，其他同字形实体仍可抽取；字袋不足时可循环其他弃字。超速的追加补字也沿用排除列表，避免补回本次实体。普通补字保留原先的行为和统计。

币在成功的正价支付时兑现，原价为 0 或支付不足时保留优惠；新回合清除未使用优惠。通用支付仍支持临时资金与合资替代，优惠影响实际费用。利记录本回合正数金币收入，随后花掉金币不取消资格；新回合清除收入记录。

投先选有效四邻目标，再选落点，最后点发动；选择与取消期间不扣金币、不移动字。满盘时可选择投字发动后腾出的原格。无效目标、被占落点和支付不足在消耗前拒绝，移动保留原实体及状态。强化投作为成词附加效果时，自动选剩余邻字与空格并支付费用。自动化接口支持相同选择和支付规则。
