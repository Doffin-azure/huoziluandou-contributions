# 单字第三批平衡 · 2026-10-14

按用户确认的第三批方案实现八枚单字。分生成仅供组词的临时复制；停降热后强制结束当前出字阶段，敌人正常行动。

| 字 | 当前效果 |
|---|---|
| 合 | 本回合下一次成功组词后获得 2 临时格挡、1 储能，仅一次 |
| 分 | 选择原格四邻己方字，在原格生成其主字形的临时复制；仅供组词 |
| 复 | 本回合下一次实际消耗储能时返还 1 点，不超过实际消耗，仅一次 |
| 速 | 本回合下一次成功组词后补 2 字、热度 +1，仅一次 |
| 停 | 热度 -4，立即结束出字阶段；敌人正常行动 |
| 载 | 本回合热容 +2，下回合开始撤销临时加成；热度不变 |
| 铸 | 四邻非固定己方实体字回袋，原格随机换入另一真实己方实体 |
| 炼 | 移除四邻非固定敌方字、临时字或自生污染字，获得 1 金币、热度 +1 |

合、速等待成功的多字词，单字和非法词不会兑现。标记在成词结算前取走旧值，结算后发放收益；强化在当前词中新设的标记留给后续词。合、速、复未兑现的标记在下回合开始清除。重复施放的额度相加，并在下一次对应事件中一次兑现；复的总退款始终不超过实际花费。免费支出和没有储能的支出不消耗复。

分保留目标原实体，复制只取主字形，不带融合、污染、镀金、固定、修饰、强化等级或额外使用次数。新字标为临时、仅供组词，显示“临／词”角标。单独打出时不触发其单字效果、单字强化、心力或反复；正常组词仍结算词效。复制及后续克隆继承仅供组词限制，消耗后不进入字袋或弃字堆。原格未腾空时不覆盖原字。

铸排除目标原实体及本次施放实体，可从字袋取另一真实己方字；不足时循环其他合法弃字。不同实体的同字形仍可替换。确认存在替换牌后才把目标原实体回袋，保留其全部属性，并记录一次真实补字。字袋、弃字堆没有可用替换牌时保留目标，只弃掉铸。不能替换临时牌或固定牌。

炼只清除杂字，不移动到字袋或弃字堆。永久己方字即使带污染也受到保护，所有固定字受到保护。没有有效目标时只弃掉炼，不获得金币、不额外升温。

分、铸、炼使用四邻目标选择，选定后确认；选择与取消不消费施放字。无效目标在消费前拒绝。强化附加触发时自动选取仍在棋盘上的合法邻字。战斗自动化接口同步目标规则，并公开仅供组词标记与临时热容。

载的临时热容独立记录，多次施放累加；到期只扣除本批临时加成，不影响重载等永久加成。到期本身不生成灼热污染；后续正数升温仍走正常溢热规则。

同时修正强制结束回合入口：出字演出的忙碌状态不再拦截停、急停、停息发出的结束请求。界面立即结算敌人行动，并恢复下回合输入。
