# 远征事件系统

远征事件内容和效果结算集中维护，UI 与两种运行模式不再各自复制事件选项。事件条目的完整表格与数值基线见[庭院事件条目](事件条目_庭院_2026-10-18.md)。

## 文件边界

- `src/data/event_catalog.gd`：共用事件目录；每个事件包含 `id`、`title`、`body`、可选 `illustration`、`options`，连续事件还可使用 `nodes` / `goto`。旧版自由探索的三种地图谜题放在同文件的 `MYSTERY_EVENTS`，它们使用不同玩法，不混入房间事件目录。
- `src/core/event_effects.gd`：事件目录查询、选项检查与效果解释器。
- `src/screens/event_screen.gd`：旧版节点地图事件的展示、选字浮层与 UI 状态；不再负责具体奖励规则。
- `src/core/run_harness.gd`：旧版整局 / AI 桥的事件阶段、合法动作、结算接线。
- `src/expedition/room_run_state.gd`：庭院房间事件的抽取、结算、待选效果与存档。
- `src/expedition/expedition.gd`：独立地图探索中「谜」事件的局内效果；文案数据引用目录的 `MYSTERY_EVENTS`。

## 添加事件

在 `EVENTS` 加一项，给稳定且唯一的 ID。每个事件固定三个选项，并标注 `acts` 与 `tags`：

```gdscript
{
    "id": "quiet_archive",
    "title": "静室",
    "body": "尘封的书架后传来纸页声。",
    "acts": [1, 2],                 # 第几幕可抽到；不写默认三幕
    "tags": ["character", "heal"], # 仅用于检索与文档
    "options": [
        {"text": "翻找（获得一枚字）", "primary": true, "effects": [
            {"type": "gain_character", "min_rarity": 0, "max_rarity": 1},
        ]},
        {"text": "静坐（回复 15 气血）", "effects": [
            {"type": "heal", "amount": 15},
        ]},
        {"text": "离开", "effects": []},
    ],
}
```

庭院模式用 `EventEffects.roll(GameState.act_index, GameState.rng, seen_events)` 抽取：按 `acts` 过滤当前幕，并优先避开本局已经出现过的事件；本幕事件全部用完后回退到完整池。无头 `RunHarness` 也按幕抽取；旧版事件页仍从完整目录均匀抽取，保留旧行为。连续事件在 `event_node` 中推进，`goto` 目标和待选效果都会进入庭院存档。

当前效果类型：

| 类型 | 字段 | 行为 |
|---|---|---|
| `damage` / `heal` | `amount` | 改变玩家生命；临时气血优先吸收 `damage` |
| `heal_percent` | `amount` | 按最大气血百分比回复 |
| `max_hp` | `amount` | 改变最大气血；当前气血不超过新上限 |
| `permanent_damage_reduction` | `amount` | 永久减伤成长 |
| `event_temp_hp` / `spend_event_temp_hp` | `amount` | 旧的事件内缓冲气血；借寿已改用【寿契】债务，不再依赖此字段 |
| `gold` | `amount` | 改变金币；负数为失去 |
| `gain_character` | `min_rarity`、`max_rarity`、可选 `count` / `glyph` | 从有效字库随机获得实体字；写 `glyph` 时发放指定字 |
| `gain_pollution` / `remove_pollution` | 可选 `count`；`gain_pollution` 可写 `character` 指定污染字 | 加入或清除污染字；默认加入【污】，可改为【债】【契】【忘】 |
| `gain_relic` / `remove_relic` | `relic`，可选 `fallback_gold` / `chance`；随机时可用 `pool` | 获得或献出遗物；绑定遗物自动尝试绑定一枚字；`chance` 失败时发保底金币；`pool:"event"` 才从事件遗物池随机 |
| `spend_gold` | `amount` | 扣除金币；事件选项应同时用 `gold_at_least` 条件 |
| `borrow_life` / `repay_life_hp` / `repay_life_max_hp` / `refuse_debt` | `amount` | 借寿、以气血还、以最大气血还、赖账；寿债存于【寿契】的 `life_debt` 计数器，2 点寿债折算 1 点最大气血 |
| `if` | `condition`、`then`、`else` | 按持有字、遗物、金币、气血等条件选择效果分支 |
| `remove_character` | 可选 `count`、`min_rarity`、`max_rarity` | 暂停结算，等待玩家逐枚选字删除；可按稀有度过滤；没有字可删时跳过 |

解释器拒绝未知效果类型；新增效果时先在解释器实现，再补 `tests/event_system_test.tscn` 覆盖。效果按数组顺序结算。选字暂停时，余下效果保留在待处理状态中；庭院模式将其纳入自动存档。事件条件可检查 `has_glyph`、`lacks_glyph`、`has_relic`、`lacks_relic`、`gold_at_least`、`hp_at_most`、`event_temp_hp_at_least`、`has_normal_relic_choice`、`pollution_count_at_least`、`has_character_min_rarity`。

## 事件专属字【础】

`foundation_stone`（础石留字）发放特殊字 `chu` / 【础】。它不是普通奖励字，带 `event` 标签，因此不会进入战斗奖励、商店、随机事件字池或自定义字袋。

- 稀有度 3，不可通过普通随机字池获得。
- 单字效果 `anchor_self`，目标为 `EMPTY_TILE`。
- 打出前先把原实体从原格移到所选空格，再设为 `pinned`；随后 `_consume_path` 不会把它送进弃字堆。
- `pinned` 字不被重力、旋转、换行和换位移动，可作为调整版面位置的“垫脚石”。
- 当前不要求它参与词谱组词；如果需要，后续再加入词条和平衡。

## 事件遗物池

事件遗物和普通遗物分池：

- 普通池：`Relics.normal_pool()`，商店、普通奖励、随机遗物效果使用。
- 事件池：`Relics.event_pool()`，目前为 `black_water`、`life_lantern`、`life_debt`。
- 事件池里的遗物不会进入普通随机池。
- 事件要发事件遗物时，显式写 `{"type":"gain_relic","relic":"..."}`；随机发事件遗物写 `{"type":"gain_relic","relic":"random","pool":"event"}`。
- 当前庭院房间地图不走旧远征许愿池，不能把许愿作为遗物获取入口。

## 璇玑字盘

`lantern_riddle` 的选项由 `LanternRiddles.fill()` 在事件开始时动态生成，并写入事件数据；退出重进不会刷新。

`xuanji_board` 是一个特殊事件子流程：

- 事件选项带 `"board": true` 后进入 `event_board` 阶段。
- 字盘由 `src/expedition/event_word_board.gd` 生成：4×4、至少 3 个 2～3 字词。
- `src/screens/event_board_screen.gd` 复用 `BoardView` 选路；`RoomRunState._resolve_event_board()` 再次校验路径和词谱。
- 确认合法词后，按词中不重复的字发放字卡，然后完成事件。
- 字盘种子、字面、目标词和路径写入庭院存档；每个事件只结算一次。

## 乱文骨骰

`chaos_dice` 事件指定发放【乱文骨骰】。遗物在拾取时把永久字袋全部替换为随机普通字，数量变为原来的 N+3；旧实体 uid、镀金和强化不继承，绑定类遗物会重新绑定。事件选项明确写“字袋全部重铸”，不隐藏这个风险。

## 无字灯

`lantern_riddle` 是一个随机灯谜池：`src/data/lantern_riddles.gd` 维护 16 个谜底、33 条谜面。事件开始时按简单/中等/困难各抽一个不同谜底，选项只显示谜面和“打一字”，谜底及隐藏收益不显示；选中后按谜底发字，并按是否已有该字给不同的隐藏奖励。

## 射覆

`shefu` 是一个纯随机三选一事件：三只碗中只有一只藏稀有字，另外两只为空。奖励位置由事件开始时的固定种子生成并写入 `event_data`，选项只显示“左边的碗/中间的碗/右边的碗”，重进不会刷新。

## 空手离开

纯益事件可以在三个收益选项之外，额外显示一个“空手离开”按钮：

- 事件数据默认 `allow_leave: true`；
- 强买强卖事件显式 `allow_leave: false`，不显示；
- 如果事件三个选项里已经有一个空效果选项，就不再显示额外按钮，避免重复；
- 离开不结算任何收益，直接完成事件；
- 庭院模式调用 `event_leave`，旧地图调用 `complete_current_node()`。

## 事件即时遭遇

事件选项可以带 `"spawn": "treasure"` 或 `"spawn": "battle"`，在事件效果结算后立即触发一次遭遇：

- `treasure`：直接从普通遗物池掉 1 件遗物，不进入选字奖励；普通遗物已收集完时改为金币 +30。事件专属遗物不会从宝箱掉出。
- `battle`：在事件房间内开始一场普通战斗；胜利后按普通战斗结算，再完成该事件房间。
- `spawn_relic: "random"`：只与 `spawn: "battle"` 搭配；胜利后不发普通战后三选一，改为发一件随机普通遗物；普通遗物已取尽时改为金币 +35。
- 当前实现是“事件结算后即时触发”，不向已经生成好的庭院路线里临时插入新房间，避免破坏物理道路和连通性。
- 选字类事件先完成选字，`spawn` 会保留到选字结束后触发。

## 事件污染字

污染字与普通字共用 `resources/characters` 注册，当前有四枚：

| 字 | id | 打出代价 | 用途 |
|---|---|---|---|
| 污 | `pollution` | 无单字效果，只占字袋 | 旧事件与敌人塞字 |
| 债 | `debt` | 失去 3 生命 | 井中回声 |
| 契 | `contract` | 失去 2 生命，下一次正常补字 -1 | 碑后小龛 |
| 忘 | `oblivion` | 下一次正常补字 -1 | 夜半敲门 |

新增污染字时，除了在 `src/tools/build_content.gd` 的 `_build_curated_characters()` 登记，还要给该字形补 `_solo_spec()`，否则只会成为没有代价的占位牌。若暂时不跑内容生成器，需要同时在 `resources/characters/` 放置同名 `.tres`，保证 `Database` 能立即加载。

随机字沿用本局 `GameState.rng`；插图只按路径加载，不抽随机数。事件 `requires` 会在进入事件池前过滤；讨债事件只有在持有【寿契】时才会被 `EventEffects.pool()` 选中。新事件可以不配插图；庭院抽屉会显示有 `illustration` 的事件图，未配图事件只显示文字；旧版事件页会自动隐藏插图区。添加选项时文案应清楚表达数值成本 / 收益，测试固定种子与既有插图测试，确认 RNG 与展示不被意外改变。
