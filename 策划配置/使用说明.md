# 用 Excel 调整怪物

1. 打开本目录的 `怪物数值.xlsx`，只修改浅黄色单元格，填整数并保存。
2. Mac 双击 `导入怪物数值.command`；Windows 双击 `导入怪物数值.bat`。
3. 确认窗口显示“导入成功”，重新启动本项目的游戏，再开始测试战斗。

不需要编辑代码、安装第三方 Python 包或另存为 CSV。导入工具需要本机已有 Python 3。Mac 脚本自动查找可用解释器；Windows 使用 `py -3` 或 `python`。

## 表格内容

| 工作表 | 用途 |
| --- | --- |
| 怪物 | 出现层数、小怪／精英／Boss类型、投放区域与状态；可调基础生命和开场护盾，共29只 |
| 行动 | 80个招式的基础伤害、攻击段数、护盾、塞字数量、状态层数 |
| 机制参数 | 67项条件门槛、成功后的伤害、奖励、复制规则、首领二阶段数值 |
| 污染 | 4种污染的打出扣血与少补字代价 |

灰色单元格只读：有些是定位标识，有些数值是该招式不会使用的字段，修改后会拒绝导入。条件伤害优先由“机制参数”控制，例如拓印师复制攻击的伤害、完成任务后的伤害、首领二阶段伤害。

允许对完整数据区域排序，行通过怪物ID、行动序号、参数ID定位。不要更改表头、增删行列、移动第4行表头，或只排序表内的一列。

## 常用例子

- 炉腹兽：在“怪物”修改基础生命，在“行动”修改炉息／喷焰的基础伤害与塞热数量，在“机制参数”修改高热门槛、伤害加成和攻击后升热。
- 铸巢蛾：在“行动”修改结巢塞连数量；在“机制参数”修改每枚复制数量、首次等待回合数、同源盘面上限。复制数量设0可关闭复制，结巢塞字数量设0可停止新注入。
- 墨蚀蠹：在“行动”修改注蚀数量，在“机制参数”修改蚀的同源盘面上限；打出代价在“污染”的刺痛行修改。
- 拓印师：在“行动”修改拓的塞重数量；在“机制参数”修改各类别对应伤害／护盾；堵塞代价在“污染”修改。
- 首领：阶段门槛以整数百分比填写，例如75表示生命不高于上限75%进入二阶段，不填0.75。

## 校验与回退

空白不是0，数值单元格不能填文字、小数、公式或超出允许范围的值。导入失败会显示工作表、行和字段，原游戏配置保持不变。

每次成功导入都会保存上一份配置。双击“恢复上次怪物数值”脚本可以撤回最近一次成功导入；然后重启游戏。恢复的是游戏配置，Excel不自动回退。连续点击恢复不会逐级恢复历史记录。

游戏读取到损坏、缺行或不匹配的配置时，会明确警告并整表回退到默认数值，不会只应用一半。

## 生效范围

修改本项目源码运行的游戏。已经开始的战斗保留开场配置；最稳妥的测试方式是导入后重启游戏。远征中的阶段／幕数生命倍率、印章等效果仍照常叠加在表格基础生命上。

发布版本需要先导入，再重新导出游戏。已安装的旧版App不会因为本目录Excel被修改而自动更新。新增怪物、机制类型、字形或词语仍需程序接入；本表用于现有内容调数值。

## 查看层数和怪物类型

“怪物”表的出现层数来自当前远征实际投放池：第1、2、3层分别对应第一、二、三幕。跨层复用显示为“第2、3层”；投放区域细分前区、中区、深区和层末。类型分小怪、精英、Boss。

当前实际投放21只，保留旧怪8只。旧怪明确标为“不投放／保留旧怪”，不会根据资源里的默认幕数误标成第一层。层数、类型、区域和状态用于阅读筛选，属于只读信息；调整投放规则仍需程序修改。
