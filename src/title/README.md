# 正式庭院标题界面

正常启动 `scenes/main.tscn`（F5）即可进入庭院标题。`project.godot` 的主场景没有改变，不需要启动独立样板。

## 职责

- `src/screens/title_screen.gd`：标题菜单、浮层锁、开始／取消入场、经典冒险和墨途远征路由。
- `src/title/courtyard_view.gd`：专用 SubViewport、背景与遮罩、相机入口、减少动效偏好、分辨率上限。没有游戏状态或存档操作。
- `src/title/courtyard/`：建筑、景观、有限色板与墨线、独立灯光、水面倒影、体积雾、树冠／灯笼风摆和落花。
- `assets/title/courtyard/materials/`：项目内贴图与 CC0 来源记录。运行时不访问网络。
- `src/tools/title_art_sample.tscn`：继续保留的独立审阅工具，继承正式背景视图，额外提供相机往返与灯光／雾调节；正式标题不显示这些调试控件。
- `src/art_samples/courtyard/`：材质下载、模型烘焙和 GIF 组装等美术工具。

标题保留当前主线的开始新冒险、墨途远征、自定义构筑、字库图鉴、字网图谱、设置、离开七个入口。设置复用 SettingsOverlay；图鉴复用 CollectionOverlay。存档和继续冒险仍在未合并的 `feat/study-battle-ui` 分支中，当前主线没有 SaveManager；本次未合并其他分支或新增持久化接口。

## 生命周期与交互

庭院使用独立世界与光照，进入标题时停用 StudyStage 的旧书房视口。Router 在 Main 下保留唯一的标题和庭院；离开标题时隐藏界面、禁用整棵子树处理及庭院／倒影视口渲染，返回时复用并复原镜头、文字、按钮和偏好，避免同步重建程序化网格。退出 Main 时统一释放缓存与 GPU 资源。地图使用行旅背景；战斗使用轻量 StudyStage 绘卷背景与独立字盘视口，旧书房、BattleTable 及其渲染资源已删除。

开始入口先锁定菜单、淡出文字并推进庭院镜头，2 秒后才创建一局冒险并打开地图。远征继续调用既有 Expedition.start。连点只触发一次；ESC 可取消，复原镜头、文字与按钮且不创建冒险；中途切屏会停止定时器并清除入场状态。图鉴、设置打开时阻断底层按钮，关闭后恢复输入与键盘焦点。

「减少动效」会实时暂停树木、灯笼、雾流、水纹，隐藏落花，并跳过入场镜头推进。设置沿用原持久化行为；测试直接恢复内存偏好，不写玩家配置。

桌面背景视口上限 1920×1080，镜像视口为其一半。移动平台或触屏设备自动使用手机配置：背景上限 960×540、30 帧更新，不创建实时倒影、体积雾或屏幕轮廓通道，关闭 MSAA、SSAO、实时阴影和部件重复描边；只更新 28 片落花。菜单和输入保持主视口分辨率与帧率，减少动效时背景只在布局／偏好变化时重绘。手机横屏按实际窗口比例预留至少 48 屏幕像素的按钮高度；不整组缩小菜单。实际手机帧率仍需真机验证，项目全局渲染方式保持不变。

## 验证

- `tests/menu_return_performance_test.tscn`：实际战斗暂停菜单返回按钮，连续 10 次记录同步耗时、首个绘制帧、帧间隔、内存和节点数；断言标题复用、隐藏时无动画／渲染、旧战斗释放、入场状态重置及主场景清理。性能数值只记录，不用固定毫秒阈值判断不同硬件。运行方法和真机测试见 `docs/qa/menu-return-2026-10-17/README.md`。

- `tests/study_flow_test.tscn`：正式启动、开始连点、相机推进、地图／战斗、返回标题、取消、减少动效、远征入口与场景释放。
- `tests/title_menu_test.tscn`：七个入口、图鉴与设置模态阻断、ESC、偏好实时响应、键盘焦点、自定义／图谱路由、内置字体切换、主场景退出。原生加 `-- --capture` 会额外保存桌面与 960×432 横屏截图并检查触控目标。
- `tests/title_art_sample_test.tscn`：共用背景的模型、着色、光照、镜头、反射开关、牌匾文字、薄雾图像变化、花瓣可见性及动态暂停／恢复。
- `tests/intent_design_test.tscn`：保留的战斗界面回归。
- `tests/mobile_presentation_fix_test.tscn`：桌面及两种手机横屏的状态布局、异常前后立绘占位、弹窗层级，以及手机庭院渲染预算、减少动效和入场／取消镜头。原生加 `-- --capture` 保存截图和同机绘制调用数据。

截图与运行记录见 `docs/art-concepts/2026-10-16/courtyard-3d/integration/`。美术工具的原始 GLB 仍为原始建模材质版本，不能在其他软件中自动复现 Godot 的着色和雾。
