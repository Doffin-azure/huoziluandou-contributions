# 行旅界面视觉层

选卡、商店、休整、事件、幕地图、远征、构筑、图鉴和共用浮层使用同一套墨青 / 米金 / 朱砂组件。正式标题仍使用独立 3D 庭院，战斗保留自己的舞台和字盘表现。

## 文件边界

- `journey_style.gd`：局部 Theme、色彩、九宫格边框、字号、页标题和分节。不要修改全局 `Palette` 来给某一页换皮。
- `journey_backdrop.gd` / `backdrop.gdshader`：正式庭院的原生截图，配合静态压暗，供普通行旅页使用。商店、奖励改用 `object_stage/` 的独立 3D 场景。
- `assets/ui/journey/`：所有运行时 PNG / SVG 都打包在项目中；`sources.json` 记录来源。
- `journey_tabs.gd`：仅切换可见页，保留控件和滚动位置，不调用游戏规则。
- `CharCard`：字袋、图鉴等列表的字面、说明、品阶刻点、悬停和焦点。商店、奖励使用 `GlyphOffer` 作为 3D 物件的投影交互区域。
- `ScreenBase`：默认给非战斗页面接入行旅皮肤；有独立背景的页面覆写 `has_scene_background()`。
- `HintButton`：仅在行旅皮肤下应用 48 屏幕像素的最低高度和键盘焦点；战斗常驻按钮沿用自己的布局。

说明文字按窗口与逻辑画布的比例放大。手机商店将价格投影在实物附近，当前物件的完整说明放在底部并保留滚动；字袋网格根据可用宽度减少列数。远征的手机横屏使用可滚动的大地图与「行旅 / 字阵 / 战报」侧栏；地图、版面和字匣按至少 48 屏幕像素预留触控面积，走动后保持玩家所在格可见。页签切换仅影响显示，不调用游戏行动。

## 展示与规则

页面仍把购买、治疗、字袋变化和推进节点交给原有 GameState / Expedition。商品抽取、价格、事件 RNG 不因换皮而更改。设置切换战斗字盘时只更新主题，不重建当前商店或奖励页，以免重抽内容。

选字列表按 glyph 查询当前字袋；显式传入空列表时保持空列表，不回退成全图鉴。取消选字和 ESC 关闭仍由各浮层负责。

字网只调整显示色、居中约束和节点避让，不改词库、度数或边集合。增加/删除词条时会重新计算布局。
